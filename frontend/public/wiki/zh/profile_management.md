# 个人资料、尺寸与配置 (`/me`)

在您的个人资料仪表板上管理身体测量、肤色、全身照片剪影、造型偏好、AI 模型凭据和系统集成。

## 概述
**个人资料与设置**页面 (`https://dressapp.co/me`) 是您 DressApp 生态系统的中央控制中心。它包含您的身体人体测量参数、数字试穿 Avatar 舞台、风格约束、本地化偏好、AI 模型密钥和推送通知时间表。

---

## 前提条件
- 一个活跃的 DressApp 账户。
- (可选) 用于上传全身照片的设备摄像头权限。
- (可选) 用于本地造型师营销活动定位和天气预报的位置权限。

---

## 分步指南：页面自上而下概览

### 1. 页面页眉和探索导航栏
位于 `/me` 仪表板顶部：
- **页眉**：显示您的账户状态和标题。
- **探索卡片**：通往应用主要部分的快捷方式：
  - **潮流侦察** (`/trends`)：查看每日 AI 精选时尚新闻。
  - **穿搭** (`/outfits`)：访问您保存的穿搭日历。
  - **专家** (`/experts`)：浏览本地时尚造型师和裁缝。
  - **拆箱 / 统计** (`/me/stats`)：查看衣橱估值、单次穿着成本 metrics 和颜色细分。

### 2. 语言与语音选择卡片
显眼显示，便于即时访问：
- **语言选择器**：从 12 种支持的语言中选择（*English, Spanish, French, German, Italian, Portuguese, Russian, Chinese, Japanese, Arabic, Hindi, Hebrew*）。选择语言会自动更新 UI locale 并绑定默认的区域 Text-to-Speech (TTS) 语音模型。

---

### 3. 身份与个人详情卡片 (`ProfileDetailsCard`)

包含 9 个可展开的 accordion 面板，用于管理您的个人身份、尺寸和 Avatar 渲染：

#### 面板 A：身份
- **名字与姓氏**：个人身份识别字段。
- **电子邮件地址**：您注册电子邮件的只读显示。
- **出生日期**：用于个性化人口统计趋势评分。
- *Google 自动填充徽章*：如果您的个人资料是通过 Google OAuth 自动填充的，则会自动显示。

#### 面板 B：联系方式与收货地址
- **电话号码**：接收每日日程安排提案和本地专家活动 SMS/Push 提醒所需。
- **地址行 1**：提供 OpenStreetMap (Nominatim) 街道级自动完成功能。选择建议会自动填充地址行 1、城市、区域、邮政编码和国家/地区。
- **地址行 2、城市、区域、邮政编码**：用于 marketplace 配送的手动地址字段。
- **国家/地区**：可通过国家名称或 ISO-2 代码搜索的离线 combobox。

#### 面板 C：人口统计
- **性别**：选择 *女* 或 *男* 以配置基础身体测量值和服装 taxonomy。
- **个人状态**：选择 *单身*、*已婚*、*离异* 或 *丧偶*。
- **职业**：自由文本输入（例如 *学生*、*市场经理*、*咖啡师*）。用于向潮流侦察个性化 ranker 提供信息，以优先显示相关风格新闻。

#### 摘要指南：同步缺失的 Google 个人资料数据 (People API 重新授权)
如果您在 DressApp 请求访问您的 **People API** 个人资料详情（电话、地址、性别、出生日期）之前通过 Google 登录，这些字段可能仍为空。您可以通过一键同步它们：

1.  **打开联系方式或人口统计 accordion** — 您会看到一个 **“从 Google 同步”** 按钮（刷新图标）位于部分标题旁边。
2.  **点击“从 Google 同步”** — 如果在您初次登录时未授予所需的 People API scopes，DressApp 会检测到这一点并显示一个 info toast：“*Google 需要您的权限才能访问个人资料详情。您将被重定向到 Google 以授予访问权限。*”
3.  **在 Google 屏幕上授予同意** — 您将被重定向到 Google 的 OAuth 同意屏幕。勾选 **个人资料信息**（姓名、电子邮件、照片）和 **联系信息**（电话、地址、性别、生日）的复选框。
4.  **自动返回与自动填充** — 同意后，Google 会将您重定向回 DressApp。`syncGoogleProfile()` 函数会自动运行，调用后端 `/auth/google/sync-profile` endpoint，该 endpoint 会：
    - 从 Google People API 获取您的电话、地址、性别和出生日期
    - 填充**联系方式**（电话、地址）和**人口统计**（性别、出生日期）面板中的空字段
    - 立即将更新保存到您的个人资料中
5.  **完成** — 您的个人资料现在已完成，无需手动输入。

> **注意**：“从 Google 同步”按钮也显示在页面页眉中（主“同步 Google 个人资料”按钮旁边），其工作方式相同 — 它会一次性同步所有可用的 Google 个人资料数据。

#### 面板 D：偏好与测量单位
- **重量单位**：在千克 (`kg`) 和磅 (`lb`) 之间切换。
- **长度单位**：在厘米 (`cm`) 和英寸 (`in`) 之间切换。

#### 面板 E：照片与数字 Avatar 舞台
- **左栏 — 照片选择器**：
  - *头像照片*：上传 Avatar 缩略图。
  - *全身照片*：上传全身照片。系统会自动执行本地 U2-Net (`rembg`) matting 以去除背景。
  - *删除照片按钮*：一键删除您的照片剪影，立即将试穿舞台切换回 2D SVG vector mannequin，无 UI 延迟。
- **右栏 — 数字 Avatar 与试穿舞台**：
  - **肤色选择器**：交互式调色板，用于选择您的 mannequin 肤色。
  - **Avatar 试穿画布**：使用校准的 landmark offsets（`top-[14.5%]` 领口到颈线和 `top-[36.5%]` 腰带到腰线）在您的照片剪影或动态 Bezier vector mannequin (`DynamicAvatar.jsx`) 顶部渲染服装。

#### 面板 F：风格档案
- **美学**：逗号分隔的风格关键词（例如 *简约、街头风、复古*）。
- **调色板**：首选色调（例如 *柔和色、大地色系、单色*）。
- **避免**：从 AI 推荐中严格排除的颜色或服装类型（例如 *黄色、露脐上衣*）。
- **文化着装保守度**：选择保守程度（*休闲/宽松*、*适度*、*保守*）以指导 AI 造型师的服装覆盖。

#### 面板 G：身体测量与尺寸（ANSUR II 尺寸预测器）
- **新手引导 / 全新开始模式**：输入 4 个基本数据：**身高**、**体重**、**腰围**和**脚长**。内置的 scikit-learn ANSUR II 多输出 regression model 会自动预测 6 项结构测量值：
  - *肩宽*、*胸围 / 胸部*、*臀围*、*袖长*、*内缝长* 和 *外缝长*。
- **自动尺寸转换**：一旦预测出结构测量值，确定性 sizing algorithms 会立即填充**所有标准零售尺寸**，直至鞋码：
  - *休闲衬衫尺寸* (XS–XXL 基于胸围)
  - *裤子腰围尺寸* (英寸，由腰围 cm 转换)
  - *美国鞋码* (男/女尺码公式基于脚长)
  - *女式连衣裙尺寸* (US 0–14+ 基于腰围)
  - *女式胸罩尺寸* (基于胸围/下胸围计算的 band + cup)
- **详细编辑模式**：自动填充后，微调所有 15 个 sizing 参数（包括衬衫尺寸、裤子尺寸、鞋码、胸罩尺寸、连衣裙尺寸）和头发属性（*长度、类型、颜色、款式*）。
- **实时单位切换**：在 *kg/cm* 和 *lb/in* 之间切换 — 所有值都会即时转换，无需重新预测。

#### 面板 H：专业与专家目录注册
- **专业造型师切换**：注册成为认证时尚专业人士（造型师、裁缝、设计师）。
- **业务详情**：输入公司名称、地址、电话、电子邮件、网站和描述，以显示在 `/experts` 目录和区域营销活动 ticker 中。

#### 面板 I：PayPal 付款设置
- **PayPal 收款电子邮件**：输入您的 PayPal 电子邮件，以接收 marketplace 销售和活跃专家活动的付款。

### 4. 系统偏好设置 Accordion 卡片

管理系统级设置、订阅和 AI 集成：

- **AI 配置**：
  - *标准模式*：使用系统管理的 Gemini Flash 2.x endpoints。
  - *自定义 API 密钥模式*：通过引导设置 modal 连接自定义 Google Gemini、Anthropic、OpenAI 或 DeepSeek API 密钥。
- **订阅与衣橱限制**：
  - 查看当前账户 tier（**免费版**：50 件物品限制 vs **经理版** 或 **专业版**：无限物品）。
  - 通过 PayPal Subscriptions REST API 升级（经理版：每月 $5 或每年 $50；专业版：每月 $10 或每年 $100）。
- **日程安排与推送提醒**：
  - 切换早晨穿搭提案通知。
  - 设置频率（*每天*、*隔天*、*每周两次*、*工作日*）、时间（例如，*07:00*）和着装风格要求（*休闲*、*正装*、*运动*、*自定义*）。
  - 启用浏览器 VAPID push 提醒。
- **营销活动通知偏好**：
  - *本地时尚推送/电子邮件*、*促销提醒*、*可持续时尚*、*奢侈品促销* 和 *个人造型师* 的精细开关。
  - 调整**最大营销活动距离**滑块（5km 至 50km）。
- **Google 日历连接**：OAuth 按钮，用于将个人日历事件与 AI 造型师同步。
- **位置服务卡片**：切换 GPS 位置权限，以获取距离匹配的专家信息和 hyper-local 天气。
- **邀请朋友按钮**：复制可分享的 referral link。
- **购物助手**：访问 Chrome Web Store 扩展程序详情或生成**通用 Bookmarklet** (`javascript:...`)，用于即时 e-commerce 尺寸比较。

- **未收到推送提醒**：请确认浏览器通知权限已启用，并且在*联系方式*下保存了电话号码。
- **地址自动完成无响应**：请检查互联网连接是否活跃，以便进行 OpenStreetMap Nominatim 查询。
