# Programma mattutino e avvisi push

Automatizza le tue scelte di stile mattutino con gli avvisi sugli outfit di cron.

## Panoramica
Lo strumento di pianificazione del guardaroba fornisce notifiche push mattutine personalizzate contenenti tre layout di outfit in stile. Coordina gli aggiornamenti meteo e gli eventi del calendario per mantenere il tuo look fresco e prevenire ripetuti modelli di usura.

## Prerequisiti
- Autorizzazioni di notifica push consentite nel browser del tuo dispositivo.
- Oggetti riposti nell'armadio (almeno uno sopra, uno sotto e le calzature).
- Chiavi API Gemini personalizzate (consigliate).

## Passo dopo passo
1. **Abilita avvisi**: vai a Dettagli profilo -> Pianificazione e push. Attiva/disattiva **Abilita notifiche**.
2. **Imposta orario**: scegli a che ora desideri ricevere l'avviso quotidiano (ad esempio, 07:30).
3. **Sincronizzazione calendario**: collega Google Calendar in modo che il sistema conosca le tue attività quotidiane.
4. **Ricevi suggerimento**: tocca la notifica per aprire l'elenco degli outfit.
5. **Conferma usura**: seleziona un layout per salvarlo nel tuo diario quotidiano.

## Risultati attesi
Una notifica push che arriva all'orario previsto mostrando le opzioni di stile ottimizzate.

## Risoluzione dei problemi
- **Nessuna notifica in arrivo**: controlla se il tuo browser/sistema operativo ha disattivato le autorizzazioni di notifica per DressApp.
- **Si consiglia di ripetere gli outfit**: compila il tuo diario di abbigliamento all'interno del calendario; l'algoritmo di rotazione richiede i registri della cronologia per filtrare le ripetizioni.

## Limitazioni
- Le notifiche richiedono una connessione Internet in background stabile sul server.
