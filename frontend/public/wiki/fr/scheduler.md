# Programme du matin et alertes push

Automatisez vos choix de style matinaux avec les alertes de tenues cron.

## Aperçu
Le planificateur de garde-robe fournit des notifications push matinales personnalisées contenant trois configurations de tenues stylisées. Il coordonne les mises à jour météorologiques et les événements du calendrier pour garder votre look frais et éviter les usures répétées.

## Conditions préalables
- Autorisations de notification push autorisées dans le navigateur de votre appareil.
- Articles stockés dans votre placard (au moins un haut, un bas et des chaussures).
- Clés API Gemini personnalisées (recommandées).

## Étape par étape
1. **Activer les alertes** : accédez à Détails du profil -> Planificateur et Push. Activez **Activer les notifications**.
2. **Définir l'heure** : choisissez l'heure à laquelle vous souhaitez recevoir votre alerte quotidienne (par exemple, 07h30).
3. **Calendar Sync** : associez Google Agenda pour que le système connaisse vos activités quotidiennes.
4. **Recevoir une suggestion** : appuyez sur la notification pour ouvrir la liste des tenues.
5. **Confirmer l'usure** : sélectionnez une mise en page pour l'enregistrer dans votre agenda quotidien.

## Résultats attendus
Une notification push arrivant à l'heure prévue affichant les options de style optimisées.

## Dépannage
- **Aucune notification n'arrive** : Vérifiez si votre navigateur/système d'exploitation a désactivé les autorisations de notification pour DressApp.
- **Répétez les tenues suggérées** : remplissez votre journal de tenue à l'intérieur du calendrier ; l'algorithme de rotation nécessite des journaux d'historique pour filtrer les répétitions.

## Limites
- Les notifications nécessitent une connexion Internet en arrière-plan stable sur le serveur.
