# 衣装プランナーとキャンバス

調整されたレイアウトを作成、レイヤー化、レビューします。

## 概要
Outfit Planner は、トップス、ボトムス、アウターウェア、履物を動的に重ねるためのアバター テンプレートを備えたビジュアル キャンバスを提供します。

## 前提条件
- クローゼットの収納アイテム。

## ステップバイステップ
1. **キャンバスを選択**: プランナーを開き、日付または新しいドラフトをクリックします。
2. **レイヤーアイテム**: 衣服を 2D アバターにドラッグします。アウターは自動的にインナーシャツの上に重ねられます。
3. **適合性の評価**: 互換性スコアと警告 (色の衝突や気象警報など) を確認します。
4. **保存**: タイトルを設定し、ワードローブ ダイアリーの外観をスケジュールします。

## 期待される結果
美しくレイヤードされた衣装の構成はカレンダーに保存され、グリッド カードのプレビューとして表示されます。

## トラブルシューティング
- **レイヤーの順序が間違っています**: アイテムのカテゴリを再確認してください。アウターを正しくスタックするには、「アウターウェア」として分類する必要があります。
- **重複アラート**: アバターが繰り返し着用することを警告する場合は、最近同じ場所で同じ服を着たかどうかを確認してください。

## 制限事項
- レイヤーはカテゴリタグに基づいて自動的に管理されます。手動の z-index オーバーライドはサポートされていません。
