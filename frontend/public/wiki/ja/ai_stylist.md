# 会話型AIスタイリスト

あなたのクローゼット、天気、スケジュールを知っている知的なパーソナルスタイリストに相談してください。

## 概要
AI スタイリストは自然言語の音声またはテキストのスタイリング クエリを処理し、気象条件やカレンダー イベントを自動的に統合します。

## 前提条件
- Gemini API キー (またはデフォルトのシステム クレジット)。
- 接続されたカレンダーイベント。

## ステップバイステップ
1. **セッションの開始**: [スタイリスト] タブを開き、[チャット]、[シャッフル]、または [マッチ] を選択します。
2. **音声入力**: マイクをタップし、質問を話して (例: 「雨の日の服装を提案してください」)、タップして送信します。
3. **オーディオ再生**: 高忠実度のスピーチ プレーヤーを介して、生成されたスタイリング理論を聞きます。
4. **シャッフル**: [Sparkles] ボタンをクリックしてスロット マシンを回転させます。 AI は、一致するアイテムに焦点を合わせて自動的に配置します。

## 期待される結果
個人の好み、季節の制約、スケジュールに合わせてカスタマイズされた衣装レイアウト。

## トラブルシューティング
- **オーディオの再生が遅すぎる**: プロファイル設定で Gemini TTS と Web Speech API フォールバックを切り替えます。
- **繰り返しの提案**: ローテーション アルゴリズムが繰り返しの着用をブロックできるように、服装カレンダーの履歴が更新されていることを確認します。

## 制限事項
- 推奨事項では、ルックを完成させるために、クローゼットに少なくとも 1 つのトップス、1 つのボトム、1 つの靴アイテムが必要です。
- サポートされていないエッジ デバイスでは、音声文字起こしが標準のテキスト入力にフォールバックする場合があります。
