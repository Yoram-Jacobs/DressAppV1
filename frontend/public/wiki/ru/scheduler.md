# Утреннее расписание и push-уведомления

Автоматизируйте свой выбор утреннего стиля с помощью оповещений cron об одежде.

## Обзор
Планировщик гардероба предоставляет настраиваемые утренние push-уведомления, содержащие три макета одежды. Он координирует обновления погоды и события календаря, чтобы сохранить свежесть вашего образа и предотвратить повторный износ.

## Предварительные условия
- Разрешения на push-уведомления разрешены в браузере вашего устройства.
- Хранящиеся вещи в вашем шкафу (хотя бы одна верхняя, нижняя и обувь).
- Пользовательские ключи API Gemini (рекомендуется).

## Шаг за шагом
1. **Включить оповещения**: перейдите в раздел «Сведения о профиле» -> «Планировщик и Push». Установите переключатель **Включить уведомления**.
2. **Установить время**: выберите время, в которое вы хотите получать ежедневное оповещение (например, 07:30).
3. **Синхронизация календаря**: привяжите Календарь Google, чтобы система знала о ваших ежедневных действиях.
4. **Получить предложение**: коснитесь уведомления, чтобы открыть список нарядов.
5. **Подтвердить ношение**: выберите один макет, чтобы сохранить его в своем ежедневном дневнике.

## Ожидаемые результаты
Push-уведомление, пришедшее в запланированное время, с оптимизированными вариантами стиля.

## Устранение неполадок
- **Уведомления не приходят**: проверьте, есть ли в вашем браузере/ОС разрешения на отключение уведомлений для DressApp.
- **Повторите предложенные наряды**: заполните свой дневник ношения в календаре; алгоритм ротации требует журналов истории для фильтрации повторов.

## Ограничения
- Для уведомлений требуется стабильное фоновое подключение к Интернету на сервере.
