# 对话式 AI 造型师

与了解您的衣橱、天气和行程安排的智能个人造型师互动。

## 概述
AI 造型师处理自然语言语音或文本造型查询，利用具备 15 分钟缓存和在途请求去重功能的线程安全 `useSyncExternalStore` 自定义 Store（`stylistStore` 和 `dailySuggestionsStore`），自动整合天气状况、日历事件和推送通知。

## 前提条件
- Gemini API 密钥（或默认系统积分）。
- 已连接的日历事件。

## 操作步骤
1. **启动会话**: 打开 Stylist 选项卡并选择 Chat、Shuffle 或 Match。
2. **语音输入**: 轻按麦克风，说出您的查询（例如“推荐一套雨天穿搭”），然后轻按发送。
3. **音频播放**: 通过高保真语音播放器聆听生成的造型理由。
4. **随机摇号 (Shuffle)**: 点击 Sparkles 按钮旋转老虎机；AI 会自动将匹配物品对齐到焦点位置。
5. **无等待无缝导航**: 在 Stylist 和其他选项卡之间导航时，使用内存中缓存的偏好设置，不会触发数据库 GET 请求循环。

## 预期结果
围绕您的个人偏好、季节约束和日程安排定制的穿搭布局。

## 故障排除
- **音频播放太慢**: 在 Profile 设置中切换 Gemini TTS 和 Web Speech API 备用方案。
- **重复推荐**: 请确保您的穿搭日历历史记录已更新，以便轮换算法阻止重复穿搭。

## 局限性
- 推荐需要衣橱中至少有一件上装、一件下装和一双鞋履才能完成一套造型。
- 在不支持的边缘设备上，语音转录可能会退回到标准文本输入。
