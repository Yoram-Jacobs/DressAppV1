# 前提条件とセットアップガイド

DressApp を使用する前に、すべての AI 機能とサービスを利用できるようにシステムが設定されていることを確認してください。

## 概要
このドキュメントでは、アプリをスムーズに実行するために必要なハードウェア要件、ブラウザーの権限、API キーの設定について説明します。

## 前提条件
- 最新のスマートフォン、タブレット、または PC。
- マイクのアクセス許可 (音声スタイルのリクエスト用)。
- 場所の許可 (現地の天候を考慮したスタイル用)。

## ステップバイステップ
1. **権限を許可**: アイテムをアップロードする際のカメラのプロンプトと、天気情報の更新に関する位置情報のプロンプトを受け入れます。
2. **Gemini API セットアップ**: プラットフォームの制限を回避したい場合は、プロフィールに移動し、Google AI Studio から無料の Gemini API キーを入力します。
3. **カレンダーをリンク**: Google カレンダーの同期を有​​効にして、イベントを意識した服装の計画を立てます。

## 期待される結果
シームレスな音声認識、自動化されたローカル天気予報、ローカルなカレンダー同期をお楽しみいただけます。

## トラブルシューティング
- **位置情報なし**: OS またはブラウザの設定で位置情報サービスが無効になっているかどうかを確認します。
- **マイクの問題**: 他のアクティブなアプリがマイク入力をロックしていないことを確認してください。

## 制限事項
- ローカル音声トランスクリプションは、Chromium ベースのブラウザで最適に機能します。
