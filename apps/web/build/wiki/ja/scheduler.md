# モーニングスケジュールとプッシュ通知

天候に合わせた最適なスタイル提案を毎朝自動でデバイスに直接お届けし、一日をスタートさせましょう。

## 概要
モーニングスケジューラーは、毎朝カスタムのスタイル提案を配信することで、アウトフィットの選択を自動化します。地域の天気予報と（Google カレンダー経由の）毎日のスケジュールを確認し、3つのコーディネートオプションを生成します。通知をタップすると、個人のアバターでオプションを確認し、お気に入りの選択肢を保存して、天候との適合スコアをすぐに表示できます。

## 前提条件
- **通知の許可**: デバイスまたはブラウザの設定で、DressApp のプッシュ通知を有効にする必要があります。
- **クローゼットのアイテム**: クローゼットにトップス、ボトムス、フットウェアのアイテムがそれぞれ少なくとも1つ以上アップロードされている必要があります。
- **Google カレンダー**: 連携済みの Google カレンダーアカウント（必須ではありませんが、予定に応じた提案を行うために推奨されます）。
- **Gemini キー**: 設定で設定済みのカスタム Gemini API キー。

## ステップバイステップの手順
1. **通知の有効化**: **プロフィール設定** -> **スケジューラーとプッシュ通知** に移動します。通知スイッチを「有効」に切り替えます。
2. **時間の調整**: 提案を受け取りたい正確な時間と分を設定します（例：午前 7:30）。
3. **カレンダーの連携**: カレンダー設定で Google カレンダーアカウントを接続し、AI があなたのスケジュールを把握できるようにします。
4. **提案を開く**: 朝のプッシュ通知が届いたらクリックします。**スタイリスト**内の**デイリー提案**（マッチ）タブに直接ルーティングされます。
5. **オプションの確認**: **アウトフィットのスケジュール**セレクターが自動的に開き、アバター上に直接レンダリングされた3つのスタイリングされた組み合わせが表示されます。
6. **保存と確認**: デイリー提案のいずれかをタップして、カレンダーにスケジュールします。アプリはアウトフィットを保存し、すぐに天候との相性メトリクス（カラーハーモニー、温度の適合度、スタイルの整合性）を示す詳細パネルをスライドして開きます。

## 期待される結果
設定した時間に毎日通知が届きます。クリックするとアプリが開き、アバター上に3つのオプションが表示され、完全な互換性の詳細とともにカレンダーに1つ保存できます。

## トラブルシューティング
- **通知が届かない**: 
  - ブラウザのサイト設定またはオペレーティングシステムの設定で、DressApp ウェブサイトの通知が許可されていることを確認してください。
  - 予定されている通知時間中に、デバイスが「応答不可」または「集中」モードになっていないことを確認してください。
- **アバターの衣服アイテムが不足している**: 
  - スケジューラーがアバターに正しく服を着せられるよう、クローゼットにすべての基本カテゴリ（トップス、ボトムス、靴）の服があることを確認してください。
- **一般的な提案ばかりになる**: 
  - Google カレンダーを連携して、提案が特定の毎日の予定と一致するようにしてください。

## 制限事項
- カレンダーにスケジュールできるアウトフィットは1日あたり最大1つです。
- 気象情報の更新には、サーバー上の有効なインターネット接続が必要です。
