# Интерактивный ИИ-стилист

Взаимодействуйте с интеллектуальным личным стилистом, который знает ваш гардероб, погоду и расписание.

## Обзор
ИИ-стилист обрабатывает запросы на стилизацию голосом или текстом на естественном языке, автоматически интегрируя погодные условия, события календаря и push-уведомления на базе потокобезопасных пользовательских хранилищ `useSyncExternalStore` (`stylistStore` и `dailySuggestionsStore`) с 15-минутным кэшированием и дедупликацией активных запросов.

## Предварительные требования
- Ключ Gemini API (или системные кредиты по умолчанию).
- Подключенные события календаря.

## Пошаговое руководство
1. **Начало сеанса**: Откройте вкладку Stylist и выберите Chat, Shuffle или Match.
2. **Голосовой ввод**: Нажмите на микрофон, произнесите ваш запрос (например, «Предложи наряд для дождливого дня») и нажмите для отправки.
3. **Воспроизведение аудио**: Прослушайте сгенерированное обоснование стиля через высокоточный речевой плеер.
4. **Перемешивание (Shuffle)**: Нажмите кнопку Sparkles, чтобы запустить слот-машину; ИИ автоматически выравнивает подходящие предметы в фокусе.
5. **Навигация без задержек**: Переход между Stylist и другими вкладками использует кэшированные в памяти настройки без запуска циклов GET-запросов к базе данных.

## Ожидаемые результаты
Индивидуальные раскладки нарядов, составленные с учетом ваших личных предпочтений, сезонных ограничений и расписания.

## Устранение неполадок
- **Аудио воспроизводится слишком медленно**: Переключитесь между Gemini TTS и резервным вариантом Web Speech API в настройках Profile.
- **Повторяющиеся предложения**: Убедитесь, что история календаря нарядов обновлена, чтобы алгоритм ротации мог блокировать повторное ношение вещей.

## Ограничения
- Для завершения образа в гардеробе требуется как минимум один верх, один низ и одна пара обуви.
- Голосовая транскрипция может переключаться на стандартный ввод текста на неподдерживаемых устройствах.
