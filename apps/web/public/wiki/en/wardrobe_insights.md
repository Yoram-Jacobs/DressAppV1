# Wardrobe Insights & Statistics

Analyze your clothing assets, spending efficiency, and usage statistics.

## Overview
The Insights workspace displays your closet's total financial worth, color compositions, and cost-per-wear metrics using rich graphs.

## Prerequisites
- Closet items with input prices.
- Scheduled outfit history in your calendar.

## Step-by-Step
1. **Open Insights**: Select your profile and navigate to Wardrobe Stats.
2. **Evaluate Worth**: View the aggregated financial value of your closet.
3. **Check Cost-per-Wear (CPW)**: Monitor the efficiency leaderboard showing which items have the lowest CPW (Price / Wears).
4. **Analyze Colors**: Review the color wheel distribution.

## Expected Results
Clear visual graphs illustrating under-utilized items, guiding future purchasing decisions.

## Troubleshooting
- **Zero value stats**: Make sure you populate the "Purchase Price" field when editing items.
- **Incorrect wear count**: Log daily outfits inside the scheduler to update wear frequencies.

## Limitations
- Graphs require active data points to render correctly; empty closets will display placeholder states.
