# Planos de Assinatura, Créditos e Rebaixamento de Plano

## Visão Geral
O DressApp oferece um modelo transparente de assinatura em três níveis (**Grátis / Free**, **Manager** e **Professional**), além de pacotes de recarga avulsa (Pay-As-You-Go).

## Níveis de Assinatura
| Recurso | Grátis ($0) | Manager ($10/mês ou $100/ano) | Professional ($15/mês ou $150/ano) |
| :--- | :--- | :--- | :--- |
| **Capacidade Máxima do Armário** | 50 peças | 200 peças | 300 peças |
| **Reconstruções de Peças com IA** | 5 / mês | 50 / mês | 100 / mês |
| **Upload de Conjunto de Peças (`mass`)** | Proibido | Incluído | Incluído |
| **Sugestões de Looks com IA** | 5 / mês | 30 / mês | 100 / mês |
| **Provador Virtual com IA** | 1 / mês | 15 / mês | 50 / mês |

## Por Que o Upload de Conjunto é Proibido no Plano Grátis
O upload de conjunto de peças (pipeline `mass`) usa o Nano Banana para reconstruir várias peças de uma só foto. Como uma única imagem pode consumir toda a franquia mensal de reconstrução de um usuário Grátis e deixar muitas peças sem reconstrução, esse recurso é exclusivo dos planos **Manager** e **Professional**.

## Aviso de Rebaixamento de Plano (Demotion para o Plano Grátis)
Se um usuário **Manager** (200 espaços) ou **Professional** (300 espaços) rebaixar para o **Plano Grátis (Free)**:
- **Perda dos espaços extras no armário:** A capacidade máxima do seu guarda-roupa volta para **50 itens**.
- **Apenas os últimos 50 itens adicionados são mantidos:** O sistema preserva apenas as **últimas 50 peças adicionadas mais recentemente** no seu guarda-roupa.
- **Peças mais antigas são excluídas permanentemente:** Todos os itens mais antigos além dos últimos 50 adicionados são removidos de forma permanente.
- **Confirmação obrigatória:** Antes de concluir o rebaixamento, o DressApp exibe um aviso claro sobre a perda das peças mais antigas e solicita sua confirmação.
