# Pré-requisitos e Guia de Configuração

Antes de começar a usar o DressApp, certifique-se de que seu sistema está configurado para aproveitar todos os recursos inteligentes de estilo e IA.

## Visão Geral
Este documento aborda os requisitos de hardware, permissões do navegador e opções de configuração de IA necessárias para executar o DressApp com facilidade. O DressApp foi desenvolvido para funcionar imediatamente sem a necessidade de chaves de API externas, oferecendo integrações opcionais para usuários avançados.

## Pré-requisitos
- Um smartphone, tablet ou computador moderno (iOS, Android, macOS, Windows, Linux).
- Permissão de câmera ativada (para fotografar roupas e ler códigos DPP).
- Permissão de microfone ativada (para pedidos de estilo por voz com mãos livres).
- Permissão de localização (para recomendações de roupas adaptadas ao clima local).
- *(Opcional)* Uma chave de API gratuita do Google Gemini caso queira usar recursos avançados como os canais do Trend Scout, restauração de fotos Nano Banana ou cotas personalizadas na nuvem. Contas gratuitas NÃO precisam de chave de API para usar o DressApp.

## Instruções Passo a Passo
1. **Conceder Permissões**: Aceite as solicitações da câmera ao fotografar itens, do microfone para conversas por voz e de localização para atualizações climáticas em tempo real.
2. **Comece a Estilizar Imediatamente (Plano Gratuito)**: Sua conta já vem equipada com o motor de IA local do DressApp (Gemma-4-E4B ajustado) e 10 créditos diários gratuitos de cortesia, sem necessidade de configuração técnica.
3. **Chave de API Personalizada Opcional (BYOK)**: Para ativar a inteligência de tendências Trend Scout ou a restauração de fotos Nano Banana, abra **Perfil** (/me) &rarr; **Configuração de IA** e insira sua chave gratuita do [Google AI Studio](https://aistudio.google.com/).
4. **Vincular Google Agenda**: Conecte sua agenda do Google no perfil para que o estilista considere reuniões, jantares e treinos agendados.

## Resultados Esperados
Você desfrutará de digitalização rápida de roupas, recorte transparente automático de qualidade de estúdio, consultoria de estilo por voz, alertas de clima local e combinações sincronizadas com sua rotina.

## Solução de Problemas
- **Clima local não aparece**: Verifique se os serviços de localização estão desativados nas configurações do navegador ou do sistema.
- **Problemas com o microfone**: Confirme se o DressApp tem permissão para acessar o microfone e se nenhum outro aplicativo o está bloqueando.
- **Preciso de uma chave de API?**: Não! Usuários do plano gratuito podem digitalizar roupas, organizar o guarda-roupa e conversar com o estilista sem inserir nenhuma chave externa.

## Limitações
- O reconhecimento de voz local funciona melhor em navegadores baseados em Chromium (Chrome, Edge) e no Safari.
- Os canais do Trend Scout e o reparo de fotos Nano Banana exigem uma chave de API pessoal do Google Gemini.
