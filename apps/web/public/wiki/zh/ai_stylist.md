# 对话式 AI 造型师 (Conversational AI Stylist)

与一位深谙您的衣橱储备、当地天气及每日日程的专属智能私人造型师畅快交流。

## 概述
AI Stylist 是您的贴心时尚伴侣。您可以像与好友聊天一样，通过打字或语音与它互动。造型师会自动获取您所在地的天气预报，浏览您的 Google Calendar 日程，并直接从您已拥有的衣物中搭配出完整得体的时尚造型。

DressApp 的造型大脑由高可用性的多层级智能架构驱动：
- **核心主力引擎 (Google Gemini 3.5 Flash-Lite)**：通过 `llm_gateway.py` 开箱即用，承担所有核心造型对话。它提供极致迅捷的响应（TTFT 首字延迟低于 350ms），零初始配置、零门槛——无需个人 API 密钥即可即刻开启造型咨询！
- **本地 VPS Eyes (`gemma-4-E4B`) — 免费层级与配额安全网 (Quota Safety Net)**：运行在 Hetzner CPX32 VPS 服务器 7860 端口 `dressapp-eyes` 容器中的专用精调 `gemma-4-E4B` 模型。它为免费层级（Free Tier）用户提供零变动成本的基础保障，并充当透明的故障备用（fallback）网。一旦遭遇 Google Gemini API 频率超限（`429` / `RESOURCE_EXHAUSTED`），查询将自动无缝重定向至本地部署的 Gemma，绝不会报错中断或产生 500 异常。
- **测试用户组计划 (Tester Group Program)**：经审核的测试人员可免费享有 **Professional 专业版** 权益，包括无限衣橱容量、Trend Scout 潮流雷达、每日着装排程推送以及每周期 100 造型额度。
- **自带密钥定制云端模型 (BYOK)**：用户可在“个人资料”设置中选择配置自己的 Google Gemini API 密钥，从而接入更高阶的模型（`gemini-2.5-pro`）或解锁高级生成式工具（Nano Banana 图像重构）。

## 先决条件
- 衣橱中至少已上传一件上装、一件下装和一双鞋履。
- 如需使用免提语音造型，请在浏览器或设备中开启麦克风权限。
- *（可选）* 关联 Google Calendar，使搭配建议能够契合特定活动与场合。
- *（可选）* 个人 Google Gemini API 密钥，如果您希望使用自己的云端开发者配额。

## 分步指南
1. **打开造型师**：点击底部导航栏中的 **AI Stylist** 标签页。
2. **语音或文字提问**：点击 **麦克风图标** 并询问着装建议（例如：*“下雨天的午餐聚会我应该穿什么？”* 或 *“推荐一套干练的职场通勤装”*）。
3. **收听语音建议**：造型师将通过语音给予专属搭配指导，并在屏幕上展示匹配的单品卡片。随时点击 **Play reply** 可再次收听语音回复。
4. **尝试 Shuffle 灵感轮盘**：想要突发奇想的新搭配？点击 **Shuffle** 标签页转动您的衣橱，探索从未设想过的全新组合！
5. **多轮对话微调**：在连续对话中直接要求造型师更换鞋子、替换外套或应对温度骤变。
6. **保存心仪搭配**：点击 **Save to Diary**，将造型保存至您的专属衣橱日历中。

## 预期效果
屏幕上将呈现个性化、适应当前天气的整套穿搭方案，并配有解释单品搭配原理的语音说明。如果外部 API 配额暂时耗尽，系统将通过横幅提示：已由内置的本地部署造型师无缝接替完成回答。

## 常见问题排查
- **麦克风无法识别声音**：请检查浏览器或设备的权限设置，确保 DressApp 已获准使用麦克风。
- **造型师频繁推荐重复衣物**：请在日历中记录每日穿搭，以便造型师了解您近期的穿着记录，并优先推荐未穿着的衣物。
- **“Using Platform Stylist (Quota Fallback)” 横幅提示**：当外部 API 触发速率限制时会出现该提示。应用已使用 DressApp 内置的本地 Gemma 引擎顺畅回答您的问题，对话不会产生任何中断。

## 使用限制
- 造型师仅根据您衣橱中的现有单品进行搭配；无法推荐您尚未上传的衣物。
- 免费层级（Free Tier）用户享有定期自动刷新的免费造型额度，而 Pro 与 Tester 测试账户则享有更高额度的月度配额。
