# 对话式 AI 智能造型师

与了解您的专属衣橱、当地天气与日常日程的 AI 私人造型师展开智能对话。

## 概述
AI 造型师是您在 DressApp 中的私人时尚顾问。您可以像与朋友聊天一样，通过文字或语音直接交流。造型师会实时查询您所在地的天气预报、查看 Google 日历行程，并完全使用您数字化衣橱中已有的衣物，为您量身打造完整而得体的时尚穿搭。

DressApp 的造型引擎默认搭载在服务器本地运行的深度微调模型 **Gemma-4-E4B**，所有免费层用户无需配置任何 API 密钥即可直接享受完整的智能对话服务。对于选择配置个人 Google Gemini API 密钥的用户，DressApp 还配备了**配额耗尽自动回退（Quota Fallback）**机制：当您的私有密钥达到速率限制（429 错误）或用尽每日配额时，系统会自动无缝切换至内置的 Gemma 模型并显示提示横幅，确保您的造型会话绝不会因报错而中断。

## 前置要求
- 衣橱中至少录入了一件上衣、一件下装和一双鞋履。
- 开启麦克风权限（用于免提语音对话）。
- *（可选）* 关联 Google 日历以获得兼顾商务会议与聚会场合的穿搭方案。
- *（可选）* 个人 Google Gemini API 密钥（如果您希望使用专属的云端限额）。

## 分步操作指南
1. **打开造型师**：点击底部导航栏中的 **AI Stylist** 标签页。
2. **说话或打字**：点击**麦克风图标**，直接询问着装建议（例如：*“下雨天去参加室外午餐该穿什么？”* 或 *“帮我搭配一套干练优雅的职场风穿搭”*）。
3. **聆听语音解答**：造型师将以生动自然的语音进行讲解，并展示匹配的整套穿搭卡片。点击 **“播放回复”** 可随时再次收听语音建议。
4. **使用灵感洗牌（Shuffle）工具**：想要新鲜感？点击 **Shuffle** 选项卡随机摇一摇您的衣橱，发现从未想过的惊喜搭配组合！
5. **保存至日记**：点击 **“保存至日记”** 将心仪搭配排期到您的个人穿搭日历中。

## 预期效果
屏幕上将呈现个性化、适应天气的成套搭配方案，并附带语音解说搭配逻辑。若私有 API 密钥超出额度，系统会展示提示横幅，告知已通过内置模型顺畅完成回答。

## 故障排除
- **麦克风无法录入声音**：请检查浏览器或设备的系统权限设置，确保已允许 DressApp 访问麦克风。
- **造型师频繁推荐重复衣物**：建议在穿搭日历中记录每日着装，以便造型师感知您最近穿过的衣服并优先挑选闲置服饰。
- **出现“正在使用平台内置造型师（Quota Fallback）”提示**：这表明您的私有 Gemini 密钥已达到请求限额。系统已通过内置引擎成功为您生成了回答，您可继续放心对话。

## 使用限制
- 造型师严格仅为您推荐已录入到个人衣橱中的衣物，无法推荐尚未上传的单品。
- 免费层用户每日享有 10 点免费 AI 造型额度，每 24 小时自动刷新充沛。
