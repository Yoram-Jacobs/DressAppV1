# 对话式 AI 造型师 (Conversational AI Stylist)

与一位深谙您的衣橱储备、当地天气及每日日程的专属智能私人造型师畅快交流。

## 概述
AI 造型师是您的私人时尚伴侣。您可以像与朋友交谈一样，通过打字或直接开口说话与它互动。造型师会查看您当地的天气预报，浏览您的 Google 日历事件，并直接用您已经拥有的衣服搭配出完整、时尚的穿搭方案。

DressApp 的造型大脑由高弹性的零 BYOK（无需自备密钥）多层级智能架构驱动：
- **Manager 与 Professional 计划 — 快速云端模型 (Google Gemini 3.5 Flash)**：**Manager** 和 **Professional** 计划的订阅者享有优先路由至快速云端 AI 模型（目前通过 `llm_gateway.py` 调用 **Google Gemini 3.5 Flash**）的权益，实现闪电般的极速响应（首字延迟 TTFT 低于 350 毫秒），且完全零配置。
- **免费层级（Free Tier）— 本地部署 Eyes (`Qwen 2.5 VL 3B`) 与配额安全网**：免费层级用户由运行在 Hetzner CPX32 VPS 的 7860 端口 `dressapp-eyes` 容器中的 DressApp 专用微调 **Qwen 2.5 VL 3B** 模型提供支持。它同时还充当付费层级的透明安全后备方案：如果遇到云端 API 速率限制（`429` / `RESOURCE_EXHAUSTED`），查询将自动重定向至本地部署的 Eyes，而不会失败或抛出 500 错误。

## 先决条件
- 衣橱中至少已上传一件上装、一件下装和一双鞋履。
- 如需使用免提语音造型功能，请开启麦克风权限。
- *（可选）* 连接 Google 日历，使穿搭建议能够感知具体场合与日程。

## 分步操作指南
1. **打开造型师**：点击底部导航栏中的 **AI Stylist（AI 造型师）** 标签页。
2. **语音或文字输入**：点击 **麦克风图标** 并询问您应该穿什么（例如：*“下雨的午后聚餐我该穿什么？”* 或 *“推荐一套别致的商务造型”*）。
3. **收听语音建议**：造型师会用语音回答量身定制的建议，并显示匹配的穿搭卡片。您可以随时点击 **Play reply（播放回复）** 再次收听语音建议。
4. **尝试 Shuffle（随机灵感）工具**：想要即时收获惊喜灵感？点击 **Shuffle** 标签页转动您的衣橱，探索您以前可能从未想到过的新颖搭配组合！
5. **通过追问进行微调**：在连续的对话流程中，您可以要求造型师更换鞋子、替换外套或根据温度变化进行调整。
6. **保存心仪搭配**：点击 **Save to Diary（保存到日记）**，将这套造型安排到您的个人衣橱日历上。

## 预期效果
屏幕上将显示个性化、适合天气的穿搭建议，并配有解释单品为何相配的语音分析。如果外部云端 API 配额暂时耗尽，信息横幅会提示内置的本地部署 Eyes 造型师已无缝完成了您的请求。

## 常见问题排查
- **麦克风无法识别说话内容**：请检查您的浏览器或设备权限，确保已允许 DressApp 访问您的麦克风。
- **造型师推荐过多重复的穿搭**：请在日历中记录您的每日穿搭，以便造型师了解您最近穿过什么，并优先推荐未穿过的衣物。
- **出现“Using Platform Stylist (Quota Fallback)”横幅**：当触及外部云端 API 速率限制时会出现此提示。应用已使用 DressApp 内置的本地部署 Eyes（`Qwen 2.5 VL 3B`）引擎顺畅回答了您的问题，您的对话不会受到任何干扰。

## 使用限制
- 造型师严格使用您衣橱中的现有单品进行搭配；无法推荐您尚未上传的衣物。
- 免费层级（Free Tier）用户使用本地部署的 Eyes 模型，并享有自动刷新的免费造型积分；而 Manager 和 Professional 账户则享有快速云端模型（`Gemini 3.5 Flash`）以及更高的月度配额。
