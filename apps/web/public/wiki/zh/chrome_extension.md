# 购物助理扩展

在线智能购物，找到与您的身体尺寸相匹配的确切尺码。

## 概述
DressApp 购物助手是一个与合作伙伴零售网站（如 Zara 和 ASOS）集成的浏览器扩展。它会动态读取服装页面上的尺码表，将其与您的个人资料尺寸进行比较，并立即推荐您最合适的尺码。

## 先决条件
- 桌面版 Google Chrome 浏览器。
- 在您的个人资料设置中存储身体指标（肩部、胸部、臀部、腰部）。
- 活动 DressApp 用户帐户凭据。

## 一步一步
1. **安装**：从 Chrome Web Store 下载并安装 DressApp 扩展。
2. **连接**：单击扩展图标并使用您的 DressApp 凭据登录。
3. **浏览**：转到合作伙伴商店（例如 Zara）并打开产品页面。
4. **比较**：扩展程序会读取服装尺码并突出显示您的搭配（例如“建议穿大尺码，以实现宽松的胸部合身”）。
5. **导入**：点击扩展弹出窗口中的**导入到衣柜**以保存该项目的草稿卡。

## 预期结果
准确、实时的尺码建议直接呈现在零售商店的产品描述上，消除了因尺码问题而导致的退货。

## 故障排除
- **没有推荐徽章**：确保您在扩展程序弹出窗口中登录到您的帐户。
- **测量空白**：返回您的移动应用程序配置文件详细信息并填充所有测量字段。

## 局限性
- 尺码表分析仅限于支持的合作伙伴商店。
