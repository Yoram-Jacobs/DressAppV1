# 欢迎使用 DressApp

欢迎体验您的终极数字衣橱助手！DressApp 旨在帮助您将实体衣橱数字化、条理化，并发挥衣物的最大价值。

## 概述
DressApp 依托尖端的多层级 AI 架构，将您的实体衣物转化为结构化的高清数字档案：
- **零门槛智能造型**：以 **Google Gemini 3.5 Flash-Lite** 作为核心主力引擎，提供低于 350ms 的极速响应；同时以本地托管的 **Gemma-4-E4B** 容器作为透明的配额安全网（Quota Safety Net）。无需配置个人 API 密钥，即可即刻获得智能搭配推荐。
- **日历与天气联动**：根据实时每日天气预报以及您的个人 Google Calendar 日程，为您量身定制每日晨间着装建议。
- **搭配规划器与人体模型画布**：可在个性化 2D 矢量模特或您自己的抠图人像上，直观进行数字衣物叠穿搭配。
- **互动式行李打包助手**：由 AI 精心策划的行李箱打包清单，适应任意旅行时长。
- **购物助手**：提供 Chrome 浏览器扩展和通用书签小工具（Bookmarklet），跨各大电商平台智能比对尺码与版型。
- **循环时尚市场**：直接发布闲置衣物进行出售、交换或出租，内置买卖双方安全交易机制。

## 先决条件
- 现代网页浏览器（推荐使用 Google Chrome、Apple Safari 或 Mozilla Firefox）。
- 互联网连接。
- 访问设备摄像头或相册的权限，用于衣物数字化。
- *（可选）* 麦克风权限，用于语音交互式造型咨询。

## 分步指南
1. **数字化录入**：使用摄像头拍摄衣物、上传照片或导入电子收据。应用将自动进行单品抠图与背景去除。
2. **分类整理**：在“衣橱”（Closet）工作区中为衣物添加标签、搜索并整理归类到专属合集中。
3. **咨询 AI 造型师**：点击 AI Stylist，通过语音或文字获取契合当前场景的搭配推荐。
4. **设计与叠穿**：在 Outfit Canvas 画布上组合造型，对比叠穿层级效果，并安排至日记日程（Diary）中。
5. **旅行打包**：根据目的地的天气预报，自动生成量身定制的行李箱打包清单。
6. **转售或置换**：直接将闲置衣物发布到循环市场，盘活衣橱资产。

## 预期效果
您将拥有一个井然有序、随时随地可查阅的数字衣橱，告别清晨选衣纠结，提升衣物利用率，拥抱可持续时尚生活。

## 常见问题排查
- **页面或图片加载缓慢**：请检查网络连接是否稳定；已缓存的离线单品仍可正常查阅。
- **界面方向异常**：切换语言时，DressApp 会针对从右至左阅读的 RTL 语言（希伯来语、阿拉伯语）自动镜像调整界面排版。

## 使用限制
- 免费层级（Free Tier）基础衣橱容量为 50 件单品（通过好友推荐奖励最高可扩充至 150 件）；升级至 Manager 或 Professional 订阅即可解锁无限存储空间。
- 在光线充足、背景对比鲜明的环境下，抠图与背景去除效果最佳。
