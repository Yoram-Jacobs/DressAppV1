# 前置要求与设置指南

在深入体验 DressApp 之前，请确保您的系统已完成相应设置，以便充分利用所有功能和造型服务。

## 概述
本文档涵盖了顺畅运行 DressApp 所需的硬件要求、浏览器权限以及订阅计划 AI 层级。DressApp 开箱即用，无需任何 API 密钥。

## 前置要求
- 现代智能手机、平板电脑或电脑（iOS、Android、macOS、Windows、Linux）。
- 已开启相机权限（用于拍摄衣物和扫描 DPP 标签）。
- 已开启麦克风权限（用于免提语音造型请求）。
- 位置权限（用于基于当地天气的造型推荐）。

## 分步操作指南
1. **授予权限**：在拍摄单品时接受浏览器或应用的相机提示，在语音对话时接受麦克风提示，并在获取实时当地天气更新时接受位置提示。
2. **立即开始造型（免费层级 / Free Tier）**：您的免费账户内置了 DressApp 的本地部署 **Eyes** AI（目前为经过微调的 **Qwen 2.5 VL 3B** 模型）以及每日免费造型积分，零配置即可直接使用。
3. **升级以享快速云端 AI（Manager 与 Professional 计划）**：**Manager** 和 **Professional** 订阅计划的用户自动享有优先路由至快速云端 AI 模型（目前为 **Google Gemini 3.5 Flash**）的权益，并可全面访问 Trend Scout（潮流雷达）时尚情报和 Nano Banana 照片重建功能。
4. **连接 Google 日历**：在您的“个人资料”下连接 Google 日历，让 AI 造型师能够了解即将到来的商务会议、聚会和健身课程。

## 预期效果
您将享受到流畅的相机录入、自动透明背景抠图、语音造型建议、当地天气提醒以及与日历同步的穿搭推荐。

## 故障排除
- **无法获取当地天气**：请检查您的操作系统或浏览器隐私设置中是否禁用了位置权限。
- **麦克风问题**：请确认已允许 DressApp 的麦克风权限，且没有其他应用程序独占锁定音频输入。
- **我需要 API 密钥吗？**：不需要！BYOK（自带密钥）功能已停用。免费用户使用我们的本地部署 Eyes 引擎（`Qwen 2.5 VL 3B`），而 Manager 和 Professional 计划订阅者自动享有快速云端模型（`Gemini 3.5 Flash`）。

## 使用限制
- 本地语音识别在基于 Chromium 的现代浏览器（Google Chrome、Microsoft Edge）和 Safari 上效果最佳。
- 快速云端模型路由（`Gemini 3.5 Flash`）和 Trend Scout 时尚频道在 Manager 和 Professional 计划中提供。
