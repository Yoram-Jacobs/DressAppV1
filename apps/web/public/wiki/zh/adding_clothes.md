# 录入与添加衣物

通过多模态 AI 扫描、智能背景移除和自动图像补全，在数秒内将您的实体衣橱数字化。

## 概览
通过实时相机拍照、相册多图上传、数字产品护照（DPP）二维码标签或电子收据（发票 OCR）录入衣物。内置的本地部署 AI 会自动去除背景、标记 20 多项时尚属性，并生成干净的影棚级抠图，全程无需任何 API 密钥。

## 前提条件
- 清晰、光线充足的衣物照片（对镜自拍、全身穿搭照或平铺照）。
- 用于扫描实物单品和二维码的相机访问权限。
- 电商购物的电子收据或发票截图（PDF / PNG / JPEG）。

## 分步操作指南

1. **交互式上传与拍摄**：
   - 点击 **添加单品 (Add Item)** &rarr; 选择 **拍照 (Take Photo)** 或从您的设备上传一张或多张穿搭照片。
   - 内置的重复检测功能会立即检查您之前是否已上传过同一件衣物。
2. **AI 分割与多单品检测**：
   - 视觉模型在单次扫描中即可分离出不同的服装单品（外套、上衣、半身裙、裤装、鞋履、配饰）。
3. **AI 抠图与干净的影棚级照片**：
   - 内置视觉流水线会自动为所有账户抠除背景，生成清晰、透明的 PNG 图像。
4. **自动元数据标签**：
   - 免费层级（Free Tier）账户使用 DressApp 的本地部署 **Eyes** 引擎（目前为经过微调的 `Qwen 2.5 VL 3B` 模型），而 **Manager** 和 **Professional** 计划用户则享有快速云端模型（`Google Gemini 3.5 Flash`），以提取 20 多项时尚属性（颜色、面料成分、子类别、着装规范、品牌和成色状况）。
5. **高级生成式照片修复（Nano Banana）**：
   - Nano Banana 会检查裁剪单品是否存在遮挡物（包袋、手部）和画幅边缘截断，自动外绘（outpainting）并重建缺失的面料，还原完整的影棚级照片，无需任何外部 API 密钥。
6. **电子收据与 DPP 标签**：
   - 切换至 **数字导入 (Digital Import)** 以解析订单确认邮件或发票，锁定购买价格和经核实的尺码。
   - 点击标签上的 **扫描二维码 (DPP)**，导入欧盟数字产品护照的供应链信息和洗护指南。
7. **保存至衣橱**：
   - 点击 **保存 (Save)**。单品将立即显示在您的衣橱网格中。

## 预期效果
每件衣物都会以居中、干净的影棚级品质照片呈现在您的数字衣橱中，并带有完整索引的搜索属性和丰富的分类标签。

## 常见问题排查
- **照片中衣物被截断/不完整**：请将衣物干净地居中放置在对比鲜明的背景前。Nano Banana 可以自动重建被截断的衣领或下摆。
- **光线与对比度**：拍摄深色衣物时，建议在浅色对比度高的背景前拍摄以获得最佳效果。
- **收据 OCR 识别偏差**：在收据图像上使用交互式选框工具，手动指定单个商品行。

## 使用限制
- 高分辨率批量上传（>5 件单品）将通过异步后台队列处理，以确保流畅的响应性能，避免浏览器超时。
