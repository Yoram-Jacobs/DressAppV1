# DressApp 完整技术用户手册

DressApp 个人衣橱生态系统、搭配引擎、循环市场和管理面板的全面用户手册和技术参考指南。

---

## 1. 概述与技术栈

DressApp 是一款 AI 驱动的个人衣橱管理器、搭配顾问和循环市场。它帮助用户以数字化方式管理衣服，自动剪裁并标记标签，接收结合天气和日历的穿搭建议，扫描欧盟数字产品护照 (DPP) 并交易衣物。

### 核心价值主张
- **数字衣橱导入**：照片上传或拍摄处理，带有自动后台去除、衣物分类和属性标签生成。
- **AI 虚拟搭配师**：一个对话式智能体，可结合上下文审查您的衣橱、Google Calendar 事件和当地天气预报，为您建议每日穿搭。
- **循环市场 (Circular Marketplace)**: 安全的个人间衣物购买、销售、交换和租赁，以减少快速时尚的浪费。
- **单次穿搭成本 (CPW) 分析**：洞察衣橱的资金价值、利用率和使用率优化。

### 技术架构
- **后端 Edge**：Python 3.11 及 FastAPI，使用连接到 MongoDB Atlas 集群的异步 Motor 驱动程序。
- **前端 SPA**：React 19 单页面应用，使用 `useSyncExternalStore` 自定义 Store (`stylistStore`、`dailySuggestionsStore`、`useOutfitStore`、`useClosetStore`、`useSuitcaseStore`)、Tailwind CSS、Shadcn/UI 组件，以及支持 12 种语言的 `react-i18next`。
- **状态与网络优化**：正在进行的请求去重、15 分钟的 Store 缓存和切换页面时的视口重新验证 (`visibilitychange`)，在闲置时实现零后台 GET 请求。
- **本地机器学习与尺码预测**：基于 CPU 的本地 U2-Net (`rembg`) 背景抠图、SegFormer-b2 衣物分割、Fashion-CLIP 嵌入和 ANSUR II 身体数据回归模型 (`body_predictor.py`)。可选路由到自托管的 GPU 容器 (SegFormer-b3 + BiRefNet) 以进行快速操作。
- **对话式 STT/TTS**：实时客户端 Web Speech 语音识别备用方案、服务端多模态 Gemini 2.5 Flash 生成、以及设备上离线的 Piper/Sherpa-ONNX 引擎。
- **外部集成服务**：用于天气获取的 OpenWeatherMap API、用于每日日程导出的 Google Calendar OAuth、OpenStreetMap (Nominatim) 地址自动填充以及 PayPal Subscriptions/Checkout REST API。

## 2. 前提条件

### 服务器宿主环境要求
- **硬件**：最低 4 GB RAM VPS（例如，托管生产环境 `dressapp.co` 的 Hetzner VPS）。
- **依赖项**：Docker 和 Docker Compose（包括后端、前端和 Caddy TLS 证书管理）。
- **环境变量**：API 密钥配置（`GEMINI_API_KEY`、`DEEPGRAM_API_KEY`、`OPENWEATHER_API_KEY`、`PAYPAL_LIVE_CLIENT_ID/SECRET` 和 Google Calendar OAuth 令牌）。

### 用户应用要求
- **网页浏览器**：Google Chrome 或 Apple Safari（完整语音功能兼容性所需）。
- **权限**：授予相机权限（用于衣服拍摄和二维码扫描）和麦克风权限（用于语音对话）。
- **网络**：大语言模型 (LLM) 处理的活跃连接，IndexedDB 本地缓存可提供离线目录浏览。

## 3. 步骤说明

### 3.1 导入衣物（添加物品）
导入方式：照片拍摄、欧盟数字产品护照 (DPP) 和电子购物小票。

#### A. 交互式相机和文件上传
1. 导航到**添加物品** (Add Item) 屏幕。
2. 选择 **Take Photo**（启动移动设备原生相机）或点击 **Upload Photos**（打开系统文件选择器）。
3. 客户端在浏览器中计算图像的 SHA-256 和 dHash 值（~100-180ms），以核对当前衣橱是否存在重复。
4. 如果发现重复，会打开**重复物品确认窗口**，显示匹配的预览。选择 **Skip** 或 **Add anyway**。
5. 确认添加后，服务器开始 NDJSON 数据流。占位符预览框架将在 5-7 秒内显示，允许您在后台完成标签分类的同时立即编辑物品详情。
6. 验证自动检测的标签（颜色、面料、版型、图案、场合）。如果抠图形状不正确，请更改 **Category** 下拉菜单，这将触发 SegFormer 自动重新裁剪衣物。
7. 点击 **Save**，即可立即在衣橱网格中显示该物品（~16ms），同时在后台完成 WebP 缩略图生成。

#### B. 扫描欧盟数字产品护照 (DPP)
1. 点击添加物品页面上的 **Scan QR (DPP)** 按钮。
2. 授予相机权限并对准印在衣物零售标签上的二维码，或上传保存的二维码截图。
3. 后端解析 URL 并执行 SSRF 安全检查（阻止私有 IP 范围）。
4. 系统抓取 JSON-LD 结构数据以提取品牌、材料成分、供应链追溯、碳足迹和保养洗涤指南。
5. 检查绿色 **Verified DPP Data** 手风琴面板中显示的提取数据，然后点击 **Save**。

#### C. 导入电子购物小票
1. 打开 **Digital Import** 选项卡。
2. 选择子模式：**Paste Text**（粘贴文本）、**Upload Image**（上传图片）、**Upload PDF**（上传 PDF）或输入 **Web Link**。
3. 后端使用多模态视觉模型提取交易信息（品牌、价格、尺码、类别）。
4. 提取的字段将被锁紧以保护它们免受未来的视觉重新分析。点击 **Save** 确认。

## 3.2 对话式 AI 虚拟搭配师
描述穿搭烦恼，并获得免提口头穿搭建议。

1. 导航到 **AI Stylist** 屏幕。
2. 点击聊天输入栏中的麦克风图标 `[Microphone]`。
3. 说出您的请求（例如：“下雨天的户外午餐，有什么上衣能搭配我的米色裤子？”）。
4. 如果支持 Web Speech，您的语音会实时转录在输入框中。如果不支持，应用会录制 WebM 文件并上传。
5. 后端将语音查询路由到本地 Gemma4 容器（如果离线，则回退到 Gemini 2.5 Flash 转录）。
6. 搭配师处理您的衣橱历史、当地天气预报和日历事件，以制定搭配方案。
7. 搭配师使用预先选择的语音配置文件（`puck`、`aoede` 或 `charon`）说出回复。
8. 点击卡片上的 **Play reply**（或希伯来语模式下的 **Replay**）以重新播放语音音频。

## 3.3 个人资料、偏好和子系统依赖性
个人资料页面是 DressApp 的核心控制面板。配置字段直接影响后续模块的性能、路由和行为。

##### 手风琴板块依赖关系与理据

1. **照片与数字头像舞台 (`AvatarViewer2D` 与 `DynamicAvatar`)**
   - **重要性**：使用双模式舞台（裁剪的真实身体照片剪切对比动态 2D 贝塞尔曲线矢量 SVG 人体模型），在所有试穿画布上呈现您的视觉形象。
   - **子系统依赖性**：照片剪切通过本地 U2-Net (`rembg`) 进行背景抠图处理，并在浏览器中压缩至最大 1280px、82% 的质量，以契合 MongoDB 的 16MB 文档上限。舞台应用校准的标志性偏移位置（领口到衣领为 `top-[14.5%]`，裤腰到腰线为 `top-[36.5%]`，鞋履平面为 `bottom-[2%]`）和比例胸围/臀部宽度调整（$scaleX$）。点击 *Remove Photo* 即可立即切换回 2D SVG 矢量人体模型。

2. **穿搭风格（保守度规则，着装要求）**
   - **重要性**：为推荐的穿搭建立个人边界，防止 AI 生成不合适的风格建议。
   - **子系统依赖性**：选定的参数（例如保守衣服限制）将直接输入到 Gemini 2.5 Flash 的搭配提示词中，在展示之前过滤匹配的衣橱物品。

3. **个人详情（姓名、电话、职业）**
   - **重要性**：定制沟通语气并路由通知提醒。
   - **子系统依赖性**：用户名被动态整合到邮件和系统推送中。电话号码作为日程提醒的备用联系方式。职业参数输入给搭配师 LLM 和 Trend Scout 个性化排序器以定制专属提议。

4. **身体数据与尺寸 (ANSUR II 回归模型与尺寸预测器)**
   - **重要性**：消除尺寸猜测，实现自动零售尺码计算、外部零售尺码对比以及精准的虚拟叠穿。
   - **子系统依赖性**：输入 4 个基本参数（**身长**、**体重**、**腰围**、**足长**）会触发 scikit-learn ANSUR II 回归模型 (`body_predictor.py`) 自动预测 6 个结构维度（*肩宽*、*胸围*、*臀围*、*袖长*、*裤内缝长*、*裤外缝长*）。
     - **确定性尺寸转换**：一旦预测出结构尺寸，后端尺码引擎会动态将其转换为零售服装尺码：**衬衫尺码**（根据胸部计算的 XS-XXL）、**裤子尺码**（以英寸为单位的腰围）、**鞋码**（基于足长和性别的美国男款/女款和欧洲标准）、**连衣裙尺码**（基于胸围、腰围和臀围的美国 0-14+ 码）和**胸罩尺码**（基于胸围和预计下胸围计算的罩杯和下胸围围度）。
     - **自动填充**：这些推荐的零售尺码会自动填充到个人资料中的 *Detailed Edit Mode* 字段中。
     - **集成**：测量值直接由 Shopping Assistant 浏览器扩展程序读取，以查阅合作网站（Zara、Asos）上的尺码表并推荐最佳尺码。

5. **生活方式（婚姻状况、性别）**
   - **重要性**：量身定制默认推荐并对内容算法进行评分。
   - **子系统依赖性**：性别选择直接影响每日 Trend Scout 卡片的排序逻辑。如果新闻卡片类别与用户性别不匹配，算法会应用 -2.0 的评分惩罚，从而在信息流中降低其位置。

6. **AI 配置（SaaS 密钥、本地运行、额度）**
   - **重要性**：决定计费路由、运行性能和网络离线状态。
   - **子系统依赖性**：路由文本/音频生成查询。标准设置会消耗 DressApp 系统额度。输入个人 API 密钥（Google AI Studio、Anthropic、OpenAI）会将费用重定向到用户的开发者账单账户。选择本地运行模式会将查询路由到离线 Gemma 容器。

7. **日程与推送（频率、日常警报、风格重点）**
   - **重要性**：管理每日自动搭配推送。
   - **子系统依赖性**：激活 FastAPI 后端上的 `APScheduler` 定时任务。每天早上，它会使用客户端的 VAPID 密钥通过 `pywebpush` 发送推送通知，匹配所选的风格重点参数。

8. **Google Calendar（OAuth 同步，导出规则）**
   - **重要性**：将您的衣橱直接与您的现实日历事件联系起来。
   - **子系统依赖性**：通过 Google OAuth 进行身份验证。日程表查询您的日历以识别事件、生成搭配，并将日历事件直接推送到您的 Google Calendar 日程中。

9. **定位服务（GPS 定位，天气精度）**
   - **重要性**：协调适合天气的建议和本地交易的距离过滤器。
   - **子系统依赖性**：触发 `navigator.geolocation` 逆地理编码。坐标发送至 OpenWeatherMap API 以调整搭配师建议（例如大雨天气建议防雨服）。它还会计算与本地市场商品和专家的距离。

10. **语音与语言（虚拟搭配师声音选择）**
    - **重要性**：确定语言环境和语音配置文件。
    - **子系统依赖性**：控制通过 `react-i18next` 进行翻译的活动语言。声音选择将 BCP-47 语音代码（例如 `he-IL` 或 `ar-JO`）映射到客户端网页语音合成声音或离线 Piper TTS 模型。

11. **邀请好友（分享数据 API）**
    - **重要性**：为免费衣橱扩容提供裂变循环。
    - **子系统依赖性**：将推荐人的 MongoDB ID 附加到 URL。新注册会动态读取此 ID，并自动将推荐人的 `closet_capacity_bonus` 增加 +10 个位置，更新 `closet.py` 中的容量上限。

## 3.4 衣橱分析仪表板
分析衣橱总价值，跟踪衣物利用率和 CPW 参数。

1. 导航到 **Wardrobe Insights**。
2. **审查指标**：
   - *衣橱价值 (Closet Worth)*：购买价格的动态总和。
   - *衣橱利用率 (Closet Utilization)*: 至少穿过一次的衣物百分比。
   - *平均单次穿搭成本 (CPW)*：计算为 `价格 / 穿搭次数`。
3. **分布图表**：切换选项卡以查看 Recharts 可视化图表：
   - *调色板*：衣橱中十六进制颜色代码分布。
   - *材料*：面料百分比分布。
   - *子类别*：子类别分布。
4. **效率排行榜**：查看展现出最低单次穿搭成本 (CPW) 的前 5 件衣服。

## 3.5 头像画布与穿搭规划
在交互式 2D 头像画布上构建、搭配多层并审查穿搭建议。

1. 打开 **Outfit Canvas** 规划器。
2. **多层叠穿（双画布）**：如果您的穿搭包括衬衫外的外套（例如夹克），该页面会渲染两个垂直头像画布：“With Outerwear”（显示夹克外搭）和“Without Outerwear”（展示里层衬衫）。
3. **交互式 2D 元素**：直接点击头像身上的任何衣服配件，即可直接跳转到该物品的详情屏幕。
4. **指标选项卡**：点击详情按钮并选择 **Metrics** 选项卡，查看兼容性标准的进度条：
   - *色彩和谐度*（中性色调和谐）。
   - *图案兼容性*（防印花冲突）。
   - *身体贴合度*（尺寸匹配）。
   - *气候匹配*（季节适合度）。
   - *事件匹配*（活动适当性）。
   - *位置匹配*（审查是否符合保守衣服限制）。
5. **重命名/描述**：点击画笔图标编辑衣服套装名称和描述。

## 3.6 行李箱助手
明智组织旅行的行李打包需求，避免超重。

1. 转到 **Suitcase** 页面并填写旅行信息表（目的地、开始/结束日期、旅行类型、日历事件）。
2. AI 根据旅行天数和当地天气预报生成定制打包清单和每日穿搭。
3. 检查打包进度。如果缺少重要物品（例如雨天用的雨伞、沙滩用的泳装），系统会警告您并建议从市场或本地商店补充。
4. 使用内置聊天框微调建议（例如“将第 2 天改为休闲晚装”）。助手在保留其余列表的同时编辑行李箱。
5. 点击 **Approve Suitcase** 最终确认您的打包计划。

## 3.7 日程规划与每日提醒
设置每日搭配提醒，以便在手机上自动接收穿搭推荐。

1. 打开 **Profile** 并前往 **Scheduler & Push**。
2. 启用通知，设置每日警报时间、周工作日频率和穿搭主题。
3. 每天早晨，后台定时任务 (`APScheduler`) 会查看天气预报并发送推送通知。
4. 点击手机上的通知（或访问 Web 应用通知中心）以打开显示 3 个推荐方案的对话窗口。
5. 将推荐直接保存到您的穿搭日历 **Wardrobe Diary**。

## 3.8 循环市场（二手销售、出租、交换、赠送）
参与个人间的循环时尚市场。

- **创建商品信息**：打开物品的详情页面，选择 **Edit Intent**，然后选择一个公开意图：
  - *For Sale*（销售）：输入售价和货币（通过本地设置自动检测您的默认货币）。
  - *Rent*（租赁）：设定每日租金和借出条件。
  - *Swap*（交换）：标记物品开放以进行交换。
  - *Donate*（捐赠）：免费发布物品。
- **状态同步**：商品信息会自动发布到市场信息流中。客户端使用 `useSyncExternalStore` 和本地 IndexedDB 缓存来无延迟加载搜索结果。
- **虚拟试穿沙盒**：买家/租客可以在结账前，将商品信息与自己私人衣橱中的衣物并列进行虚拟试穿。
- **交易结账**：
  - *购买/租赁*：通过集成的 PayPal 按钮完成交易。传入的 Webhook 会通知卖家，将商品状态变更为已售/已租，并在扣除 7% 平台费后记录在账本中。
  - *以物易物（交换）*：潜在交换者提出交换提议。拥有者收到确认邮件以接受或拒绝。

## 3.9 管理后台仪表板 (Admin Panel)
系统运行状况验证、财务账簿审计和用户账户管理。

1. 导航到 `/admin`（可供管理员角色使用）。
2. **概述**：审计总交易量和平台佣金收入摘要。检查 **Provider Activity Table** 以监控外部服务（Gemini API、天气 API）的响应时间及错误率。
3. **服务商 (Providers)**：点击 **Verify Key** 向 Gemini API 发送测试 Ping。切换 **Eyes Vision Override** 开关，在默认的 Gemini 云端和本地的 Gemma 容器之间切换图像分析。
4. **用户**：查看活跃额度、角色和累计付款。使用直接操作来提升或降低用户权限。
5. **商品信息 (Listings)**：查看商品状态并编辑活跃标记以暂停欺诈商品。

## 4. 预期结果

- **物品导入**：物品立即出现在衣橱网格中（~16ms）。背景去除效果干净，可生成透明的 PNG 文件。
- **DPP 验证**：扫描正确的二维码产品护照会显示绿色的可持续信息卡。
- **头像多层渲染**：在 2D 头像画布上，外套正确盖在衬衫上方，且鞋帽和配饰无显示冲突。
- **语音播放**：AI 搭配师的文本回复会自动伴随波形动画进行语音朗读。
- **订阅方案**：升级到 Manager 或 Professional 方案后，容量限制警告会立即消失。

## 5. 常见问题排除

### HTTP 402 Payment Required
- **问题**：衣物导入被阻止。您已达到 50 件物品的免费上限（或通过邀请好友增加至 200 件）。
- **解决方案**：前往**价格页面** (`/pricing`) 并订阅 Manager 或 Professional 方案，或者分享您的邀请链接以在每次注册时获得 +10 个位置（最多 200 件物品）。

### SSRF Blocked / DNS 错误（DPP）
- **问题**：无法解析所扫描产品护照二维码的 URL。
- **解决方案**：解析器会拦截局域网 IP（例如 `127.0.0.1` 和 `192.168.x.x`）以保护平台内部服务器。确保二维码指向公网域名。

### 相机 / 麦克风权限被拒绝
- **问题**：扫描或捕获窗口显示带 'X' 的错误屏幕，或语音打字失效。
- **解决方案**：打开浏览器权限设置，允许该域名访问相机和麦克风，然后重新加载。

### 搭配师聊天失败 / 达到调用限制
- **问题**：聊天冻结或报错。
- **解决方案**：服务器捕获 Gemini `429` 频率超限错误并自动切换到基于静态规则的衣服选择逻辑。检查您的网络稳定性。

### 服务器内存溢出 (OOM) 峰值
- **问题**：上传文件时服务器 CPU/内存占用过高。
- **解决方案**：一次性上传 5 件以上物品时，导入会使用顺序队列锁。确保服务器至少有 4 GB RAM。

## 6. 限制

- **浏览器语音 API**：语音转文字输入主要支持 Chrome 和 Safari；其他浏览器将退回到键盘输入。
- **离线语音合成**：手机离线的 Piper ONNX 语音角色数量少于在线时的 Gemini 语音模型。
- **图片尺寸限制**：上传的头像和配置文件图片在设备上本地压缩至 82% 质量，以契合 MongoDB 的 16MB 文件限制。
- **小票分析范围**：非常模糊、扭曲或手写的小票可能无法被系统识别。
