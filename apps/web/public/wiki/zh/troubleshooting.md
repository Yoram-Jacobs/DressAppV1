# 故障排除与常见解决方案

针对常见问题、权限设置、衣橱容量上限及 AI 密钥提示的快速实用排查方案。

## 概述
提供关于相机权限、图片处理速度、衣橱容量额度、语音设置及 AI 回退提示的速查解决方案，让您轻松无忧地享受数字穿搭管理。

## 前置要求
- 稳定的互联网连接。
- 现代网页浏览器（推荐 Google Chrome 或 Apple Safari）或 DressApp 移动端应用。

## 分步排查指南
1. **相机无法启动**：
   - 打开浏览器或手机系统设置，找到 **DressApp**，确保将 **相机** 权限设置为“允许”，然后刷新页面。
2. **出现“已达到衣橱容量上限”提示**：
   - 免费账户基础容量支持存放最多 **150 件衣物**。
   - 您可以通过邀请好友注册，每次获得 **+10 个额外奖励名额**（上限达 1,000 件），也可以清理闲置衣物，或升级至 **Pro 会员**（$4.99/月）享受无限容量。
3. **语音输入或语音朗读无声音**：
   - 检查浏览器设置中是否已授予麦克风录音权限。
   - 确保您的手机或电脑音量已开启，且未开启“静音”或“请勿打扰”模式。
4. **照片处理需要等待**：
   - 包含多件服饰的照片需要几秒钟时间，由 AI 自动抠图、透明化背景、边缘修整并识别服饰标签。该过程在后台顺畅运行，您可以继续浏览其他页面。
5. **出现“正在使用平台内置造型师（Quota Fallback）”提示**：
   - 若您配置了个人的 Google Gemini API 密钥，且该密钥触发了速率限制（`429 Too Many Requests`）或耗尽了每日配额，DressApp 将自动捕捉这一情况，并调用服务器本地的 Gemma-4-E4B 引擎顺畅生成穿搭建议。您的对话永远不会抛出硬性报错！您可随时在 Google AI Studio 检查配额，或继续免费使用内置模型。
6. **打开 Trend Scout 或 Nano Banana 修图时提示“需要 API 密钥 (403)”**：
   - Trend Scout 每日潮流咨询和 Nano Banana 图像修图为高级功能，需绑定个人的 Google Gemini API 密钥。您可前往 [Google AI Studio](https://aistudio.google.com/) 免费申请密钥，并在**个人资料** (`/me`) &rarr; **AI 配置**中填入。
7. **关联 Google 日历**：
   - 进入**个人资料** &rarr; **Google 日历**并点击**连接**，授权日历读取权限以便造型师感知您的日常行程。

## 预期效果
快速排查并解决日常使用中的疑问，确保您的数字化衣橱全天候稳定顺畅运行。

## 故障排除
- **仍有问题？** 尝试退出登录并重新登录账号，或清理浏览器缓存以刷新会话。
- **RTL 语言排版**：希伯来语和阿拉伯语界面会自动实现从右至左的镜像镜像布局，提供自然的母语阅读体验。

## 使用限制
- 从其他竞品应用批量迁移衣橱的功能仅支持桌面电脑端浏览器，无法在移动端手机上运行。
- Trend Scout 潮流频道及 Nano Banana 图像修图必须配置个人的 Google Gemini API 密钥。
