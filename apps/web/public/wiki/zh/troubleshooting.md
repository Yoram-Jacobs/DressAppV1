# 故障排除与功能限制

## 1. 免费版（Free）上传成簇衣物被拦截
- **原因：** 成簇衣物上传（`mass` 流水线——挂在衣柜或衣架上的衣服、鞋架、叠放的衬衫堆等）使用 Nano Banana。单张照片就可能耗尽免费用户的全部 AI 重建额度，因此免费版禁止使用该功能。
- **解决方法：** 在弹窗中选择 **跳过图片（Skip Image）** 并逐件上传衣物（单件抠图不消耗重建积分），或点击 **升级套餐（Upgrade Plan）** 升级至 Manager 或 Professional。

## 2. 成簇衣物上传的 5 项局限性
- **隐藏印花与精细细节：** 适用于纯色及简单的格纹、条纹，无法分析被遮挡的印花和精细细节。
- **衣物当前状态：** 重建图像很少反映衣物的当前实际折旧或褶皱状态。
- **漏检与色彩/图案幻觉：** 严重重叠的衣物可能会被跳过，AI 有时也会产生图案或颜色幻觉，且每件重建衣物均消耗重建积分。复杂衣物建议单件拍摄。

## 3. 套餐降级与仅保留最后 50 件单品规则
- **原因：** 从 Manager（200 件容量）或 Professional（300 件容量）降级至 Free 免费版（50 件容量）时，将失去额外的衣橱槽位。
- **结果：** 您的衣橱中将**仅保留最后添加的 50 件单品（最新 50 件）**，更早添加的旧衣物将被永久删除。请在确认降级前仔细阅读弹窗警告。
