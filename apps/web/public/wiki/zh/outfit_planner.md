# 穿搭计划器与画布

创作、叠穿并审查协调的搭配布局。

## 概述
穿搭计划器提供一个直观的 2D avatar 画布（同时支持用户真实身体照片抠图与动态矢量 SVG 人体模型），带有经过校准的地标偏移（`top-[14.5%]` 领口至颈线及 `top-[36.5%]` 腰带至腰线），可将上装、下装、外套和鞋履紧密叠穿在身体轮廓上。

## 前提条件
- 已保存的衣橱物品。

## 操作步骤
1. **选择画布**: 打开计划器并点击某一天或新草稿。
2. **叠穿物品**: 将服装拖放到 2D avatar 上。外套会自动叠加在内搭衬衫上方。
3. **评估合身度**: 检查兼容性得分和警告（例如颜色冲突或天气预警）。
4. **保存**: 设置标题并将造型排期到您的衣橱日记中。更新会通过 `useOutfitStore` 以线程安全的方式实时传输。

## 预期结果
优雅叠穿的穿搭组合已保存到您的日历中，并作为网格卡片预览显示，无需后台网络请求轮询循环。

## 故障排除
- **图层顺序不正确**: 请重新核实物品类别；外套必须分类为“Outerwear”才能正确叠加。
- **重复穿搭警告**: 如果人体模型发出重复穿搭警告，请检查您最近是否在同一地点穿过相同的套装。

## 局限性
- 图层根据类别标签自动管理；不支持手动 z-index 覆盖。
