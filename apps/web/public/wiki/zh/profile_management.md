# 个人资料、尺寸与配置 (`/me`)

在您的个人资料仪表板上管理身体测量数据、肤色、身体照片剪切、穿搭风格偏好、AI 模型凭证和系统集成设置。

## 概述
**个人资料与设置** 页面 (`https://dressapp.co/me`) 是您 DressApp 生态系统的中央控制枢纽。它保存着您的身体人体测量参数、数字试穿头像舞台、风格限制、本地化偏好、AI 模型密钥以及推送通知日程表。

---

## Prerequisites (前提条件)
- 一个活跃的 DressApp 账户。
- （可选）用于上传全身照片的设备相机权限。
- （可选）用于本地搭配师活动定位、文化限制和天气预报的定位权限。

---

## 步骤指南：页面自上而下概述

### 1. 页面标题与探索导航栏
位于 `/me` 仪表板的顶部：
- **标题**：显示您的账户状态和名称。
- **探索卡片**：通往应用主要板块 purchasing 的快捷方式：
  - **Trend Scout** (`/trends`)：查看每日由 AI 筛选的时尚新闻资讯。
  - **Outfits** (`/outfits`)：访问您保存的穿搭日历。
  - **Experts** (`/experts`)：浏览本地时尚搭配师和裁缝。
  - **Unpacked / Stats** (`/me/stats`)：查看衣橱估值、单次穿搭成本 (cost-per-wear) 指标和颜色分布。

### 2. 语言与语音选择卡片
显眼展示，以便立即访问：
- **语言选择器**：从 12 种支持的语言（*简体中文、英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、日语、阿拉伯语、印地语、希伯来语*）中进行选择。选择语言后会自动更新 UI 语言，并绑定默认的区域文本转语音 (TTS) 语音模型。

---

### 3. 身份与个人详细信息卡片 (`ProfileDetailsCard`)

包含 9 个可展开的手风琴面板，用于管理您的个人身份、尺寸和头像渲染：

#### 面板 A：身份
- **名字与姓氏**：个人身份识别字段。
- **电子邮件地址**：已注册电子邮件的只读显示。
- **出生日期**：用于个性化人口统计趋势评分。
- *Google 自动填充徽章*：如果您的个人资料是通过 Google OAuth 创建的，则会自动显示。

#### 面板 B：联系方式与收货地址
- **电话号码**：接收日常日程规划提案和本地专家活动短信/推送提醒所必需。
- **地址栏 1**：具有通过 OpenStreetMap (Nominatim) 进行的街道级自动填充功能。选择建议会自动填充地址栏 1、城市、省份、邮政编码和国家。
- **地址栏 2、城市、省份、邮政编码**：用于市场配送的手动地址输入字段。
- **国家**：可通过国家名称或 ISO-2 代码搜索的离线下拉组合框。

#### 面板 C：人口统计
- **性别**：选择 *Female*（女性）或 *Male*（男性）以配置基本身体测量值和衣物分类法。
- **个人状态**：选择 *Single*（单身）、*Married*（已婚）、*Divorced*（离婚）或 *Widowed*（丧偶）。
- **职业**：自由文本输入（例如 *学生*、*市场经理*、*咖啡师*）。输入至 Trend Scout 个性化排序器以优先推送相关的时尚资讯。

#### 简要指南：同步缺失的 Google 个人资料数据 (People API 重新授权)
如果您在 DressApp 请求访问您的 **People API** 个人资料详细信息（电话、地址、性别、出生日期）之前使用 Google 登录，这些字段可能会保持空白。您可以一键同步它们：

1. **打开联系信息或人口统计手风琴面板** — 您将在板块标题旁看到一个 **"Sync from Google"** 按钮（刷新图标）。
2. **点击 "Sync from Google"** — 如果在您最初登录期间未授予所需的 People API 权限范围，DressApp 会检测到此情况并显示浮动提示：*"Google 需要您的许可才能访问个人资料详细信息。您将被重定向到 Google 以授予访问权限。"*
3. **在 Google 的屏幕上授予同意** — 您将被重定向到 Google 的 OAuth 同意屏幕。勾选 **Profile info**（姓名、电子邮件、照片）和 **Contact info**（电话、地址、性别、生日）的复选框。
4. **自动返回和自动填充** — 同意后，Google 会将您重定向回 DressApp。`syncGoogleProfile()` 函数会自动运行，调用后端 `/auth/google/sync-profile` 接口，该接口将：
   - 从 Google People API 获取您的电话、地址、性别和出生日期。
   - 填充**联系信息**（电话、地址）和**人口统计**（性别、出生日期）面板中的空白字段。
   - 立即将更新保存到您的个人资料中。
5. **完成** — 您的个人资料现在已完整，无需手动输入。

> **注意**： “Sync from Google” 按钮也会出现在页面标题中（在主 “同步 Google 个人资料” 按钮旁）并且工作方式相同 — 它会一次性同步所有可用的 Google 个人资料数据。

#### 面板 D：偏好与测量单位
- **重量单位**：在千克 (`kg`) 和磅 (`lb`) 之间切换。
- **长度单位**：在厘米 (`cm`) 和英寸 (`in`) 之间切换。

#### 面板 E：照片与数字头像舞台
- **左栏 — 照片选择器**:
  - *面部照片*：上传头像缩略图。
  - *全身照片*：上传一张全身照片。系统会自动执行本地 U2-Net (`rembg`) 背景抠图处理以去除背景。
  - *删除照片按钮*：一键删除您的照片抠图，立即将试穿舞台切换回 2D SVG 矢量人体模型，无任何 UI 延迟。
- **右栏 — 数字头像与试穿舞台**:
  - **肤色选择器**：交互式调色板，用于选择您的人体模型肤色。
  - **头像试穿画布**：使用校准的标志性偏移量（衣领到领口为 `top-[14.5%]`，裤腰到腰线为 `top-[36.5%]`），在您的照片抠图或动态贝塞尔曲线矢量人体模型 (`DynamicAvatar.jsx`) 之上渲染服装。

#### 面板 F：穿搭偏好资料
- **审美风格**：逗号分隔的风格关键词（例如 *Minimalist, Streetwear, Vintage*）。
- **调色板**：首选色调（例如 *Pastels, Earth Tones, Monochrome*）。
- **避开**：要严格从 AI 推荐中排除的颜色或服装类型（例如 *Yellow, Crop Tops*）。
- **文化着装保守度**：选择保守级别（*Casual/Relaxed*、*Moderate*、*Conservative*）以引导 AI Stylist 服装覆盖范围。

#### 面板 G：身体数据与尺寸 (ANSUR II Sizing Predictor)
- **新手引导 / 全新开始模式**：输入 4 个基本数据：**Height**（身高）、**Weight**（体重）、**Waist**（腰围）和 **Foot Length**（足长）。内置的 scikit-learn ANSUR II 多输出回归模型会自动预测 6 个结构测量值：
  - *肩宽*、*胸围*、*臀围*、*袖长*、*裤内缝长 (Inseam)* 和 *裤外缝长 (Outseam)*。
- **自动尺寸转换**：一旦预测出结构测量值，确定性的尺码计算算法就会立即填充**所有标准零售尺码**，甚至细化到鞋码：
  - *休闲衬衫尺码*（根据胸围计算的 XS–XXL）。
  - *裤子腰围尺码*（由腰围厘米转换而来的英寸）。
  - *美国鞋码*（根据足长计算的男款/女款公式）。
  - *女式连衣裙尺码*（根据腰围计算的美国 0–14+ 码）。
  - *女式内衣尺码*（根据胸围/下胸围计算的罩杯和下胸围围度）。
- **详细编辑模式**：自动填充后，微调所有 15 个尺码参数（包括衬衫尺码、裤子尺码、鞋码、胸罩尺码、连衣裙尺码）和头发属性（*长度、类型、颜色、发型*）。
- **实时单位切换**：在 *kg/cm* 和 *lb/in* 之间切换 — 所有值会立即转换，无需重新预测。

#### 面板 H：专业人士与专家目录注册
- **专业搭配师开关**：注册为经过认证的时尚专业人士（搭配师、裁缝、设计师）。
- **业务详情**：输入商家名称、地址、电话、电子邮件、网站和说明，以显示在 `/experts` 目录和地区活动滚动条中。

#### 面板 I：PayPal 提现设置
- **PayPal 收款电子邮件**：输入您的 PayPal 电子邮件以接收市场销售和活跃专家活动的付款。

### 4. 系统偏好设置手风琴卡片

管理系统级设置、订阅和 AI 集成：

- **AI 配置**：
  - *标准模式*：使用系统托管的 Gemini Flash 2.x 接口。
  - *自定义 API 密钥模式*：通过引导设置窗口连接自定义 Google Gemini、Anthropic、OpenAI 或 DeepSeek API 密钥。
- **订阅与衣橱限制**：
  - 查看当前账户层级（**Free**：50 件限制 与 **Manager** 或 **Professional**：无限件）。
  - 访问**价格页面** (`/pricing` 或点击您的方案卡片) 以查看层级对比表，选择方案并订阅。
  - 通过 PayPal Subscriptions REST API（Manager：每月 $4.99；Professional：每月 $9.99）或 Atzmai 支付网关进行本地 ILS 交易升级。
  - 复制**推荐链接**：为每位注册的朋友赠送 +10 个衣橱容量位置（最多 200 件物品）。
- **日程规划与推送提醒**：
  - 切换早晨穿搭提议通知。
  - 设置频率（*每天*、*隔天*、*每周两次*、*在工作日*）、时间（例如 *07:00*）和着装风格需求（*Casual*、*Formal*、*Athletic*、*Custom*）。
  - 启用浏览器 VAPID 推送提醒。
- **推广活动通知偏好**：
  - 细粒度控制开关，包括 *Local Fashion Push/Email*、*Sale Alerts*、*Sustainable Fashion*、*Luxury Promos* 和 *Personal Stylist*。
  - 调节**最大活动距离**滑块（5 公里至 50 公里）。
- **Google Calendar 连接**：OAuth 授权按钮，用于与 AI Stylist 同步个人日历事件。
- **位置服务卡片**：切换 GPS 定位权限，以获取基于距离匹配的专家推荐和极度本地化的天气资讯。
- **邀请好友按钮**：复制可分享的推荐链接。
- **Shopping Assistant**：访问 Chrome Web Store 扩展程序详情或生成 **Universal Bookmarklet** (`javascript:...`) 以进行即时电子商务尺码对比。

## 常见问题与排除
- **照片背景未成功去除**：确保您上传的是背景光线对比明显的全身照片。
- **推送提醒未送达**：确认已启用浏览器通知权限，且在 *联系信息* 下保存了电话号码。
- **地址自动填充无响应**：检查 OpenStreetMap Nominatim 查询的网络连接是否活跃。

---

## 限制
- 免费层级的账户空间上限为 50 件物品，除非通过推荐奖励扩展（每次邀请 +10 个位置，最多 200 件物品）或升级到 Manager 或 Professional 层级。
- 自定义 API 密钥模式需要来自相应服务商的、尚有剩余配额的有效密钥。
