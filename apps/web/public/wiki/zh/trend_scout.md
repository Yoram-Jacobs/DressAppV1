# 潮流雷达与穿搭灵感（Trend Scout）

每日发现全球前沿时尚风向与本地潮流情报，一键使用自有衣橱单品即刻复刻秀场大片造型。

---

## 1. 功能概览
Trend Scout（潮流雷达）是您在 DressApp 内的每日时尚智能雷达。每天清晨，它会自动检索全球权威时尚刊物的最新秀场热评、高级定制周焦点、可持续环保面料及当代街头风格动态。

全模块分为 **7大精选频道**，根据您的画像与地理位置智能定制。依托核心功能 **“用我的衣橱复刻”（Style with My Closet）**，AI 造型师会自动拆解潮流的色彩美学与剪裁轮廓，直接从您已数字化的衣橱中匹配对应单品，无需额外添置即可紧跟全球时尚！

---

## 2. 前提条件
- **个人定制 AI 供应商 API 密钥（BYOK）**：Trend Scout 需在 **个人主页 > AI 配置** 下绑定个人 Google Gemini API 密钥（可在 [Google AI Studio](https://aistudio.google.com/) 免费申领），用于驱动实时文章检索与精炼摘要。
- **有效订阅计划**：本功能向 **Manager**（\$10/月）与 **Professional**（\$15/月）会员开放。免费账户可浏览预览版并随时升级。
- **数字化衣橱单品**：建议衣橱内至少录入 5 至 10 件衣物，以便 AI 造型师提供高匹配度的复刻穿搭方案。
- **地理位置权限**：用于准确定位您所在国家与城市的设计师发布会、本地买手店及区域时尚资讯。

---

## 3. 分步操作指南

### 第 1 步：打开潮流雷达
1. 在底部或侧边导航栏中点击 **Trend Scout**（上升趋势图标 📈）。
2. 系统将加载定位至您常住国家的每日个性化潮流资讯。

### 第 2 步：浏览 7 大精选频道
通过顶部的分类标签进行筛选：
- 📍 **本地热点（Local News）**：您所在区域的独立设计师品牌动态与买手店活动。
- 👑 **秀场直击（Runway）**：高定时装周、品牌发布会与前沿设计深度解读。
- 👟 **街头风格（Street Style）**：当代都市日常风貌、球鞋文化与潮流混搭。
- 🌿 **可持续时尚（Sustainability）**：环保纤维、循环时尚与零浪费设计。
- ✨ **名人偶像（Influencers & Icons）**：红毯造型盘点与头部创作者穿搭趋势。
- ♻️ **复古档案（Vintage / Archival）**：古着文化、中古淘货与经典丹宁档案。
- 🔧 **洗护与修护（Care & Repairs）**：贵重面料护理、衣物除皱保养与鞋履修复指南。

### 第 3 步：切换男女装视角
- 可随时通过顶部的切换按钮在 **女装潮流** 与 **男装潮流** 之间自由切换。

### 第 4 步：一键“用我的衣橱复刻”
1. 浏览到心仪的潮流卡片时，点击卡片上的 **用我的衣橱复刻** 按钮。
2. AI 造型师将立即携带该潮流的风格参数启动，展示从您衣橱中挑选的复刻搭配方案。
3. 在 2D 试衣模特上预览效果，并一键收录至您的穿搭日历中！

### 第 5 步：个性化偏好设置（设置 ⚙️）
1. 点击顶部的 **设置齿轮 ⚙️**。
2. 勾选您的偏好风格标签（如 *静奢风*、*极简主义*、*街头机能*、*老钱风* 等），点击 **保存并刷新资讯** 即可立即重塑卡片流。

### 第 6 步：阅读外媒原版长文
- 点击卡片上的 **“在 [媒体名] 阅读”**，可直接跳转至 Vogue、GQ、Elle 等官方原站阅读深度专栏。

## 4. 常见问题排查

### 页面提示“Trend Scout 需要配置自定义 API 密钥 (403)”
- **原因**：账户尚未配置个人 Google Gemini API 密钥。
- **解决方法**：前往 **个人资料 > AI 配置**，切换至自定义密钥模式，输入从 [Google AI Studio](https://aistudio.google.com/) 获取的免费密钥即可。

### 页面提示“Trend Scout 为会员专享功能”
- **解决方法**：点击 **升级计划** 订阅 Manager 或 Professional 会员方案。

---

## 5. 局限与说明
- **必须配置 API 密钥**：本功能必须配置用户的个人 Gemini API 密钥方可抓取并总结海外资讯。
- **纯粹编辑精选**：专注于穿搭审美灵感，彻底过滤推销弹窗与导购广告。
- **衣橱联动性**：AI 仅能在您已录入衣橱的衣物中进行搭配推荐。
