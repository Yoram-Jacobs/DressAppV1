# Conditions préalables et guide de configuration

Avant de plonger dans DressApp, assurez-vous que votre système est configuré pour utiliser toutes les fonctionnalités et services d'IA.

## Aperçu
Ce document couvre la configuration matérielle requise, les autorisations du navigateur et les configurations de clés API nécessaires au bon fonctionnement de l'application.

## Conditions préalables
- Un smartphone, une tablette ou un PC moderne.
- Autorisations du microphone (pour les demandes de style vocal).
- Autorisation de localisation (pour un style local tenant compte de la météo).
- Une clé API Gemini. Obtenez-la gratuitement sur [Google AI Studio](https://aistudio.google.com/).

## Étape par étape
1. **Autoriser les autorisations** : acceptez les invites de la caméra lors du téléchargement d'éléments et les invites de localisation pour les mises à jour météorologiques.
2. **Configuration de l'API Gemini** : accédez à votre profil et saisissez une clé API Gemini gratuite depuis Google AI Studio si vous souhaitez contourner les limites de la plate-forme.
3. **Lier le calendrier** : activez la synchronisation de Google Agenda pour planifier vos tenues en fonction des événements.

## Résultats attendus
Vous bénéficierez d'une reconnaissance vocale transparente, d'alertes météorologiques locales automatisées et d'une synchronisation localisée du calendrier.

## Dépannage
- **Pas de météo de localisation** : vérifiez si les services de localisation sont désactivés dans les paramètres de votre système d'exploitation ou de votre navigateur.
- **Problèmes de microphone** : assurez-vous que d'autres applications actives ne verrouillent pas l'entrée du microphone.

## Limites
- La transcription vocale locale fonctionne mieux sur les navigateurs basés sur Chromium.
