# DressAppとは？

**DressApp**へようこそ。あなたのスマートなデジタルワードローブ兼パーソナルスタイルアシスタントです。DressAppは、インテリジェントな画像認識、音声対応AIスタイリスト、そして実用的なワードローブ計画ツールを組み合わせ、毎日の服選びを快適にします。

## 主な機能

- **すぐに使えるAIスタイリング＆画像認識**: 無料アカウントは初期設定なしで**DressAppのオンプレミスAIモデル**をそのまま利用でき、**Manager**（月額$10）および**Professional**（月額$15）プランでは、より高速な**最先端AIモデル**が解放されます（オンプレミスAIモデルへの自動フォールバック機能により、スタイリングが中断されることはありません）。
- **簡単なワードローブのデジタル化＆一括アップロード**: 1着の衣類や着用中の全身コーディネートを撮影できます。**15以上のAI再構築クレジット**を保有する無料（Free）プランのユーザー（料金プランページでクレジットパックを購入可能）、および**Manager**・**Professional**プランでは、クローゼットやハンガーに掛かった服、靴棚、畳んだシャツの束をまとめて撮影できる**クラスター衣類アップロード**も利用でき、少ない写真で素早くクローゼットをデジタル化できます。
- **音声対応AIスタイリスト**: あなたのクローゼット、現地の天気、カレンダーの予定、個人の好みに合わせたコーディネート提案を、自然な音声会話で受け取れます。
- **バーチャル試着＆コーディネートプランナー**: 着替える前に、リアルな3Dダイナミックアバター（またはご自身の全身写真）の上で服を自由に組み合わせ、重ね着をシミュレーションできます。
- **トラベルスーツケースアシスタント**: 目的地の天気と旅行日程に合わせた、日別の完全なパッキングリストを自動生成します。
- **ワードローブ分析**: クローゼットの総資産価値、1回あたりの着用コスト（コスパ）、最も着用しているアイテム、カラー分布を追跡します。
- **コミュニティマーケットプレイス**: 古着の購入・販売・レンタル・交換・寄付が可能で、購入前に自分のワードローブとの相性を試着確認できます。
- **トレンドスカウト＆認定スタイリスト**: クローゼットにマッチする毎日のファッショントレンドを探したり、認定されたプロの人間のスタイリストに1対1の相談を依頼したりできます。
- **60秒のパーソナライズオンボーディング＆スターターカプセル**: ログイン前にスタイルDNAや3D/2Dアバターの体型サイズを調整し、事前登録された48点のメンズ・ウィメンズ定番アイテム（パンツ、スカート、ドレス、アバヤ、カフタン、ガラベーヤ、サリー、トーブ、クルタ、テーラードスーツなど）から選んで、天気に合わせた最初のAIコーディネートを作成できます。
