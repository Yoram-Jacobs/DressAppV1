# DressApp 概要（Overview）

DressAppは、AIを搭載したデジタルワードローブ兼パーソナルスタイリストです。

## 主な機能
- **スマートなクローゼットデジタル化：** 単一アイテムの高速切り抜き、着用コーデの自動分解、さらに革新的な**複数衣類のまとめアップロード** *（Manager・Professional限定）* により、クローゼットやハンガーに掛かった服、靴棚、畳んだシャツの山を撮影するだけで、あっという間にワードローブをデジタル化できます。
- **AIスタイリスト＆バーチャル試着：** 天気やTPO、体型に合わせたコーディネート提案とバーチャル試着。
- **柔軟なプラン体系：** Free（50着）、Manager（200着）、Professional（300着）。*（注：Freeプランへダウングレードすると、最後に追加された50着のみが保持されます）。*
