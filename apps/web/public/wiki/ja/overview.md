# DressApp へようこそ

究極のデジタルワードローブコンパニオンへようこそ！DressApp は、お手持ちのクローゼットをデジタル化して整理し、衣服の魅力を最大限に引き出すために設計されています。

## 概要
DressApp は、最先端のマルチティア AI エンジンを活用して、物理的な衣服を構造化されたデジタルアーカイブへと変換します：
- **ストレスフリーなインテリジェントスタイリング**: 350ms 未満の超高速レスポンスを誇る **Google Gemini 3.5 Flash-Lite** をメインエンジンとし、オンプレミス環境の **Gemma-4-E4B** コンテナが透過的なクォータセーフティネット（Quota Safety Net）としてバックアップします。個人の API キーを設定することなく、すぐにスマートな提案を受け取ることができます。
- **カレンダーと天気の連携**: 毎日の天気予報と個人の Google Calendar の予定に合わせた、リアルタイムの朝のスタイリング提案を提供します。
- **コーディネートプランナーとアバターキャンバス**: パーソナライズされた 2D ベクトルマネキンまたはご自身の写真切り抜きの上に、衣服をデジタルで重ね着（レイヤリング）できます。
- **インタラクティブなパッキングアシスタント**: 旅行の日数に応じた AI キュレーションによるスーツケース持ち物チェックリストを自動生成します。
- **ショッピングアシスタント**: オンラインショップ間でスマートなサイズ感やフィット感を比較できる Chrome 拡張機能およびユニバーサルブックマークレットです。
- **循環型マーケットプレイス**: 着なくなった服を出品・交換・レンタルできる、買い手と売り手の安全性を確保したプラットフォームです。

## 前提条件
- 最新の Web ブラウザ（Google Chrome、Apple Safari、または Mozilla Firefox を推奨）。
- インターネット接続環境。
- 衣服をデジタル化するためのデバイスのカメラまたは写真ライブラリへのアクセス権限。
- *（オプション）* 音声対話スタイリングを使用するためのマイク使用許可。

## ステップバイステップの手順
1. **デジタル化**: カメラで衣服を撮影するか、写真をアップロードするか、デジタルレシートを取り込みます。アプリが自動的にアイテムを切り出し、背景を透過処理します。
2. **整理**: クローゼット（Closet）ワークスペース内で衣服にタグを付け、検索し、コレクションごとにグループ化します。
3. **スタイリストへの相談**: AI Stylist をタップし、音声またはテキストで状況に応じたコーディネート提案を依頼します。
4. **計画とレイヤリング**: Outfit Canvas 上でコーディネートを組み立て、レイヤリングを確認し、ダイアリー（Diary）に予定として保存します。
5. **旅行の準備**: 目的地の今後の天気に合わせて、最適なスーツケースパッキングリストを生成します。
6. **再販・交換**: 着なくなった衣服を循環型マーケットプレイスに直接出品し、ワードローブを収益化します。

## 期待される結果
毎朝の服選びの迷いを解消し、衣類の稼働率を高め、サステナブルなファッションの選択をサポートする、構造化された使いやすいデジタルクローゼットが実現します。

## トラブルシューティング
- **ページや画像の読み込みが遅い場合**: 安定したネットワーク接続を確認してください。オフラインでキャッシュされたアイテムには引き続きアクセス可能です。
- **レイアウトの向きに関する問題**: 言語を切り替えると、DressApp は RTL 言語（ヘブライ語、アラビア語）に合わせてインターフェースの配置を自動的に左右反転します。

## 制限事項
- Free Tier（無料プラン）のクローゼット容量は初期 50 アイテムまでです（紹介ボーナスにより最大 150 アイテムまで拡張可能）。Manager または Professional プランにアップグレードすると無制限の保管が可能になります。
- 背景の切り抜きやセグメンテーションは、良好な照明とコントラストのある背景で最も高い精度を発揮します。
