# ショッピングアシスタント拡張機能

オンラインで賢く買い物をし、身体の寸法に合った正確なサイズを見つけてください。

## 概要
DressApp Shopping Assistant は、パートナー小売 Web サイト (Zara や ASOS など) と統合するブラウザ拡張機能です。衣服のページにあるサイズ表を動的に読み取り、プロファイルの測定値と比較し、最適なフィット感を瞬時に推奨します。

## 前提条件
- デスクトップの Google Chrome ブラウザ。
- プロフィール設定に身体指標 (肩、胸、ヒップ、ウエスト) を保存。
- アクティブな DressApp ユーザー アカウントの認証情報。

## ステップバイステップ
1. **インストール**: Chrome ウェブストアから DressApp 拡張機能をダウンロードしてインストールします。
2. **接続**: 拡張機能アイコンをクリックし、DressApp 認証情報を使用してログインします。
3. **閲覧**: パートナー ストア (Zara など) に移動し、商品ページを開きます。
4. **比較**: 拡張子は衣服のサイズを読み取り、一致するものを強調表示します (例: 「胸部にリラックスしたフィット感を与えるには、L のサイズをお勧めします」)。
5. **インポート**: 拡張機能ポップアップ内の [**クローゼットにインポート**] をタップして、アイテムのドラフト カードを保存します。

## 期待される結果
小売店の商品説明に正確なリアルタイムのサイズ推奨を直接表示することで、サイズの問題による返品を排除します。

## トラブルシューティング
- **推奨バッジなし**: 拡張機能のポップアップでアカウントにログインしていることを確認してください。
- **測定値が空白**: モバイル アプリのプロファイルの詳細に戻り、すべての測定フィールドに値を入力します。

## 制限事項
- サイズチャートの分析は、サポートされているパートナー ストアに限定されます。
