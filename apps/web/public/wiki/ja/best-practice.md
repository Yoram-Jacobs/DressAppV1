# DressApp はじめに：ベストプラクティスガイド

**DressApp**へようこそ！このガイドでは、服をきれいに撮影するコツ、累積型クレジットシステムを活用して効率よくクローゼットをデジタル化する方法、アイテム情報の確認ポイント、そしてパーソナルAIスタイリストから最適な提案を引き出す質問の書き方を詳しく解説します。

---

## 1. 無料AIクレジットの仕組みを理解する

無料プランでは、ワードローブのデジタル化・画像補正・スタイリングをスムーズに行えるよう、2種類の専用クレジット枠が用意されています。

| クレジットの種類 | 付与と繰り越し | 主な用途 | 消費クレジット数 |
| :--- | :--- | :--- | :--- |
| **オンプレミスAIクレジット** *(DressAppのオンプレミスAIモデル)* | **1日10クレジット無料**、最大**30日間（最大300クレジットまで）累積**し、その後リセット | 衣類スキャン、複数アイテムの自動分割、AIスタイリストとのチャット、旅行パッキング作成 | • **1着のスキャン**：1クレジット — • **複数アイテム写真のスキャン（例：5着）**：5クレジット（1着につき1） — • **AIスタイリストへの相談**：1クレジット — • **旅行パッキング**：選ばれた服1着につき1クレジット |
| **スタジオ再構築クレジット** *(最先端のAIモデル)* | **登録時に5クレジット無料付与**（料金プラン画面からいつでも追加購入可能） | スタジオ品質の衣類画像再構築、見切れた端の補正、照明・シワの美化 | • **1回のスタジオ画像補正につき1クレジット** |

> **ヒント:** **累積クレジットが初期登録に便利な理由：** **毎日10付与されるオンプレミスAIクレジット**は**30日間で最大300クレジットまで貯まる**ため、週末にまとめて服を撮影したい場合でも毎日の付与分が無駄になりません。わずか**5日間**で**50クレジット**が貯まり、無料プランの50着分のクローゼットをまるごと無料でデジタル化できます！

## 2. 衣類をきれいに撮影するベストプラクティス

写真をアップロードすると、DressAppのAIが**1着のみの写真**、**着用中の全身コーデ写真**、または**複数並べて置いた写真**のいずれかを自動判別し、背景の切り抜きや色・シルエット・スタイルの認識を行います。明るく鮮明な平置き写真を撮ることで、1回目から正確な切り抜きと色判定が可能になり、貴重な**5回分のスタジオ再構築クレジット**を本当に難しいアイテムのために温存できます。

### 複数衣類のまとめアップロード（Manager・Professionalプラン）

複数衣類のまとめアップロード（Massパイプライン）は、実際のクローゼットの中をそのまま撮影し、少ない写真枚数であっという間にワードローブをデジタル化できる革新的な機能です。以下のものを識別・再構築できます：
- **クローゼットやハンガーに掛かっている服**
- **靴棚・シューズラック**
- **畳まれたシャツや服の山**
- **まとめて置かれた複数の衣類**（ベッドの上に広げた服だけではありません！）

> **無料（Free）プランで禁止されている理由：** まとめアップロードは **Nano Banana** AI再構築を使用します。1枚の写真だけで無料ユーザーのAI再構築枠をすべて消費し、多くの服が未再構築のまま残ってしまうため、Freeユーザーはご利用いただけません。Freeユーザーがアップロードすると、**画像をスキップするかプランをアップグレードする**よう案内が表示されます。

**まとめアップロードの5つの制限事項（フォールバック）：**
1. **無地やシンプルな柄向き**：無地や非常にシンプルなチェック・ストライプ柄に適しており、隠れたプリントや細かなディテールは解析できません。
2. **服の現在の状態**：再構築された画像は実際の服の現在の状態をほとんど反映しません。
3. **一部の服がスキップされる可能性**：重なりが大きい場合、一部の服がスキップされることがあります。
4. **柄や色のハルシネーション（幻覚）**：隠れた部分の柄や色をAIが誤って補完する場合があります。
5. **再構築クレジットを消費**：再構築された服ごとに再構築クレジットを消費します。

> **プラン降格（ダウングレード）に関する注意：** ManagerまたはProfessionalユーザーがFreeプランへダウングレードすると追加スロットが失われ、**最後に追加された最新50着のみがクローゼットに残ります**。ダウングレード実行前に古いアイテムが削除される旨の警告と確認が表示されます。

### 平置き撮影の4つの黄金ルール

1. **明るい部屋とコントラストのある背景を使う**
   - 自然光が入る明るい部屋で、服を平らに広げます。
   - **服の色とコントラストがはっきり出る面**の上に置きます（例：白・クリーム・パステルカラーの服は濃い色の床やマットの上に、黒・ネイビー・濃い色の服は白いシーツや明るい面の上に置きます）。
   - 輪郭のコントラストが明確だと、AIが襟や袖、裾のラインを背景と混同せずにきれいに切り抜けます。

2. **服をまっすぐ中央に配置し、周囲に少し余白を残す**
   - シワを軽く伸ばし、袖やパンツの裾を自然に広げて全体のシルエットがわかるようにします（これにより、例えば長袖のパーカーが半袖ティーシャツと誤認されるのを防げます）。
   - 1枚の写真に複数の服を並べて撮る場合は、アイテム同士が重ならないよう少し隙間を空けてください。
   - カメラ枠の**中央にまっすぐ配置**し、襟や袖口が見切れないよう四方に**均等な小さい余白**を残します。

3. **服の上に影を落とさない**
   - シャッターを押す前に立ち位置を確認し、自分の体やスマートフォンの影が服にかからないようにします。
   - 強い影が落ちると色味が変化し（白がグレーに、ネイビーが黒に見えるなど）、素材感の判定に影響します。窓際の柔らかい自然光が最適です。

4. **カメラをしっかり固定して撮る**
   - スマートフォンを服と平行に構え、シャッターを押す瞬間は**しっかり静止**します。
   - ブレのない鮮明な写真により、DressAppのオンプレミスAIモデルが繊細な織り目（リネンとコットン、ウールとニットの違いなど）や細かい柄を正確に識別できます。

## 3. クローゼットのデジタル化：5日間スタートプラン

クローゼット全体を一度に撮影しようとすると大変に感じることがあります。手持ちの服を**5つのシンプルな日別カテゴリー（1日10着）**に分けるか、毎日棚を1段ずつ撮影して5日目にまとめてアップロードすることで、無料クレジットを使って**5日間で50着の主力ワードローブ**を完成させられます。

### プラン1：「1日10着」コツコツ登録プラン（1日10クレジット消費）

毎日数分で10着ずつアップロード・確認する方法です：

| 日目 | 対象カテゴリー | 撮影するアイテムの目安（10着） | 消費クレジット |
| :--- | :--- | :--- | :--- |
| **1日目** | **定番ボトムス** | よく履くジーンズ、チノパン、スラックス、スカート、ショートパンツなど10着 | 10クレジット |
| **2日目** | **デイリートップス＆ティーシャツ** | 定番のティーシャツ、ポロシャツ、タンクトップ、カジュアルブラウスなど10着 | 10クレジット |
| **3日目** | **シャツ・ニット・ワンピース** | ボタンシャツ、パーカー、セーター、カーディガン、ワンピースなど10着 | 10クレジット |
| **4日目** | **アウター＆羽織りもの** | ジャケット、ブレザー、コート、オーバーシャツ、ベストなど10着 | 10クレジット |
| **5日目** | **靴＆主要アクセサリー** | よく使う靴6〜7足（スニーカー、ローファー、ブーツ、パンプス等）＋ベルト・バッグ・帽子3〜4点 | 10クレジット |

### プラン2：「棚ごとに撮影」まとめ撮りプラン（5日目に50クレジット一括使用）

撮影とアプリへの登録を別々に行いたい場合は、**30日間のクレジット累積機能**を活用しましょう：

- **1〜4日目（撮影＆クレジット貯蓄）：** 毎日5分だけ時間をとり、棚1段分または1カテゴリーの服をスマートフォンのアルバムに撮影しておきます。その間、オンプレミスAIクレジットが自動的に貯まります（**10 → 20 → 30 → 40クレジット**）。
- **5日目（50着を一括アップロード）：** 5日目には残高が**50クレジット**に達します。**アイテム追加**を開き、撮影した写真を選択して、50着の主力ワードローブを一度に仕上げましょう！

## 4. アイテム編集：追加した服の情報は必ず確認しましょう

> **重要:** **AIスタイリストの提案精度は、各アイテムの登録情報に直接依存します。** 新しく追加したアイテムカードを開き、自動抽出されたタグを確認して、必要に応じて修正してから保存する習慣をつけましょう。

AIスタイリストがコーディネートを組んだり旅行の荷造りをしたりする際、毎回元の写真を再解析するのではなく、アイテムカードに保存された属性データを読み取って、着用シーンや天気に合った組み合わせを作成します。

### 新規アイテムでチェックすべき5つの項目

1. **カテゴリーとサブカテゴリー**（トップス、ボトムス、アウター、ワンピース/全身、靴、アクセサリー、伝統衣装）
   - *重要な理由：* 完成されたコーディネートには適切な上下と靴の組み合わせが必要です。ジャケットが誤って「アウター」ではなく「トップス」として登録されていると、重ね着の提案が正しく行われません。
2. **色**（メインカラーとサブカラー）
   - *重要な理由：* 室内の照明によっては、ネイビーが黒に、クリーム色が白に見えることがあります。正しい色に直しておくことで、美しいカラーコーディネートが実現します。
3. **素材 / 生地**（コットン、リネン、ウール、デニム、レザー、シルクなど）
   - *重要な理由：* 夏の猛暑には通気性の良い素材、冬には保温性の高い素材、また文化的・宗教的な行事ではマナーに適した素材を選ぶために使われます。
4. **ドレスコード / スタイル**（カジュアル、スマートカジュアル、ビジネス、フォーマル、スポーツ、フォーマル/伝統衣装）
   - *重要な理由：* 結婚式や重要な商談にスポーツウェアが提案されるといったミスマッチを防ぎます。
5. **季節と柄**（春、夏、秋、冬 • 無地、ストライプ、チェック、花柄など）
   - *重要な理由：* 柄同士の衝突を防ぎ、暖かい日に厚手の冬用コートが提案されるのを防ぎます。

## 5. スタイリスト活用術：理想の提案を引き出す質問のコツ

無料プランでのAIスタイリストへの相談は、1回につき**1オンプレミスAIクレジット**を使用します。スタイリストがどのようにメッセージを理解するかを知っておくと、1回の質問で理想のコーディネートやワードローブ診断を得られます。

### AIスタイリストが質問を理解する仕組み

1. **日本語を含む13言語に完全対応：** 自然な日本語でテキスト入力または音声会話ができます。
2. **2つのスマートモード（コーデ提案・ワードローブ診断）：**
   - **モード1 — コーデ提案（「何を着よう？」）：** 予定に合わせて*何を着るべきか*尋ねると、デジタルクローゼット内の実際の服だけを使って**1〜2パターンの全身コーディネート**を作成し、着こなしのポイントを解説します。
   - **モード2 — ワードローブ診断（「何が足りない？」）：** *どんな基本アイテムが足りない？*や*クローゼットを診断して*と尋ねると、手持ちの服のバランスを分析し、着回し力を最大化する**5〜7点の買い足し推奨アイテム**を具体的に提案します。
3. **予定・天気・マナーの自動考慮：**
   - スタイリストはメッセージから以下の4つの要素を自動的に読み取ります：
     1. **予定・シーン**（例：*採用面接、結婚式のゲスト、ディナーデート、オフィス勤務、週末の散歩*）
     2. **文化的・宗教的・地域のマナー**（例：*神社仏閣への参拝、教会や聖堂の見学、伝統行事、弔事・法事*）
     3. **天気と気温**（例：*雨で肌寒い12℃の夜、蒸し暑い晴れた午後*）
     4. **使いたい服や好みの色**（例：*ネイビーのブレザーを中心に、アースカラー、歩きやすいフラットシューズ*）

### 1クレジットで最高の回答を得る「4要素の質問フォーミュラ」

最も的確な提案を得るには、以下の4つの要素を組み合わせて質問しましょう：

> **`[1. 目的]` + `[2. 予定と場所]` + `[3. 天気・時間帯]` + `[4. 使いたいアイテムや色の好み]`**

### おすすめの質問テンプレート

#### 1. 全身コーディネートを依頼する
* **良い質問例：** *「明日の朝、金融業界のフォーマルな面接があります。涼しくて雨（12℃）の予報です。ネイビーと白を基調にしたコーディネートを組んでください。」*
* **効果的な理由：** フォーマル度、雨対策のアウター、希望のカラーパレットが明確に伝わります。

#### 2. 手持ちの特定の服を中心にコーデを組む
* **良い質問例：** *「今夜のスマートカジュアルなディナーデートに、オリーブ色のチノパンを使って何を着ればいいですか？夜は暖かい予報です。」*
* **効果的な理由：** オリーブ色のチノパンを主役に固定し、それに合うシャツ、靴、小物をバランスよく選び出します。

#### 3. 文化・宗教施設への訪問や旅行先のマナーに合わせる
* **良い質問例：** *「晴れた午後にローマの教会を見学するため、手持ちの服から礼儀正しく控えめなコーディネートを提案してください。」*
* **効果的な理由：** 露出を控えるドレスコードやマナーを自動的に適用しつつ、天気に合った快適な服装を選びます。

#### 4. クローゼットを診断して足りない基本アイテムを知る
* **良い質問例：** *「私のクローゼットを分析して、スマートカジュアルやフォーマルの着回しを増やすために買い足すべき基本アイテムを教えてください。」*
* **効果的な理由：** ワードローブ診断モードが起動し、現在のクローゼットの強みと、買い足すと最も効果的なアイテムのリストを提示します。

### よくある注意点

* **「コーデ」「助けて」のような単語だけの送信は避けましょう：** 行き先や天気を添えるだけで提案の質が劇的に向上します。
* **コーデ提案とクローゼット診断は別々のメッセージで質問しましょう：** それぞれ独立したメッセージで送ることで、両方のモードから十分な回答を得られます。
* **プロフィールを最新に保ちましょう：** **性別**、**露出度の好み**、**居住エリア**をプロフィールに保存しておけば、毎回メッセージに書かなくても自動的に反映されます！
