# サブスクリプションプラン、クレジット、およびプランのダウングレード

## 概要
DressAppは、透明性の高い3段階のサブスクリプションモデル（**Free**、**Manager**、**Professional**）と、必要な時に追加購入できる従量課金パック（Pay-As-You-Go）を提供しています。

## プラン比較
| 機能 | Free ($0) | Manager ($10/月 または $100/年) | Professional ($15/月 または $150/年) |
| :--- | :--- | :--- | :--- |
| **クローゼット最大容量** | 50着 | 200着 | 300着 |
| **AI衣類再構築** | 5回 / 月 | 50回 / 月 | 100回 / 月 |
| **複数衣類のまとめアップロード (`mass`)** | 利用不可 | 利用可能 | 利用可能 |
| **AIコーデ提案** | 5回 / 月 | 30回 / 月 | 100回 / 月 |
| **AIバーチャル試着** | 1回 / 月 | 15回 / 月 | 50回 / 月 |

## 無料（Free）プランでまとめアップロードが制限されている理由
複数衣類のまとめアップロード（`mass`パイプライン）はNano Bananaを使用して1枚の写真から多くの服を再構築します。1枚の写真だけでFreeユーザーの月間AI再構築枠（5回）をすべて消費し、多くの服が未再構築のまま残ってしまうため、**Manager**および**Professional**プラン限定となっています。

## プラン降格（ダウングレード）に関する重要な警告
**Manager**（200枠）または**Professional**（300枠）のユーザーが**Freeプラン**へダウングレード（解約）する場合：
- **追加クローゼット枠の喪失：** クローゼットの最大容量は**50着**に戻ります。
- **最後に追加された50着のみ保持：** クローゼットには**直近で追加された最新50着（last 50 added items）のみ**が残ります。
- **古い衣類データの完全削除：** 最新50着より前に追加された古い衣類アセットはすべて完全に削除されます。
- **事前の確認ダイアログ：** ダウングレードが実行される前に警告メッセージが表示され、古いアイテムが削除されることへの同意確認が求められます。
