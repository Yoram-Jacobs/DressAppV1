# 対話型 AI スタイリスト (Conversational AI Stylist)

あなたのワードローブ、現在の天気、毎日のスケジュールを熟知したインテリジェントな専属スタイリストと対話できます。

## 概要
AI Stylist は、あなた専属のファッションパートナーです。友人と会話するように、文字入力や声を出して話しかけるだけで相談できます。スタイリストは現地の天気予報を確認し、Google Calendar の予定を把握した上で、すでにお持ちの衣服の中から完成度の高いスタイリッシュなコーディネートを提案します。

DressApp のスタイリング頭脳は、堅牢なマルチティア インテリジェンス アーキテクチャによって支えられています：
- **プライマリ プロダクション エンジン (Google Gemini 3.5 Flash-Lite)**: `llm_gateway.py` を通じて、初期設定不要ですべてのコアスタイリング会話を提供します。350ms 未満の TTFT（最初の応答までの時間）という驚異的な高速レスポンスを実現し、個人の API キーを登録することなくすぐにスタイリングを開始できます。
- **オンプレミス VPS Eyes (`gemma-4-E4B`) — 無料プランおよびクォータセーフティネット (Quota Safety Net)**: Hetzner CPX32 VPS 上のポート 7860 で動作する `dressapp-eyes` コンテナ内の専用ファインチューニング済み `gemma-4-E4B` モデルです。Free Tier アカウントに対して変動費ゼロのベースラインを提供し、透過的なフォールバックとして機能します。Google Gemini API の制限（`429` / `RESOURCE_EXHAUSTED`）が発生した場合でも、エラーで停止したり 500 エラーを返すことなく、自動的にオンプレミスの Gemma へリダイレクトされます。
- **テスターグループプログラム (Tester Group Program)**: 承認されたテスターは、無制限のクローゼット容量、Trend Scout トレンドレーダー、毎日のスタイルスケジューリング、1サイクルあたり 100 クレジットが付与された **Professional プラン** を無償で利用できます。
- **カスタム BYOK クラウドモデル**: プロフィール設定でご自身の Google Gemini API キーを登録することで、上位モデル（`gemini-2.5-pro`）の利用や高度な画像生成ツール（Nano Banana 写真再構成）のロックを解除できます。

## 前提条件
- クローゼットにトップス、ボトムス、シューズがそれぞれ 1 点以上アップロードされていること。
- ハンズフリーの音声対話を使用する場合は、マイクの使用が許可されていること。
- *（オプション）* TPO に合わせた提案を受けるための Google Calendar の連携。
- *（オプション）* 自身のクラウド開発者枠を使用したい場合の個人の Google Gemini API キー。

## ステップバイステップの手順
1. **スタイリストを開く**: 画面下部ナビゲーションバーの **AI Stylist** タブをタップします。
2. **話す、または入力する**: **マイクアイコン** をタップし、着ていく服について質問します（例：*「雨の午後のランチには何を着ればいい？」*、*「シックなビジネススタイルを提案して」* など）。
3. **音声アドバイスを聞く**: スタイリストが的確なアドバイスを音声で返答し、マッチするコーディネートカードを表示します。いつでも **Play reply** をタップして音声アドバイスを再生できます。
4. **Shuffle ツールを試す**: 思いがけない発見をお探しですか？ **Shuffle** タブをタップしてクローゼットを回転させ、これまで思いつかなかった新しい組み合わせを見つけ出しましょう！
5. **継続的な対話で調整する**: スタイリストに靴の変更を依頼したり、ジャケットを別のものに変えたり、気温の変化に応じた調整を対話形式でリクエストできます。
6. **お気に入りを保存する**: **Save to Diary** をタップして、パーソナルワードローブカレンダーにコーディネートをスケジュールします。

## 期待される結果
アイテム同士がマッチする理由を説明した音声アドバイスとともに、天候に合わせたパーソナライズされたコーディネート提案が画面に表示されます。外部 API の利用枠が一時的に上限に達した場合でも、情報バナーが表示され、内蔵のオンプレミススタイリストがシームレスにリクエストを処理します。

## トラブルシューティング
- **マイクが音声を認識しない場合**: ブラウザまたはデバイスの設定を確認し、DressApp にマイクへのアクセス権限が付与されていることを確認してください。
- **同じコーディネートばかり提案される場合**: カレンダーに毎日の着用履歴を記録することで、スタイリストが最近着た服を把握し、まだ着ていない服を優先して提案するようになります。
- **「Using Platform Stylist (Quota Fallback)」バナーの表示**: 外部 API のレートリミットに達した際に表示されます。会話を途切れさせることなく、DressApp 内蔵のオンプレミス Gemma エンジンがスムーズに応答を代行しました。

## 制限事項
- スタイリストはクローゼットに登録されているアイテムのみを使用して提案します。アップロードされていないアイテムをおすすめすることはできません。
- Free Tier ユーザーには自動更新される無料スタイリングクレジットが付与されます。Pro および Tester アカウントには、より多くの月間クォータが提供されます。
