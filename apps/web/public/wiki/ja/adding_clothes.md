# 服の取り込みと追加

マルチモーダルAIスキャン、高精度な背景透過、自動画像補完により、あなたの実際のワードローブを数秒でデジタル化します。

## 概要
カメラ撮影、複数画像のギャラリーアップロード、デジタルプロダクトパスポート（DPP）QRタグ、または電子レシート（請求書OCR）から服を取り込みます。内蔵AIが背景を自動で切り抜き、ファッション属性をタグ付けし、切り抜きの完全性を評価して、隠れたり切れたりしている衣類を美しく再構築します。

## 事前準備
- 明るく鮮明な衣類の写真（鏡越しのセルフィー、全身コーディネート写真、平置き写真）。
- 衣類やQRコードをスキャンするためのカメラアクセス権限。
- オンライン購入時の電子レシートまたは請求書のスクリーンショット（PDF / PNG / JPEG）。

## ステップ・バイ・ステップ手順

1. **インタラクティブな撮影とアップロード**:
   - **アイテムを追加（Add Item）** をタップ &rarr; **写真を撮る（Take Photo）** を選択するか、端末から1枚以上のコーディネート写真をアップロードします。
   - 内蔵の重複検知機能により、過去に同じ服を登録していないかを瞬時にチェックします。
2. **AIセグメンテーションと複数アイテム同時検出**:
   - ビジョンモデルが1回の処理で複数の衣類（ジャケット、トップス、スカート、パンツ、靴、アクセサリーなど）を自動分離します。
3. **AI品質チェッカーと自動画像修復**:
   - Geminiのビジュアル品質チェッカーが切り抜かれた各アイテムを診断します：
     - **Complete（完全）**: 欠損のない衣類は直接背景透過処理されます。
     - **Image Completion（画像補完）**: バッグや腕による隠れ、切れた裾や襟がある場合、AIが不足している生地を自動でアウトペイントし補完します。
     - **Full Studio Reconstruction（フルスタジオ再構築）**: つま先しか写っていない靴など、大きく欠損しているアイテムは、完璧なスタジオカタログ写真として再生成されます。
4. **自動メタデータタグ付け**:
   - AIが20種類以上のファッション属性（カラー、素材構成、サブカテゴリー、ドレスコード、ブランド、コンディション）を自動抽出します。
5. **電子レシートとDPPタグのインポート**:
   - **デジタルインポート（Digital Import）** に切り替えて注文確認メールや請求書を読み込み、購入価格や認証サイズを記録します。
   - ラベルの **QRスキャン (DPP)** をタップして、EUデジタルプロダクトパスポートのサプライチェーン情報やケアガイドラインを取り込みます。
6. **クローゼットへ保存**:
   - **保存（Save）** をタップ。アイテムはすぐにクローゼットグリッドへ反映され、生成AIによる補完処理はバックグラウンドでシームレスに完了します。

## 期待される結果
すべての衣類が、整ったスタジオ品質の写真としてデジタルクローゼットに並び、詳細な検索属性やタグが自動付与されます。

## トラブルシューティング
- **写真で服が切れている場合**: AIが自動検知して再構築しますが、アイテム詳細カードの **写真を修復（Repair Photo）** をタップして手動でスタジオ再生成を実行することも可能です。
- **照明とコントラスト**: 暗い色の服を撮影する際は、明るくコントラストのある背景を選ぶと精度が向上します。
- **レシートOCRの認識ズレ**: レシート画像上のインタラクティブな領域選択枠を使って、特定の品目行を手動で指定できます。

## 制限事項
- 多数の高解像度一括アップロード（5アイテム超）は、ブラウザのタイムアウトを防ぎ快適な動作を保つため、非同期バックグラウンドキューで処理されます。
