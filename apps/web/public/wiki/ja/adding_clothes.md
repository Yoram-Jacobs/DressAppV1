# 服の追加（Adding Clothes）

## 概要
DressAppの**服を追加（Add Clothes）**エンジンは、写真の内容に応じて3つのインテリジェントなパイプラインを自動的に使い分けます：
1. **単一アイテム切り抜き（`single`）**：着用していない1着の服の背景を高速で削除します（再構築クレジットは消費しません）。
2. **着用コーデ分解（`worn`）**：全身のコーディネート写真から各アイテムを分離し、Nano Bananaスタジオ品質の画像に再構築します。
3. **複数衣類のまとめアップロード（`mass`）— 革新的な一括デジタル化 *（Manager・Professional限定）***：クローゼットやハンガーに掛かった服、靴棚（シューズラック）、畳んだシャツの山、ベッドに広げた服など、1枚の写真から複数のアイテムを識別してスタジオ画像に再構築します。

## まとめアップロード（クラスター）が識別できるもの
ベッドの上に服を1着ずつ広げる必要はありません！この革新的な機能により、実際のクローゼットの中をそのまま撮影し、少ない写真枚数であっという間にワードローブをデジタル化できます：
- **クローゼットやハンガーに掛かっている服**（シャツ、ジャケット、コート、ドレス、パンツなど）。
- **靴棚・シューズラック**（靴1足ペアごとに個別のフットウェアとして認識）。
- **畳まれたシャツやニット、パンツの山**。
- **ベッドや床、テーブルに並べられた複数の服**。

> **有料プラン限定機能：** 複数衣類のまとめアップロード（`mass`パイプライン）はNano Banana AI再構築を使用します。1枚のまとめ写真だけで無料（Free）ユーザーのAI再構築枠をすべて消費し、多くの服が未処理のまま残ってしまうため、**Freeプランのユーザーはまとめアップロードをご利用いただけません**。Freeユーザーが複数衣類の写真をアップロードすると、**画像をスキップ**するか**プランをアップグレード**するかを案内するメッセージが表示されます。

## まとめアップロードの5つの制限事項（フォールバック）
クローゼットを素早くデジタル化する際は、以下の5つの制限事項にご留意ください：
1. **無地やシンプルな柄向き：** 無地（ソリッド）、または非常にシンプルなチェック柄やストライプ柄に適しています。隠れたプリントや細かなディテールは解析できません。
2. **現在の服の状態は反映されません：** 再構築されたスタジオ画像は、実際の服の現在の状態（シワ、使用感、小さな汚れなど）をほとんど反映しません。
3. **一部の服がスキップされる場合があります：** 重なりが大きい服や奥に隠れている服は検出されないことがあります。
4. **柄や色のハルシネーション（幻覚）：** 隠れている部分を補完する際、AIが柄や色を誤って生成する場合があります。
5. **再構築クレジットを消費します：** 再構築された服1点につき、AI再構築クレジットを1消費します。

## 手順
1. 下部ナビゲーションバーの **+（アイテム追加）** ボタンをタップします。
2. 写真を撮影または選択します（単一アイテム、着用コーデ、またはクローゼット・靴棚のまとめ写真 — 最大10枚）。
3. **解析を開始（Start Analysis）** をタップします。
4. 抽出・再構築されたアイテムを確認し、必要に応じてタグを編集して **クローゼットに保存（Save to Closet）** をタップします。
