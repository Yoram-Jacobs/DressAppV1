# Предварительные требования и настройка

Чтобы использовать все возможности **DressApp**, рекомендуем выполнить простую начальную настройку.

---

## 1. Разрешения устройства и браузера
- **Камера**: необходима для фотографирования одежды и добавления её в гардероб.
- **Микрофон**: необходим для живого голосового общения с персональным стилистом.
- **Геолокация**: используется для подбора одежды по текущей погоде в вашем городе.

---

## 2. ИИ-модели в DressApp
DressApp работает сразу после входа без сложных технических настроек:
- **Локальная ИИ-модель DressApp**: всем пользователям доступны сканирование одежды, удаление фона и советы по стилю с помощью локальной ИИ-модели DressApp без внешних ключей.
- **Передовая ИИ-модель**: подписчики платных тарифов (или пользователи, указавшие личный ключ в Профиле) получают сверхбыстрый глубокий анализ и фотореалистичную примерку образов с помощью передовой ИИ-модели.

---

## 3. Заполнение профиля
Рекомендуем указать на экране **Профиль**:
- **Параметры и тип фигуры** (рост, вес и предпочитаемая посадка)
- **Цветотип внешности** (тон кожи, цвет волос и глаз)
- **Чёткое фото лица** (для виртуальной примерки образов на вас)
