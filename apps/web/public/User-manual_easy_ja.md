# DressApp — かんたんユーザーガイド＆マニュアル

個人向けAIファッションアシスタント兼デジタルクローゼット管理アプリ **DressApp** へようこそ！このシンプルなガイドでは、洋服を整理し、スマートな毎日のコーディネート提案を受け取り、クローゼットを最大限に活用するための全機能をステップバイステップで説明します。

---

## 1. はじめに

### DressAppとは？
DressAppは、手持ちの洋服をスマートフォンやパソコン上のスマートなデジタルクローゼットに変えるアプリです。DressAppでは以下のことができます：
- **洋服の写真を撮影**するだけで、自動で背景を切り抜き、アイテムタグを生成します。
- 天気、カレンダーの予定、個人のスタイルに合わせた**毎日のコーディネート提案**を受け取れます。
- カスタマイズ可能な2Dアバターまたは自身の体型写真を使って、**バーチャルで洋服を試着**できます。
- 服のラベルに印刷された**EUデジタル製品パスポート（DPP）**をスキャンして、環境に配慮した素材やお手入れ方法を確認できます。
- 循環型マーケットプレイスで、他のファッション好きと直接**洋服の購入、販売、交換、レンタル**ができます。

### 初期設定
1. **アプリを開く**: Google ChromeまたはApple Safariで [https://dressapp.co](https://dressapp.co) にアクセスします。
2. **権限を許可する**:
   - 服の撮影やQRスキャンのために**カメラ**アクセスを許可します。
   - ハンズフリーでAIスタイリストと会話するために**マイク**アクセスを許可します。
   - 正確な地域の天気情報とローカルなスタイリスト推奨のために**位置情報**アクセスを許可します。

## 2. ステップバイステップの手順

### ステップ1：クローゼットに服を追加する
DressAppへの洋服アイテムの追加は、素早く簡単にできます：

#### オプションA：写真を撮影またはアップロードする
1. 下部メニューから**アイテム追加**（Add Item）をタップします。
2. ハンガーにかけた状態や平らな場所に置いた服を撮影する場合は**写真を撮る**（Take Photo）を、ギャラリーから選ぶ場合は**写真をアップロード**（Upload Photos）を選択します。
3. すでに追加したアイテムと同じものがないか、アプリが自動で重複確認を行います。重複が検出された場合、スキップするかそのまま追加するか選択できます。
4. DressAppが自動的に写真の背景を削除し、色、カテゴリー、生地、着用シーンなどの詳細情報を入力します。
5. **保存**（Save）をタップすると、クローゼットのグリッドに即座にアイテムが反映されます。

#### オプションB：製品パスポート（DPP）のQRコードをスキャンする
1. アイテム追加ページで**QRスキャン (DPP)**をタップします。
2. 洋服のラベルに印刷されているQRコードをスキャンします。
3. ブランド詳細、素材構成、洗濯表示、サステナビリティスコアが自動的にインポートされます。

#### オプションC：購入レシートをインポートする
1. **デジタルインポート**（Digital Import）タブをタップします。
2. レシートのテキストを貼り付けるか、注文確認画面のスクリーンショット、またはZaraやAsosなどのPDFレシートをアップロードします。
3. AIがブランド、価格、アイテムのカテゴリーを自動的に抽出します。

---

### ステップ2：AIスタイリストと話す
今日何を着るべきか迷っていませんか？AIスタイリストがチャットでアドバイスします：

1. メニューの **AIスタイリスト**（AI Stylist）をタップします。
2. **マイクアイコン**をタップして、声に出して質問してください：
   - *"雨の日の屋外ランチには何を着ていけばいい？"*
   - *"青のデニムジャケットを使ったカジュアルなコーデを提案して。"*
3. AIスタイリストが地域の天気予報、カレンダーの予定、クローゼットのアイテムを確認し、音声でパーソナライズされたコーディネートを提案します！
4. カードの**返答を再生**（Play reply）をタップすると、いつでもスタイリストの音声を再再生できます。

---

### ステップ3：プロフィールとアバターを設定する
バーチャルアバターとスタイルの好みをカスタマイズしましょう：

1. **プロフィール**（Profile、`/me`）へ進みます。
2. **言語と音声**: 好みの言語（日本語、英語、スペイン語、フランス語、ヘブライ語、アラビア語など12言語に対応）とTTSの音声プロフィールを選択します。
3. **写真とアバター**:
   - リアルな試着のために全身写真をアップロードするか、動的な2Dベクトルマネキンを使用します。
   - インタラクティブなカラーパレットから正確な**肌のトーン**を選択します。
   - **写真を削除**（Remove Photo）をクリックすると、いつでも即座にベクトルマネキンに戻すことができます。
4. **自動体型計測＆サイズ予測**:
   - **身長**、**体重**、**ウエスト**、**足の長さ**の4つの基本数値を入力するだけです。
   - DressAppが自動的に肩幅、胸囲、ヒップ、袖丈、股下を予測します。
   - さらに、これらの数値から推奨される標準サイズ（**シャツサイズ**、**パンツサイズ**、**靴のサイズ**、女性用は**ドレス/ブラジャーのサイズ**）へ自動翻訳され、プロフィールに事前入力されます。
5. **スタイルプロフィール**: お気に入りのテイスト、好みのカラーパレット、露出度の好み（*カジュアル/リラックス*、*標準*、*コンサバティブ*）を設定します。

---

### ステップ4：コーディネートの計画とバーチャル試着
着替える前に、コーディネートのプレビューやレイヤリングを確認できます：

1. **コーディネートキャンバス**（Outfit Canvas）を開きます。
2. **2Dバーチャル試着**: トップス、ボトムス、アウター、シューズがアバター上で完璧に重なり合って表示されます。
3. **アウターのレイヤリング**: ジャケットを羽織った状態（「アウターあり」）と、その下の状態（「アウターなし」）を切り替えて確認できます。
4. **インタラクティブな詳細表示**: アバター上のアイテムをタップすると、その詳細が表示され、情報の編集が可能です。
5. **相性スコア**: カラーバランス、柄の組み合わせ、天候への適性、イベントへの適切さの調和スコアを確認できます。

---

### ステップ5：スーツケース荷造りアシスタント
旅行時の忘れ物をなくしましょう：

1. **スーツケース**（Suitcase）をタップし、目的地、旅行日程、予定しているアクティビティを入力します。
2. AIアシスタントが目的地の天候に基づいて、完全なパッキングリストと毎日のコーディネートスケジュールを作成します。
3. チャットボックスを使って調整を依頼できます（例：*"2日目の夜にフォーマルなディナードレスを追加して"*）。
4. **スーツケースを承認**（Approve Suitcase）をタップして、パッキングリストを保存します。

## 3. クイックトラブルシューティングとヒント

- **無料プランの容量制限**: 無料アカウントでは最大150アイテムまで保存できます。容量を無制限にするには、**Proプラン**（月額 $4.99）へアップグレードするか、友達を招待（招待1人につき+10枠ボーナス）してください！
- **音声入力が機能しない**: ブラウザの設定（ChromeまたはSafari推奨）でマイクのアクセス権限が許可されているか確認してください。
- **背景切り抜き**: 写真の背景を最も綺麗に削除するには、コントラストのコントラストがはっきりした壁やシーツを背景にして撮影してください。
