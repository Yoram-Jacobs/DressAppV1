# DressApp 隐私政策

**生效日期：** 2026年7月27日
**最后更新：** 2026年7月27日

本隐私政策描述了 DressApp（"我们"、"我们的"或"我们"）在您使用我们的数字衣橱和造型应用程序时如何收集、使用、存储、共享和保护您的个人信息。

请仔细阅读本政策。使用 DressApp 即表示您同意本政策中描述的数据实践。如果您不同意，请不要使用该应用程序。

## 1. 我们收集的信息

### 1.1 账户和个人资料信息
当您创建账户或通过社交登录连接时，我们会收集：

- **电子邮件地址** — 用于账户识别、身份验证和交易通信。
- **密码** — 以加密哈希形式存储；我们从不以明文形式存储密码。
- **显示名称** — 您在应用内选择的公开名称。
- **名和姓** — 通过 Google OAuth 个人资料填充或手动输入；可随时编辑。
- **电话号码** — 可选；用于账户恢复和通知。
- **出生日期** — 可选；用于年龄适当的内容过滤。
- **性别** — 可选；用于体型推荐和头像生成。
- **婚姻状况** — 可选（单身、已婚、离婚、丧偶）。
- **地址** — 可选；格式为 {地址1, 地址2, 城市, 地区, 国家, 邮政编码}。
- **首选语言和区域** — 用于本地化应用体验。
- **首选声音** — 用于 AI 造型师语音输出。
- **头像和个人资料照片** — 面部照片和身体照片，以 base64 数据 URL 形式存储在 MongoDB 中（每张限制约 500 KB，客户端侧）。
- **身体测量数据** — 身高、体重、胸围、腰围、臀围等，用于头像生成和服装合身推荐。
- **头发档案** — 长度、类型、颜色和样式（可选）。
- **家庭位置** — 城市、国家和坐标（纬度/经度），用于基于天气的造型建议和活动定位。
- **风格档案和文化背景** — 您的风格偏好和文化背景，用于个性化推荐。

### 1.2 衣橱和媒体数据
DressApp 是一个数字衣橱应用。以下数据对应用的核心功能至关重要：

- **衣橱照片** — 您上传的服装图片。这些图片在浏览器中进行背景移除（抠图）处理，然后以数据 URL 形式存储在 MongoDB 中。
- **服装元数据** — 类别（上装、下装、鞋类、外套、连衣裙、配饰）、品牌、颜色、尺寸、季节、传统、着装规范、性别和子类别标签。
- **造型数据** — 保存的服装组合，将多个衣橱单品连接在一起。
- **市场列表** — 如果您出售或交换商品，包括照片、价格和运输信息的列表详情。
- **行李箱/打包清单数据** — 旅行打包清单，包含物品、数量和用途标签（例如"徒步旅行 / 户外"）。

### 1.3 设备权限
DressApp 请求以下设备权限：

- **相机** — 用于直接在应用内拍摄服装照片。
- **照片库/文件系统访问** — 用于选择现有照片以上传。
- **地理位置** — 获取大致位置以获取天气数据并建议造型。您可以随时拒绝或撤销此权限。
- **通知** — 用于活动更新和造型师建议的可选推送通知。

### 1.4 AI 和机器学习处理
DressApp 在设备和服务器上使用 AI 用于以下目的：

- **背景移除（抠图）** — 您上传的服装照片通过 `rembg` / u2netp 流水线处理，以提取干净的裁剪图。此处理在服务器上进行。
- **体型预测** — SegFormer 模型根据全身造型照片估算身体尺寸。
- **服装分类** — 基于 CLIP 的分类为物品标记类别、颜色和品牌。
- **造型师推荐** — Google Gemini API 处理您的衣橱数据以生成造型建议和风格提示。
- **头像生成** — 根据身体测量数据计算 3D 头像形状参数，用于虚拟试穿。

**重要提示：** 用户上传的照片**不**用于训练任何机器学习模型。它们仅用于提供应用的核心功能，不会与模型训练流水线共享。

### 1.5 使用数据和分析
我们收集聚合的匿名使用数据以改进应用：

- 应用活动和功能使用模式。
- 项目交互数据（查看、编辑、删除）。
- 设备标识符（IP 地址、操作系统版本、浏览器类型）。
- 活动分析（广告展示、点击、查看）— 这些与活动 ID 关联，而非与个人用户身份关联。

我们**不**使用第三方分析 SDK（没有 Mixpanel、Firebase Analytics、Amplitude、Sentry、LogRocket 或类似工具）。所有分析均由内部处理。

### 1.6 支付数据
如果您使用 DressApp 的市场或订阅功能，我们会收集：

- **Stripe** — Stripe 账户 ID、订阅 ID 和支付意向 ID。信用卡号从未存储在我们的服务器上；由 Stripe 直接处理。
- **PayPal** — PayPal 收款人电子邮件和订单/捕获 ID。
- **Apple Pay / Google Play** — 由相应平台 SDK 处理的支付令牌；我们不存储卡详细信息。

### 1.7 第三方认证数据
- **Google OAuth** — 当您使用 Google 登录时，我们接收并存储加密的 OAuth 令牌（`google_oauth` 字段），用于访问您的 Google 个人资料（姓名、电子邮件、照片），并可选择访问 Google Calendar 和 People API 以获取日程安排和联系人功能。

## 3. 数据存储和安全

### 3.1 存储
- **数据库：** MongoDB Atlas（云托管，根据部署情况使用免费 M0 层级或付费层级）。
- **图片：** 衣橱照片以 base64 编码的数据 URL 形式存储在 MongoDB 文档中。每张图片在客户端上传前限制为约 500 KB。
- **模型缓存：** AI 模型权重（SegFormer、u2netp）存储在生产服务器上的持久 Docker 卷上，以避免每次请求时重新下载。
- **目前没有外部 blob 存储**用于图片；所有图片数据都驻留在 MongoDB 中。

### 3.2 安全
- 所有传输中的数据通过 **HTTPS/TLS 1.3** 加密。
- 密码以 **bcrypt 哈希**形式存储 — 从不以明文形式存储。
- Google OAuth 令牌在静止状态下加密存储。
- 支付数据（Stripe/PayPal 令牌）从未以明文形式存储在我们的服务器上；我们仅存储引用 ID。
- MongoDB Atlas 默认提供**静态加密**和**传输中加密**。
- 数据库访问通过连接字符串凭据限制为后端应用程序。

### 3.3 数据保留
- 您的数据在您的账户活跃期间保留。
- 账户删除后（见第 5 节），所有个人数据将在 30 天内从 MongoDB 中永久删除。
- 聚合的匿名分析数据可以无限期保留，并且无法追溯到个人用户。

## 5. 您的权利和账户删除

根据 GDPR（欧盟/欧洲经济区）、CCPA（加利福尼亚州）和其他适用的隐私法律，您拥有以下权利：

### 5.1 访问和导出
您可以通过联系我们（见第 6 节）请求我们持有的关于您的所有个人数据的副本。我们将提供您账户数据的 JSON 导出，包括衣橱物品、造型和个人资料信息。

### 5.2 纠正
您可以通过应用的"设置"页面随时更新或纠正您的个人资料信息。可编辑字段包括：显示名称、名和姓、电话、出生日期、地址、身体测量数据、家庭位置和风格偏好。

### 5.3 删除（被遗忘权）
您可以随时删除您的账户和所有关联数据：

- **在应用中：** 前往"设置" → "账户" → "删除账户"。
- **API：** 发送经过身份验证的 `POST` 请求到 `/api/v1/users/me/delete`。

账户删除会触发所有集合中的**级联删除**：
- 用户文档
- 所有衣橱物品（照片和元数据）
- 所有造型
- 所有市场列表
- 所有行李箱和打包清单
- 所有造型师会话和消息
- 所有积分充值和交易记录
- 所有嵌入数据（AI 生成的数据）
- 所有 Web 推送订阅

删除确认电子邮件将发送到您注册的电子邮件地址。

### 5.4 数据可移植性
您可以随时以结构化、机器可读的格式（JSON）请求您的数据。请使用第 6 节中的详细信息联系我们。

### 5.5 撤回同意
您可以通过设备设置或应用的"设置"页面随时撤回对位置访问、相机访问和营销通信的同意。撤回同意可能会限制某些应用功能（例如，基于天气的造型建议）。

### 5.6 反对权（LGPD 第 18 条、GDPR 第 21 条）
根据 LGPD（巴西）和 GDPR（欧盟/欧洲经济区），您有权反对将您的个人数据用于特定目的进行处理，包括：
- 基于合法利益的处理
- 直接营销
- 用户画像和自动决策（包括基于 AI 的造型师推荐）

要提出反对，请使用第 6 节中的详细信息联系我们。

### 5.7 跨境数据传输
DressApp 是一个国际应用。您的数据可能会传输并处理在您居住国以外的国家，包括以色列和美国。我们确保所有传输都受到适当的保障措施约束，包括在适用法律要求时采用标准合同条款（SCC）。

## 7. 儿童隐私

DressApp 不适用于 16 岁以下的儿童（或您所在司法管辖区适用的数字同意年龄，以较高者为准）。我们不会故意收集 16 岁以下人员的个人数据。如果我们得知未成年人向我们提供了个人数据，我们将采取措施及时删除。

如果您是父母或法定监护人，并且认为您的孩子向我们提供了个人数据，请通过 dev@dressapp.co 联系我们，我们将立即采取行动。

## 8. 国际合规

DressApp 旨在在所有国家运营。本隐私政策旨在符合以下国际数据保护框架：

| 框架 | 司法管辖区 | 涵盖的关键条款 |
|---|---|---|
| **GDPR** | 欧盟/欧洲经济区 | 法律依据、数据主体权利、DPO 联系、国际传输、违规通知 |
| **CCPA/CPRA** | 加利福尼亚州、美国 | 知情权、删除权、选择退出销售权、禁止歧视 |
| **LGPD** | 巴西 | 法律依据、数据主体权利、DPO、国际传输、同意 |
| **PIPEDA** | 加拿大 | 同意、访问、更正、问责、违规通知 |
| **POPIA** | 南非 | 合法处理、数据主体权利、跨境传输 |
| **PDPA** | 泰国 | 同意、数据主体权利、国际传输 |
| **PDPL** | 沙特阿拉伯 | 法律依据、数据主体权利、国际传输 |

当特定司法管辖区的法律要求超出本政策描述的额外权利或保护时，这些额外的权利适用。
