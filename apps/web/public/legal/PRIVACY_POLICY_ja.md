# DressApp プライバシーポリシー

**発効日：** 2026年7月27日
**最終更新：** 2026年7月27日

このプライバシーポリシーは、DressApp（「私たち」「当社」または「われわれ」）が、デジタルウォードローブおよびスタイリングアプリケーションをご利用いただく際に、どのようにあなたの個人情報を収集、使用、保存、共有および保護するかを説明するものです。

このポリシーを慎重に読んでください。DressApp を使用することで、ここに記載されたデータ慣行に同意したものとみなされます。同意いただけない場合は、アプリケーションをご利用くださいません。

## 1. 収集する情報

### 1.1 アカウントおよびプロフィール情報
アカウントを作成するか、SNSログインで接続する際、以下の情報を収集します：

- **メールアドレス** — アカウントの識別、認証およびトランザクション通知に使用します。
- **パスワード** — 暗号化ハッシュとして保存します。平文のパスワードは保存しません。
- **表示名** — アプリ内で選択した公開名です。
- **姓と名** — Google OAuth プロフィールから入力されるか、手動で入力されます。いつでも編集可能です。
- **電話番号** — 任意。アカウントの復旧および通知に使用します。
- **生年月日** — 任意。年齢に応じたコンテンツフィルタリングに使用します。
- **性別** — 任意。体型の推奨およびアバター生成に使用します。
- **婚姻状況** — 任意（独身、既婚、離婚、寡婦）。
- **住所** — 任意。{住所1, 住所2, 市区町村, 地域, 国, 郵便番号} の形式です。
- **優先言語と地域** — アプリの体験をローカライズするために使用します。
- **優先音声** — AI スタイリストの音声出力に使用します。
- **アバターおよびプロフィール写真** — 顔写真と身体写真。MongoDB に base64 データ URL として保存されます（クライアント側で各約500KBに制限）。
- **身体計測データ** — 身長、体重、胸囲、腰囲、ヒップなど、アバター生成およびフィット感の推奨に使用する計測データ。
- **髪のプロフィール** — 長さ、タイプ、色、スタイル（任意）。
- **自宅の所在地** — 市、国、および座標（緯度/経度）。天気ベースのスタイリング提案およびキャンペーンターゲティングに使用します。
- **スタイルプロファイルと文化的コンテキスト** — パーソナライズされた推奨のためのスタイル好みと文化的背景。

### 1.2 ウォードローブおよびメディアデータ
DressApp はデジタルウォードローブアプリケーションです。以下のデータはアプリの主要な機能に不可欠です：

- **ウォードローブ写真** — アップロードした衣類の画像。ブラウザ内で背景除去（マッティング）処理され、その後 MongoDB にデータ URL として保存されます。
- **衣類メタデータ** — カテゴリ（上着、下着、靴、外套、ドレス、アクセサリー）、ブランド、色、サイズ、季節、伝統、ドレスコード、性別、サブカテゴリータグ。
- **コーディネートデータ** — ウォードローブアイテムを組み合わせた保存されたスタイリング。
- **マーケットプレイスリスト** — 販売または交換する場合のリスト詳細（写真、価格、配送情報）。
- **スーツケース/パッキングリストデータ** — 旅行用のパッキングリスト。アイテム、数量、目的タグ（例：「トレッキング / アウトドア」）。

### 1.3 デバイス権限
DressApp は以下のデバイス権限をリクエストします：

- **カメラ** — アプリ内で直接衣類の写真を撮影するため。
- **フォトライブラリ/ファイルシステムアクセス** — アップロード用に既存の写真を選択するため。
- **ジオロケーション** — 天気データを取得しスタイリングを提案するための大まかな位置情報。いつでも拒否または取り消すことができます。
- **通知** — キャンペーン更新およびスタイリストの推奨のための任意のプッシュ通知。

### 1.4 AI および機械学習処理
DressApp はデバイス上およびサーバー上で以下の目的のために AI を使用します：

- **背景除去（マッティング）** — アップロードした衣類写真は `rembg` / u2netp パイプラインを通じて処理され、クリーンなカットアウトが抽出されます。この処理はサーバー上で行われます。
- **体型予測** — SegFormer モデルはフルボディのコーディネート写真から身体計測を推定します。
- **衣類分類** — CLIP ベースの分類がカテゴリ、色、ブランドでアイテムをタグ付けします。
- **スタイリストの推奨** — Google Gemini API がウォードローブデータを処理し、コーディネートの提案とスタイリングアドバイスを生成します。
- **アバター生成** — 3D アバターの形状パラメータは、バーチャル試着用に身体計測から計算されます。

**重要：** ユーザーがアップロードした写真は、**いかなる機械学習モデルのトレーニングにも使用されません**。アプリの主要機能を提供するためのみに処理され、モデルトレーニングパイプラインと共有されることはありません。

### 1.5 使用データと分析
アプリを改善するために、匿名化された集約使用データを収集します：

- アプリ活動および機能使用パターン。
- アイテムインタラクションデータ（表示、編集、削除）。
- デバイス識別子（IP アドレス、OS バージョン、ブラウザータイプ）。
- キャンペーン分析（広告インプレッション、クリック、ビュー）— キャンペーン ID に紐づけられ、個々のユーザー識別子には紐づけられません。

サードパーティの分析 SDK（Mixpanel、Firebase Analytics、Amplitude、Sentry、LogRocket など）は**使用しません**。すべての分析は内部で管理されます。

### 1.6 支払いデータ
DressApp のマーケットプレイスまたはサブスクリプション機能をご利用の場合、以下を収集します：

- **Stripe** — Stripe アカウント ID、サブスクリプション ID、支払い意向 ID。クレジットカード番号は当社のサーバーに保存されません。Stripe が直接処理します。
- **PayPal** — PayPal レシーバーのメールアドレスと注文/キャプチャ ID。
- **Apple Pay / Google Play** — 対応するプラットフォーム SDK が処理する支払いトークン。カード詳細は保存しません。

### 1.7 サードパーティ認証データ
- **Google OAuth** — Google でログインする場合、暗号化された OAuth トークン（`google_oauth` フィールド）を受信し保存します。これは Google プロフィール（名前、メール、写真）へのアクセス、およびオプションで Google Calendar と People API（スケジューリングおよび連絡先機能）へのアクセスに使用されます。

## 3. データの保存とセキュリティ

### 3.1 保存
- **データベース：** MongoDB Atlas（クラウドホスト、デプロイメントに応じて無料 M0 プランまたは有料プラン）。
- **画像：** ウォードローブ写真は MongoDB ドキュメント内に base64 エンコードされたデータ URL として保存されます。各画像はアップロード前にクライアント側で約500KBに制限されます。
- **モデルキャッシュ：** AI モデルの重み（SegFormer、u2netp）は、毎回のリクエストで再ダウンロードを回避するために、プロダクションサーバー上の永続 Docker ボリュームにキャッシュされます。
- **外部 Blob ストアは現在使用していません。** すべての画像データは MongoDB に格納されています。

### 3.2 セキュリティ
- 転送中のすべてのデータは **HTTPS/TLS 1.3** で暗号化されます。
- パスワードは **bcrypt ハッシュ** として保存されます。平文で保存することはありません。
- Google OAuth トークンは保存時に暗号化されます。
- 支払いデータ（Stripe/PayPal トークン）はサーバー上で平文で保存されることはありません。リファレンス ID のみを保存します。
- MongoDB Atlas は**保存時の暗号化**と**転送中の暗号化**をデフォルトで提供します。
- データベースへのアクセスは、接続文字列の認証情報を通じてバックエンドアプリケーションに制限されます。

### 3.3 データ保持
- データはアカウントがアクティブである間保持されます。
- アカウント削除後（第5節参照）、すべての個人データは MongoDB から30日以内に永続的に削除されます。
- 集約された匿名分析データは無期限に保持される可能性があり、個々のユーザーに紐づけることはできません。

## 5. あなたの権利とアカウント削除

GDPR（EU/EEA）、CCPA（カリフォルニア州）、およびその他の適用されるプライバシー法に基づき、以下の権利があります：

### 5.1 アクセスとエクスポート
当社が保持するあなたに関するすべての個人データのコピーをリクエストするには、連絡してください（第6節参照）。アカウントデータの JSON エクスポート（ウォードローブアイテム、コーディネート、プロフィール情報を含む）を提供します。

### 5.2 訂正
アプリの「設定」ページを通じて、いつでもプロフィール情報を更新または修正できます。編集可能なフィールドには：表示名、姓と名、電話、生年月日、住所、身体計測データ、自宅の所在地、スタイルの好みが含まれます。

### 5.3 削除（忘れられる権利）
いつでもアカウントとすべての関連データを削除できます：

- **アプリ内：** 設定 → アカウント → アカウントを削除 に移動します。
- **API：** 認証済みの `POST` リクエストを `/api/v1/users/me/delete` に送信します。

アカウント削除は、すべてのコレクションで**カスケード削除**をトリガーします：
- ユーザードキュメント
- すべてのウォードローブアイテム（写真とメタデータ）
- すべてのコーディネート
- すべてのマーケットプレイスリスト
- すべてのスーツケースとパッキングリスト
- すべてのスタイリストセッションとメッセージ
- すべてのクレジットチャージとトランザクションレコード
- すべての埋め込みデータ（AI 生成データ）
- すべての Web プッシュ購読

削除確認の電子メールが登録済みのメールアドレスに送信されます。

### 5.4 データポータビリティ
いつでも構造化された機械読み取り可能な形式（JSON）でデータをリクエストできます。第6節の詳細を使用して連絡してください。

### 5.5 同意の撤回
デバイス設定またはアプリの「設定」ページを通じて、いつでも位置情報アクセス、カメラアクセス、マーケティング通信の同意を撤回できます。同意を撤回すると、特定のアプリ機能（例：天気ベースのコーディネート提案）が制限される場合があります。

### 5.6 反対権（LGPD 第18条、GDPR 第21条）
LGPD（ブラジル）および GDPR（EU/EEA）に基づき、特定の目的での個人データの処理に反対する権利があります。具体的には：
- 正当な利益に基づく処理
- ダイレクトマーケティング
- プロファイリングおよび自動意思決定（AI ベースのスタイリスト推奨を含む）

反対するには、第6節の詳細を使用して連絡してください。

### 5.7 国際データ移転
DressApp は国際的なアプリケーションです。あなたのデータは、あなたの居住国以外の国（イスラエルおよびアメリカ合衆国を含む）に転送され、処理される場合があります。適用法が要求する場合、標準契約条項（SCC）を含む適切な保護措置を講じることにより、すべての転送を管理しています。
