# דרישות מוקדמות ומדריך התקנה

לפני השימוש ב-DressApp, ודאו שהמערכת שלכם מוגדרת לשימוש בכל התכונות ושירותי הסטיילינג.

## סקירה כללית
מסמך זה מפרט את דרישות החומרה, הרשאות הדפדפן ואפשרויות הגדרת ה-AI הדרושות להפעלת DressApp בצורה חלקה. DressApp מתוכננת לפעול מיד מהקופסה ללא צורך במפתח API כלשהו, לצד אפשרויות שילוב מתקדמות למשתמשים מקצועיים.

## דרישות מוקדמות
- סמארטפון, טאבלט או מחשב מודרני (iOS, Android, macOS, Windows, Linux).
- הרשאת מצלמה מופעלת (לצילום בגדים וסריקת תגיות DPP).
- הרשאת מיקרופון מופעלת (לבקשות סטיילינג קוליות ללא מגע).
- הרשאת מיקום (להמלצות סטיילינג מותאמות למזג האוויר המקומי).
- *(אופציונלי)* מפתח Google Gemini API בחינם אם ברצונכם להשתמש בכלים מתקדמים כמו רדאר האופנה Trend Scout, תיקון תמונות גנרטיבי Nano Banana, או מכסות ענן אישיות. משתמשי המסלול החינמי אינם צריכים מפתח API כדי להשתמש ב-DressApp.

## הוראות שלב אחר שלב
1. **אישור הרשאות**: אשרו את בקשות המצלמה בעת צילום פריטים, המיקרופון לשיחות קוליות והמיקום לקבלת תחזית מזג אוויר מקומית חיה.
2. **התחלת סטיילינג מיידית (מסלול חינם)**: החשבון שלכם מגיע מוכן לפעולה עם מודל ה-AI המובנה של DressApp המותקן מקומית (Gemma-4-E4B) ו-10 קרדיטים יומיים ללא עלות וללא צורך בהגדרה טכנית כלשהי.
3. **מפתח API אישי אופציונלי (BYOK)**: אם ברצונכם להפעיל את רדאר האופנה Trend Scout, שחזור תמונות מתקדם ב-Nano Banana או מכסות אישיות, עברו אל **פרופיל** (/me) &rarr; **הגדרות AI** והזינו את המפתח החינמי שלכם מ-[Google AI Studio](https://aistudio.google.com/).
4. **חיבור יומן Google**: חברו את יומן Google תחת הפרופיל שלכם כדי להעניק לסטייליסט מודעות לפגישות עסקיות, אירועים ואימונים קרובים.

## תוצאות צפויות
תיהנו מצילום וקליטה חלקים, הסרת רקע אוטומטית לתמונות שקופות באיכות סטודיו, ייעוץ סטיילינג קולי, התראות מזג אוויר מקומיות והמלצות לבוש המסונכרנות עם היומן.

## פתרון בעיות
- **אין נתוני מזג אוויר מקומיים**: בדקו האם שירותי המיקום מושבתים בהגדרות הדפדפן או מערכת ההפעלה.
- **בעיות מיקרופון**: ודאו שהרשאות המיקרופון מאושרות עבור DressApp ושאף יישום אחר אינו נועל את המיקרופון.
- **האם נדרש מפתח API?**: לא! משתמשי המסלול החינמי יכולים לסרוק בגדים, לארגן את הארון ולשוחח עם הסטייליסט החכם ללא שום מפתח חיצוני.

## מגבלות
- זיהוי קולי מקומי פועל בצורה המיטבית בדפדפנים מבוססי Chromium (כגון Google Chrome ו-Edge) וב-Safari.
- ערוצי האופנה של Trend Scout ושחזור תמונות ב-Nano Banana דורשים מפתח Google Gemini API אישי.
