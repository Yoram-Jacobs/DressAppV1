# דרישות מוקדמות ומדריך התקנה

לפני הצלילה ל-DressApp, ודא שהמערכת שלך מוגדרת לשימוש בכל התכונות והשירותים של AI.

## סקירה כללית
מסמך זה מכסה את דרישות החומרה, הרשאות הדפדפן והגדרות מפתח ה-API הדרושים להפעלת האפליקציה בצורה חלקה.

## דרישות מוקדמות
- סמארטפון, טאבלט או מחשב מודרני.
- הרשאות מיקרופון (לבקשות עיצוב קולי).
- הרשאת מיקום (עבור עיצוב מקומי מודע למזג האוויר).
- מפתח Gemini API. ניתן לקבל אותו בחינם ב-[Google AI Studio](https://aistudio.google.com/).

## שלב אחר שלב
1. **אפשר הרשאות**: קבל הנחיות ממצלמה בעת העלאת פריטים והודעות מיקום לעדכוני מזג אוויר.
2. **הגדרת API של Gemini**: עבור לפרופיל שלך והזן מפתח Gemini API בחינם מ-Google AI Studio אם אתה רוצה לעקוף את מגבלות הפלטפורמה.
3. **קישור יומן**: הפעל את סנכרון יומן Google כדי לקבל תכנון תלבושות מודע לאירועים.

## תוצאות צפויות
תוכלו ליהנות מזיהוי קולי חלק, התראות מזג אוויר מקומיות אוטומטיות וסנכרון לוח שנה מקומי.

## פתרון בעיות
- **ללא מזג אוויר במיקום**: בדוק אם שירותי המיקום מושבתים בהגדרות מערכת ההפעלה או הדפדפן שלך.
- **בעיות מיקרופון**: ודא שאפליקציות פעילות אחרות אינן נועלות את כניסת המיקרופון.

## מגבלות
- תמלול קול מקומי עובד בצורה הטובה ביותר בדפדפנים מבוססי Chromium.
