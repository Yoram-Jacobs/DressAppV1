# Обзор трендов и вдохновение (Trend Scout)

**Trend Scout** каждый день знакомит вас с модными тенденциями и показывает, как воплотить актуальные тренды с помощью вещей, которые уже есть в вашем шкафу.

---

## 1. Как это работает
- Листайте ленту трендов, подобранную по сезону и вашим предпочтениям.
- Нажмите на любой тренд, чтобы увидеть, какие вещи из вашего гардероба подходят для создания такого образа.
- Если для завершения образа не хватает ключевой детали, система подскажет, чем можно дополнить гардероб.
