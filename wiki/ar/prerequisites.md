# المتطلبات الأساسية ودليل الإعداد

قبل البدء في استخدام DressApp، تأكد من إعداد نظامك للاستفادة من جميع الميزات وخدمات التنسيق.

## نظرة عامة
تغطي هذه الوثيقة متطلبات الأجهزة، وأذونات المتصفح، وخيارات تكوين الذكاء الاصطناعي اللازمة لتشغيل DressApp بسلاسة. تم تصميم DressApp ليعمل فوراً دون الحاجة إلى أي مفاتيح API خارجية، مع توفير تكاملات اختيارية للمستخدمين المتقدمين.

## المتطلبات الأساسية
- هاتف ذكي حديث، جهاز لوحي، أو جهاز كمبيوتر (iOS، Android، macOS، Windows، Linux).
- تفعيل إذن الكاميرا (لتصوير الملابس ومسح علامات DPP).
- تفعيل إذن الميكروفون (لطلبات التنسيق الصوتي دون استخدام اليدين).
- إذن الموقع الجغرافي (لتوصيات التنسيق المتوافقة مع الطقس المحلي).
- *(اختياري)* مفتاح Google Gemini API إذا كنت ترغب في استخدام أدوات متقدمة مثل قنوات Trend Scout اليومية، وترميم الصور باستخدام Nano Banana، أو استخدام حصتك السحابية الخاصة. لا تحتاج الحسابات المجانية إلى أي مفتاح API لاستخدام DressApp.

## الإرشادات خطوة بخطوة
1. **السماح بالأذونات**: وافق على طلبات الكاميرا عند تصوير العناصر، والميكروفون للمحادثات الصوتية، والموقع الجغرافي للحصول على تحديثات الطقس المحلية المباشرة.
2. **بدء التنسيق فوراً (الباقة المجانية)**: حسابك مزود مسبقاً بمحرك الذكاء الاصطناعي المدمج والمثبت محلياً في DressApp ‏(Gemma-4-E4B) مع 10 أرصدة تنسيق يومية مجانية دون الحاجة لأي إعداد.
3. **مفتاح API مخصص اختياري (BYOK)**: إذا كنت ترغب في تفعيل استكشاف الصيحات Trend Scout، أو إعادة بناء الصور المتقدمة عبر Nano Banana، افتح **الملف الشخصي** (/me) &rarr; **تكوين الذكاء الاصطناعي** وأدخل مفتاحك المجاني من [Google AI Studio](https://aistudio.google.com/).
4. **ربط تقويم Google**: اربط تقويم Google الخاص بك في صفحة الملف الشخصي ليتمكن المنسق الذكي من معرفة مواعيد اجتماعات العمل، والمناسبات، والأنشطة الرياضية القادمة.

## النتائج المتوقعة
ستستمتع برقمنة سلسة للملابس، وتفريغ تلقائي للخلفيات بجودة الاستوديو، ونصائح تنسيق صوتية، وتنبيهات طقس محلية، وتوصيات أزياء متزامنة مع جدولك اليومي.

## استكشاف الأخطاء وإصلاحها
- **لا تظهر بيانات الطقس المحلية**: تحقق مما إذا كانت خدمات الموقع معطلة في إعدادات النظام أو المتصفح.
- **مشاكل الميكروفون**: تأكد من منح إذن الميكروفون لـ DressApp وعدم استخدام تطبيق آخر له بشكل حصري.
- **هل أحتاج إلى مفتاح API؟**: لا! يمكن لمستخدمي الباقة المجانية رقمنة الملابس، وتنظيم الخزانة، والتحدث مع المنسق الذكي دون توفير أي مفاتيح خارجية.

## القيود
- يعمل التعرف الصوتي المحلي بأفضل كفاءة على المتصفحات القائمة على Chromium (مثل Chrome وEdge) وSafari.
- تتطلب قنوات Trend Scout وإصلاح الصور عبر Nano Banana مفتاح Google Gemini API شخصياً.
