# Importer votre garde-robe - Guide détaillé

## Vue d'ensemble

Vous avez déjà votre garde-robe suivie dans une autre application ? Pas de problème ! DressApp facilite l'importation de vos données de garde-robe existantes pour que vous n'ayez pas à recommencer à zéro. Nous prenons en charge les importations depuis une large gamme d'applications populaires de garde-robe et de planification de tenues.

## Sources d'importation prises en charge

- **Cladwell** - Exportez votre garde-robe Cladwell et importez-la directement dans DressApp
- **Stylebook** - Transférez votre inventaire Stylebook facilement
- **Acloset** - Importez vos articles et tenues Acloset
- **SmartCloset** - Migrez vos données de garde-robe SmartCloset
- **Fichiers CSV** - Importez depuis toute application prenant en charge l'exportation CSV (format générique)
- **Autres applications** - De nombreuses autres applications de garde-robe prennent en charge l'exportation CSV, que DressApp peut importer

## Guide étape par étape

### Étape 1 : Ouvrir la page Garde-robe
Accédez à votre page **Garde-robe** dans DressApp. C'est là que apparaîtront tous vos articles importés.

### Étape 2 : Accéder à la fonction d'importation
Cherchez le bouton **Importer** sur la page Garde-robe. Il se trouve généralement dans le coin supérieur droit ou dans les options du menu.

### Étape 3 : Sélectionner l'application source
Choisissez l'application depuis laquelle vous importez dans la liste des applications prises en charge. Si votre application n'est pas listée, sélectionnez **Fichier CSV** pour une option d'importation générique.

### Étape 4 : Exporter les données de l'ancienne application
Suivez les instructions fournies pour votre application spécifique :
- **Cladwell** : Allez dans Paramètres > Exporter les données > Télécharger CSV
- **Stylebook** : Ouvrez le Menu > Exporter > Choisissez le format CSV
- **Acloset** : Accédez à Profil > Exporter la garde-robe > Télécharger
- **SmartCloset** : Allez dans Paramètres > Gestion des données > Exporter
- **Exportation CSV** : Cherchez une option d'exportation ou de téléchargement dans les paramètres de votre application

### Étape 5 : Télécharger vers DressApp
Téléchargez le fichier exporté vers DressApp. Le système va automatiquement :
- Analyser les données et mapper les champs au format de DressApp
- Catégoriser les articles selon leur type (hauts, bas, robes, etc.)
- Organiser les couleurs et les tailles
- Importer les images si disponibles

### Étape 6 : Vérifier et ajuster
Une fois l'importation terminée :
- Vérifiez vos articles sur la page Garde-robe
- Ajustez les catégories qui auraient pu être attribuées incorrectement
- Ajoutez les détails manquants (marque, prix, date d'achat)
- Supprimez les doublons ou articles de test

## Ce qui est importé

Selon l'application source, les données suivantes peuvent être importées :
- Noms et descriptions des articles
- Catégories et sous-catégories
- Couleurs et motifs
- Tailles et mesures
- Informations sur la marque
- Dates d'achat et prix
- Images des articles (si disponibles dans l'exportation)
- Historique de port (si pris en charge)

## Dépannage

### Importation échouée
- Vérifiez que le format de fichier est correct (CSV, JSON ou format spécifique à l'application)
- Assurez-vous que le fichier n'est pas corrompu ou trop volumineux
- Essayez d'exporter à nouveau depuis l'application source

### Articles manquants après l'importation
- Certains champs n'ont peut-être pas été mappés correctement
- Consultez la page des résultats d'importation pour les avertissements
- Ajoutez manuellement les articles manquants si nécessaire

### Images non importées
- Toutes les applications n'incluent pas les images dans leurs fichiers d'exportation
- Vous pouvez ajouter manuellement des images aux articles importés plus tard
- Utilisez la fonction appareil photo ou téléchargement sur la page de détails de l'article

## Conseils pour une importation réussie

1. **Nettoyez d'abord** : Supprimez les doublons et articles de test de votre ancienne application avant d'exporter
2. **Vérifiez les catégories** : Assurez-vous que les articles sont correctement catégorisés dans l'application source
3. **Vérifiez les données** : Ouvrez le fichier exporté pour confirmer qu'il contient toutes les informations attendues
4. **Commencez petit** : Si vous avez une grande garde-robe, envisagez d'importer par lots
5. **Sauvegardez d'abord** : Gardez une copie de votre fichier exporté au cas où vous devriez réimporter

## Après l'importation

Une fois votre garde-robe importée :
- **Parcourez votre Garde-robe** : Tous vos articles apparaîtront sur la page Garde-robe
- **Créez des tenues** : Commencez à mixer et assortir les articles importés
- **Obtenez des recommandations IA** : Le Styliste IA utilisera votre garde-robe importée pour les suggestions
- **Suivez l'usage** : Enregistrez quand vous portez des articles pour construire votre historique de port
- **Synchronisez entre appareils** : Votre garde-robe importée se synchronise automatiquement sur tous vos appareils
