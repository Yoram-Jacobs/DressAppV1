# 先决条件和设置指南

在深入研究 DressApp 之前，请确保您的系统已设置为利用所有 AI 功能和服务。

## 概述
本文档涵盖了顺利运行应用程序所需的硬件要求、浏览器权限和 API 密钥设置。

## 先决条件
- 现代智能手机、平板电脑或个人电脑。
- 麦克风权限（用于语音样式请求）。
- 位置许可（用于本地天气感知样式）。

## 一步一步
1. **允许权限**：接受上传物品时的相机提示，以及天气更新时的位置提示。
2. **Gemini API 设置**：如果您想绕过平台限制，请转到您的个人资料，并输入来自 Google AI Studio 的免费 G​​emini API 密钥。
3. **链接日历**：启用 Google 日历同步以获取事件感知的服装规划。

## 预期结果
您将享受无缝语音识别、自动本地天气警报和本地化日历同步。

## 故障排除
- **无位置天气**：检查您的操作系统或浏览器设置中是否禁用了位置服务。
- **麦克风问题**：确保其他活动应用程序没有锁定麦克风输入。

## 局限性
- 本地语音转录在基于 Chromium 的浏览器上效果最佳。
