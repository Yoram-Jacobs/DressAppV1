# 前置要求与设置指南

在开始使用 DressApp 之前，请确保您的设备已完成相应配置，以便充分体验所有智能造型与 AI 服务。

## 概述
本文档介绍了顺畅运行 DressApp 所需的硬件要求、浏览器权限以及 AI 配置选项。DressApp 开箱即用，无需配置任何外部 API 密钥即可直接享受完整的衣橱管理和 AI 造型，同时为进阶用户提供可选的扩展支持。

## 前置要求
- 现代智能手机、平板电脑或电脑（iOS、Android、macOS、Windows、Linux）。
- 已开启相机权限（用于拍摄衣物及扫描 DPP 标签二维码）。
- 已开启麦克风权限（用于语音免提造型咨询）。
- 位置信息权限（用于获取实时本地天气并生成穿搭建议）。
- *（可选）* 免费的 Google Gemini API 密钥：用于解锁 Trend Scout 潮流雷达、Nano Banana 图像修复或使用专属云端额度。免费账户**无需**任何 API 密钥即可使用 DressApp。

## 分步操作指南
1. **授予权限**：在拍摄衣物时允许相机访问，在语音对话时允许麦克风访问，并允许位置信息以获取当地实时天气。
2. **立即开始造型（免费层）**：您的账户已预装 DressApp 本地微调的 **Gemma-4-E4B** 智能模型，并每日获赠 10 点造型额度，零门槛即开即用。
3. **可选自定义 API 密钥（BYOK）**：如需开启 Trend Scout 全球潮流频道或 Nano Banana 高度修图，请前往**个人资料** (/me) &rarr; **AI 配置**，输入在 [Google AI Studio](https://aistudio.google.com/) 获取的免费密钥。
4. **关联 Google 日历**：在个人主页连接 Google 日历，使 AI 造型师能够感知商务会议、聚会及健身行程，量身定制得体着装。

## 预期效果
衣物快速录入、全自动无缝透明抠图、语音互动造型建议、实时天气预报以及与日程表精准同步的穿搭推荐。

## 故障排除
- **无法获取当地天气**：请检查操作系统或浏览器隐私设置中是否禁用了位置服务。
- **麦克风无响应**：请确认已授予 DressApp 麦克风权限，且无其他应用独占音频输入设备。
- **必须填写 API 密钥吗？**：完全不需要！免费层用户无需提供任何外部密钥即可直接录入衣橱、智能分类并与 AI 造型师对话。

## 使用限制
- 本地语音识别在基于 Chromium 的浏览器（Chrome、Edge）及 Safari 上表现最佳。
- Trend Scout 潮流频道及 Nano Banana 图像生成修图需要配置个人的 Google Gemini API 密钥。
