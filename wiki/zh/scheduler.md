# 上午时间表和推送提醒

通过 cron 着装提醒，自动选择早晨的着装风格。

## 概述
衣柜调度程序提供包含三种风格的服装布局的自定义早晨推送通知。它协调天气更新和日历活动，让您的造型保持清新并防止重复穿着模式。

## 先决条件
- 您的设备浏览器中允许的推送通知权限。
- 衣柜中存放的物品（至少一件上衣、下衣和鞋子）。
- 自定义 Gemini API 密钥（推荐）。

## 一步一步
1. **启用警报**：转到个人资料详细信息 -> 计划程序和推送。切换**启用通知**。
2. **设置时间**：选择您希望接收每日提醒的时间（例如，上午 07:30）。
3. **日历同步**：链接Google日历，以便系统了解您的日常活动。
4. **接收建议**：点击通知打开服装列表。
5. **确认佩戴**：选择一种布局将其保存到您的每日日记中。

## 预期结果
在您预定的时间到达的推送通知显示优化的样式选项。

## 故障排除
- **没有通知到达**：检查您的浏览器/操作系统是否具有 DressApp 的静音通知权限。
- **重复建议的服装**：在日历中填写您的穿着日记；轮换算法需要历史日志来过滤重复。

## 局限性
- 通知需要服务器上有稳定的后台互联网连接。
