# 个人资料、尺码与配置 (`/me`)

在您的个人资料仪表板上管理身体测量、肤色、全身照抠图、造型偏好、AI 模型凭据和系统集成。

## 概览
**个人资料与设置** 页面 (`https://dressapp.co/me`) 是您 DressApp 生态系统的中央控制中心。它包含您的身体人体测量参数、数字试穿舞台、风格约束、本地化偏好、AI 模型密钥和推送通知时间表。

---

## 先决条件
- 一个活跃的 DressApp 账户。
- (可选) 设备相机权限，用于上传全身照。
- (可选) 位置权限，用于本地造型师活动定位和天气预报。

---

## 分步指南：自上而下的页面概览

### 1. 页面标题栏与探索导航栏
位于 `/me` 仪表板顶部：
- **标题栏**：显示您的账户状态和标题。
- **探索卡片**：通往主要应用板块的快捷方式：
  - **趋势侦察** (`/trends`)：查看 AI 策划的每日时尚资讯流。
  - **穿搭** (`/outfits`)：访问您保存的穿搭日历。
  - **专家** (`/experts`)：浏览本地时尚造型师和裁缝。
  - **拆箱 / 统计** (`/me/stats`)：查看衣橱估值、单件成本指标和色彩分析。

### 2. 语言与语音选择卡片
显著位置显示，以便即时访问：
- **语言选择器**：从 12 种支持的语言中选择 (*英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、中文、日语、阿拉伯语、印地语、希伯来语*)。选择语言会自动更新 UI 语言环境，并绑定默认区域文本转语音 (TTS) 语音模型。

---

### 3. 身份与个人详情卡片 (`ProfileDetailsCard`)

包含 9 个可展开的手风琴面板，管理您的个人身份、尺码和头像渲染：

#### 面板 A：身份
- **名字和姓氏**：个人身份字段。
- **电子邮件地址**：您注册邮箱的只读显示。
- **出生日期**：用于个性化人口统计趋势评分。
- *Google 自动填充徽章*：如果您的资料是通过 Google OAuth 创建的，会自动显示。

#### 面板 B：联系方式与收货地址
- **电话号码**：接收每日日程安排建议和本地专家活动的 SMS/推送提醒所必需。
- **地址行 1**：提供 OpenStreetMap (Nominatim) 街道级自动补全。选择建议会自动填充第 1 行、城市、地区、邮政编码和国家。
- **地址行 2、城市、地区、邮政编码**：市场发货的手动地址字段。
- **国家**：离线可搜索组合框，按国家名称或 ISO-2 代码搜索。

#### 面板 C：人口统计
- **性别**：选择 *女性* 或 *男性* 以配置基本身体测量和服装分类。
- **个人状态**：选择 *单身*、*已婚*、*离异* 或 *丧偶*。
- **职业**：自由文本输入 (如 *学生*、*市场经理*、*咖啡师*)。为 Trend Scout 个性化排序器提供支持，以优先推送相关风格资讯。

#### 面板 D：偏好与度量单位
- **重量单位**：在千克 (`kg`) 和磅 (`lb`) 之间切换。
- **长度单位**：在厘米 (`cm`) 和英寸 (`in`) 之间切换。

#### 面板 E：照片与数字头像舞台
- **左侧栏 — 照片选择器**：
  - *面部照片*：上传头像缩略图。
  - *全身照片*：上传全身照片。系统自动执行本地 U2-Net (`rembg`) 抠图以去除背景。
  - *移除照片按钮*：单击即可移除您的照片抠图，瞬间将试穿舞台切回 2D SVG 矢量人台，零 UI 延迟。
- **右侧栏 — 数字头像与试穿舞台**：
  - **肤色选择器**：交互式调色板，选择人台肤色。
  - **头像试穿画布**：在您的照片抠图或动态贝塞尔矢量人台 (`DynamicAvatar.jsx`) 上渲染服装，使用校准的关键点偏移 (`top-[14.5%]` 衣领到领口和 `top-[36.5%]` 腰带到腰线)。

#### 面板 F：风格档案
- **美学**：逗号分隔的风格关键词 (如 *极简、街头、复古*)。
- **色彩调色板**：偏好的色调 (如 *浅色系、大地色、单色*)。
- **避免**：严格从 AI 推荐中排除的颜色或服装类型 (如 *黄色、露脐装*)。
- **文化着装保守度**：选择保守程度 (*休闲/放松*、*适中*、*保守*) 以指导 AI 造型师的服装覆盖度。

#### 面板 G：身体测量与尺码 (ANSUR II 尺码预测器)
- **引导/全新开始模式**：输入 4 项基本数据：**身高**、**体重**、**腰围** 和 **脚长**。内置的 scikit-learn ANSUR II 多输出回归模型自动预测 6 项结构测量：
  - *肩宽*、*胸围/胸围*、*臀围*、*袖长*、*裤长* 和 *外侧长*。
- **自动尺码转换**：结构测量预测后，确定性尺码算法即时填充 **所有标准零售尺码**，直到鞋码：
  - *休闲衬衫尺码* (基于胸围 XS–XXL)
  - *裤子腰围尺码* (英寸，从腰围厘米换算)
  - *美国鞋码* (男/女公式，基于脚长)
  - *女装尺码* (基于腰围 US 0–14+)
  - *女士文胸尺码* (下胸围 + 罩杯，从胸围/下胸围计算)
- **详细编辑模式**：自动填充后，微调所有 15 个尺码参数 (包括衬衫尺码、裤子尺码、鞋码、文胸尺码、裙子尺码) 和发型属性 (*长度、类型、颜色、风格*)。
- **实时单位切换**：在 *kg/cm* 和 *lb/in* 之间切换 — 所有数值即时转换，无需重新预测。

#### 面板 H：专业与专家目录注册
- **专业造型师开关**：注册为经验证的时尚专业人士 (造型师、裁缝、设计师)。
- **商业详情**：输入商业名称、地址、电话、邮箱、网站和描述，以便在 `/experts` 目录和区域活动跑马灯中显示。

#### 面板 I：PayPal 收款设置
- **PayPal 收款邮箱**：输入您的 PayPal 邮箱，以接收市场销售和活跃专家活动的付款。

### 4. 系统偏好手风琴卡片

管理系统级设置、订阅和 AI 集成：

- **AI 配置**：
  - *标准模式*：使用系统托管的 Gemini Flash 2.x 端点。
  - *自定义 API 密钥模式*：通过引导式设置模态框连接自定义 Google Gemini、Anthropic、OpenAI 或 DeepSeek API 密钥。
- **订阅与衣橱限制**：
  - 查看当前账户等级 (**免费**：150 件上限 vs **Pro**：无限件)。
  - 通过 PayPal Subscriptions REST API 升级 ($4.99/月或 $29.99/年)。
  - 复制 **推荐链接**：每邀请一位好友注册即赠送 +10 衣橱容量槽位。
- **日程安排与推送提醒**：
  - 切换早间穿搭建议通知。
  - 设置频率 (*每天*、*隔天*、*每周两次*、*仅工作日*)、时间 (如 *07:00*) 和着装要求风格 (*休闲*、*正式*、*运动*、*自定义*)。
  - 启用浏览器 VAPID 推送提醒。
- **活动通知偏好**：
  - *本地时尚推送/邮件*、*促销提醒*、*可持续时尚*、*奢侈品促销* 和 *私人造型师* 的细粒度开关。
  - 调整 **最大活动距离** 滑块 (5 公里至 50 公里)。
- **Google 日历连接**：OAuth 按钮，将个人日历事件与 AI 造型师同步。
- **位置服务卡片**：切换 GPS 权限，用于距离匹配的专家推送和超本地天气。
- **邀请好友按钮**：复制可分享的推荐链接。
- **购物助手**：访问 Chrome 网上应用店扩展详情或生成 **通用书签脚本** (`javascript:...`) 以进行即时电商尺码对比。

### 5. 账户操作与诊断
- **退出登录**：退出当前会话。
- **删除我的账户**：永久清除账户数据的链接。
- **开发者面板**：用于环境测试的诊断手风琴。

## 预期结果
- 身体指标、肤色和照片抠图在 2D 头像试穿画布上即时同步。
- 在设置面板间导航时零空闲网络请求。
- 符合您的保守度规则和日程安排的定制 AI 造型师穿搭建议。

---

## 故障排除
- **照片背景未移除**：确保上传的照片是全身照，且背景光线有对比度。
- **推送提醒未收到**：确认浏览器通知权限已启用，且 *联系方式* 下已保存电话号码。
- **地址自动补全无响应**：检查互联网连接是否处于活动状态，以便进行 OpenStreetMap Nominatim 查询。

---

## 限制
- 免费层账户空间上限为 150 件，除非通过推荐奖励 (+10 槽位/邀请) 或 Pro 订阅扩展。
- 自定义 API 密钥模式需要来自相应提供商的有效密钥且有剩余配额。
