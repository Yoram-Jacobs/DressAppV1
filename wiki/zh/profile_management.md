# 个人资料、尺寸与配置 (`/me`)

在您的个人资料控制面板中管理您的身体测量数据、肤色、全身照片扣图、造型偏好、AI模型凭据以及系统集成。

## 概述
**个人资料与设置** 页面 (`https://dressapp.co/me`) 是 DressApp 生态系统的核心控制中心。它集中管理您的身体测量参数、数字试衣阿凡达舞台、风格限制、本地化偏好、AI模型 API 密钥以及推送通知计划。

---

## 前置条件
- 一个激活的 DressApp 账户。
- （可选）用于上传全身照片的设备相机权限。
- （可选）用于获取本地造型师活动和天气预报的位置权限。

---

## 分步指南：从上至下的页面概述

### 1. 页面顶部与探索导航栏
位于 `/me` 控制面板的最顶部：
- **页眉 (Header)**：显示您的账户状态与标题。
- **探索卡片 (Explore Cards)**：快速跳转至应用主要板块：
  - **潮流侦探 (Trend Scout)** (`/trends`)：查看由 AI 每日精选的时尚新闻资讯。
  - **穿搭日历 (Outfits)** (`/outfits`)：访问您保存的穿搭日历。
  - **专家目录 (Experts)** (`/experts`)：浏览本地时尚造型师和裁缝。
  - **衣橱统计 (Stats)** (`/me/stats`)：查看衣橱估值、单次穿着成本指标及颜色分布。

### 2. 语言与语音选择卡片
显眼放置以便即时使用：
- **语言选择器 (Language Selector)**：在 12 种支持的语言中进行选择（*英语、西班牙语、法语、德语、意大利语、葡萄牙语、俄语、中文、日语、阿拉伯语、印地语、希伯来语*）。选择语言会自动更新 UI 语言，并绑定默认的区域文本转语音 (TTS) 语音模型。

---

### 3. 身份与个人信息卡片 (`ProfileDetailsCard`)

包含 9 个可展开的折叠面板，管理您的个人身份、尺寸及阿凡达渲染：

#### 面板 A：身份
- **名字与姓氏 (First Name & Last Name)**：个人身份标识字段。
- **电子邮件地址 (Email Address)**：已注册邮箱的只读显示。
- **出生日期 (Date of Birth)**：用于个性化人口统计学趋势评分。
- *Google 自动填充徽章*：如果您的资料是通过 Google OAuth 创建的，将自动显示。

#### 面板 B：联系方式与送货地址
- **电话号码 (Phone Number)**：接收每日搭配建议和本地专家活动 SMS/Push 通知所需。
- **地址第一行 (Address Line 1)**：具备 OpenStreetMap (Nominatim) 街道级自动补全功能。
- **地址第二行、城市、区域、邮政编码**：集市发货的手动地址字段。
- **国家 (Country)**：可按国家名称或 ISO-2 代码搜索的离线下拉框。

#### 面板 C：人口统计学
- **性别 (Sex)**：选择 *女性* 或 *男性* 以配置基础身体测量值和服装分类法。
- **婚姻状况**：选择 *单身*、*已婚*、*离异* 或 *丧偶*。
- **职业 (Occupation)**：自定义文本输入（如 *学生*、*市场经理*、*咖啡师*）。向 Trend Scout 推荐算法提供特征。

#### 面板 D：偏好与测量单位
- **体重单位 (Weight Unit)**：在千克 (`kg`) 和磅 (`lb`) 之间切换。
- **长度单位 (Length Unit)**：在厘米 (`cm`) 和英寸 (`in`) 之间切换。

#### 面板 E：照片与数字阿凡达舞台
- **左列 — 照片选择器**：
  - *面部照片*：上传头像缩略图。
  - *全身照片*：上传全身照片。系统会自动执行本地 U2-Net (`rembg`) 抠图以去除背景。
  - *删除照片按钮*：一键删除照片扣图，试衣舞台无缝无延迟地切换回 2D SVG 矢量人体模型。
- **右列 — 数字阿凡达与试衣舞台**：
  - **肤色选择器**：交互式调色板，用于选择人体模型的肤色。
  - **阿凡达试衣画布**：使用校准后的定位偏移（`top-[14.5%]` 领口至颈线，`top-[36.5%]` 裤腰至腰线），在照片扣图或动态贝塞尔矢量人体模型 (`DynamicAvatar.jsx`) 上渲染服装。

#### 面板 F：风格档案
- **审美偏好 (Aesthetics)**：以逗号分隔的风格关键字（如 *极简主义, 街头风, 复古*）。
- **调色板 (Color Palette)**：偏好色调（如 *柔和色, 大大地调, 单色系*）。
- **避开类型 (Avoid)**：严格从 AI 推荐中排除的颜色或服装类型。
- **着装保守度**：选择保守等级（*休闲/轻松*, *中等*, *保守*）以指导 AI 造型师服装覆盖度。

#### 面板 G：身体测量与尺寸预测 (ANSUR II 尺寸预测器)
- **新手/全新开始模式**：输入 4 项基础数据：**身高**、**体重**、**腰围** 和 **脚长**。内置的基于 scikit-learn 的 ANSUR II 多输出回归模型会自动预测 6 项结构测量值：
  - *肩宽*、*胸围*、*臀围*、*袖长*、*裤内长* 和 *裤外长*。
- **详细编辑模式**：精细调整所有 15 个尺寸参数及头发属性（*长度、类型、颜色、发型*）。

#### 面板 H：专业人士与专家目录注册
- **专业造型师开关**：注册成为认证的时尚专业人士（造型师、裁缝、设计师）。
- **商业信息**：输入商家名称、地址、电话、邮箱、网站和描述，以便显示在 `/experts` 目录中。

#### 面板 I：PayPal 收款设置
- **PayPal 收款邮箱**：输入您的 PayPal 邮箱，以接收集市销售和活动的结算款项。

## 4. 系统偏好折叠卡片

管理系统级设置、订阅及 AI 集成：

- **AI 配置 (AI Configuration)**：
  - *标准模式*：使用系统管理的 Gemini Flash 2.x 端点。
  - *自定义 API 密钥模式*：通过引导弹窗连接您自己的 Google Gemini、Anthropic、OpenAI 或 DeepSeek API 密钥。
- **订阅与衣橱容量限制**：
  - 查看当前账户层级（**免费版**：150 件上限 vs **Pro 版**：无限件数）。
  - 通过 PayPal Subscriptions REST API 升级（$4.99/月 或 $29.99/年）。
  - 复制 **邀请链接**：每成功邀请一位好友注册即可增加 +10 个衣橱槽位。
- **日程安排与推送提醒**：
  - 开启早晨穿搭建议通知。
  - 设置频率、时间和着装要求。
  - 开启浏览器 VAPID 推送提醒。
- **活动通知偏好**：
  - 精细开关 *本地时尚 Push/Email*、*折扣提醒*、*可持续时尚*、*奢品促销* 和 *私人造型师*。
  - 调整 **最大活动距离** 滑块（5km 至 50km）。
- **Google 日历关联**：OAuth 按钮，用于将个人日历事件与 AI 造型师同步。
- **位置服务卡片**：开启 GPS 位置权限以获取附近专家和本地天气。
- **邀请好友按钮**：复制可分享的邀请链接。
- **购物助手**：访问 Chrome Web Store 扩展信息或生成 **通用书签** (`javascript:...`)，用于电商购物时的实时尺寸对比。

## 5. 账户操作与诊断
- **退出登录**：退出当前会话。
- **注销账户**：永久清除账户数据的链接。
- **开发者面板**：用于环境测试的诊断折叠面板。

## 预期结果
- 身体测量指标、肤色和照片扣图在 2D 阿凡达试衣画布上即时同步。
- 在设置面板之间切换时没有不必要的网络请求。
- 符合您的保守度规则和日程安排的个性化 AI 造型师搭配建议。

---

## 故障排除
- **照片背景未成功去除**：请确保上传的照片为背景对比度良好的全身照。
- **收不到推送提醒**：请确认已开启浏览器通知权限，且在联系方式中保存了电话号码。
- **地址自动补完无响应**：请检查网络连接是否正常，以便请求 OpenStreetMap Nominatim。

---

## 限制
- 免费账户空间上限为 150 件，除非通过邀请奖励（每邀请一人 +10 槽位）或订阅 Pro 版进行扩容。
- 自定义 API 密钥模式需要来自相应提供商且尚有额度的有效密钥。
