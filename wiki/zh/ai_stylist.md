# 对话式人工智能造型师

与一位了解您的衣橱、天气和日程安排的聪明的个人造型师合作。

## 概述
AI 造型师可处理自然语言语音或文本造型查询，自动集成天气状况和日历事件。

## 先决条件
- Gemini API 密钥（或默认系统积分）。
- 连接的日历事件。

## 一步一步
1. **开始会话**：打开造型师选项卡并选择聊天、随机播放或匹配。
2. **语音输入**：点击麦克风，说出您的查询（例如“建议下雨天穿的衣服”），然后点击发送。
3. **音频播放**：通过高保真语音播放器聆听生成的造型原理。
4. **随机**：点击Sparkles按钮即可旋转老虎机；人工智能会自动将匹配的项目对准焦点。

## 预期结果
根据您的个人喜好、季节限制和日程安排定制服装布局。

## 故障排除
- **音频播放速度太慢**：在配置文件设置中在 Gemini TTS 和 Web Speech API 后备之间切换。
- **重复建议**：确保更新您的着装日历历史记录，以便轮换算法可以阻止重复穿着。

## 局限性
- 建议衣柜中至少一件上衣、一件下装和一件鞋履才能完成一套造型。
- 在不受支持的边缘设备上，语音转录可能会回退到标准文本输入。
