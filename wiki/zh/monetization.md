# 订阅方案、额度包与账单管理

全面了解您的账户额度，扩展衣橱容量，并轻松管理您的 AI 智能造型点数。

## 方案概览
DressApp 采用灵活的混合商业模式，既能满足日常衣橱整理需求，又为时尚达人、创作者及认证造型师提供了强大的专业工具：
- **免费基础版（Free Tier Baseline）**: 免费存储多达 50 件衣物（通过好友邀请奖励每位 +10 槽位，最高可扩展至 150 件）。由本地微调的 DressApp Eyes v1 模型提供开箱即用的造型支持，无需配置任何 API 密钥。
- **Manager 经理版（每月 $10 或每年 $100）**: 无限衣橱容量、早间着装排程 Push 推送、日历日程同步、循环市集转售、高级数据统计及 Trend Scout 潮流雷达筛选。
- **Professional 专业版（每月 $15 或每年 $150）**: 专为独立造型师与时尚创作者量身定制，包含赞助广告活动创建、入驻专家造型师名录、优先客服支持以及每月 100 点 AI 造型额度。
- **预付费额度包（永不过期）**: 按需充值永不过期的点数包（10 点 $3、50 点 $12、100 点 $20），满足高频穿搭建议或高清图像重建需求。

## 前提条件
- 已注册并激活的 DressApp 账户。
- 用于方案升级或额度充值的 PayPal 账户、信用卡/借记卡，或以色列本地 Bit 支付应用。

## 详细操作指南
1. **体验免费基础功能**: 开箱即用支持 50 件衣物管理。穿搭建议由内置的 DressApp Eyes v1 驱动，无需设置外部 API 密钥。
2. **通过邀请免费扩容**: 在“个人资料设置”中分享您的专属邀请链接。每邀请一位好友注册即可永久获得 +10 个衣橱槽位（最高可达 150 件）。
3. **升级至 Manager 经理版（每月 $10 或每年 $100）**: 进入“个人资料设置 > 系统偏好设置 > 衣橱与订阅限制”，点击“价格页面”解锁无限容量、早间排程提醒和日历同步。
4. **升级至 Professional 专业版（每月 $15 或每年 $150）**: 选择专业版即可创建定向时尚推广活动、入驻专家造型师目录并获得优先技术支持。
5. **购买预付费额度（永不过期）**: 如需额外额度，可选择购买 10（$3）、50（$12）或 100（$20）点额度包。系统优先消耗每月的订阅点数，永久保留充值点数。

## 预期效果
订阅成功后特权即刻生效。衣橱容量上限立刻更新为无限制，个人资料页面实时显示当前等级徽章。

## 常见问题排查
- **“已达到衣橱上限”提示**: 您已用尽可用槽位（基础 50 件或邀请扩容至 150 件）。可归档闲置衣物、邀请好友扩容（每人 +10 槽位，最多 150 件），或升级至 Manager/Professional 获得无限空间。
- **支付后额度未立即到账**: 请刷新个人资料页面；交易 Webhook 将在数秒内自动入账。
- **取消订阅**: 您可以随时在 PayPal 账户或个人资料设置中管理或取消订阅，且不会丢失已上传的衣物数据。

## 限制说明
- 免费版中邀请好友的扩容上限为 150 件衣物。
- 每月订阅包含的额度不结转至下一周期；购买的预付费额度包永久有效。
