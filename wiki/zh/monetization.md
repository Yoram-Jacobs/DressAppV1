# 订阅计划、额度充值包与账单

了解您的账户额度，扩展衣橱容量，并轻松管理您的 AI 穿搭造型点数。

## 概览
DressApp 提供灵活的混合计费模式，既满足日常衣橱整理需求，又为时尚达人、创作者和认证造型师提供强大的专业工具：
- **免费基础版（Free Tier Baseline）**: 免费存储多达 150 件衣物（通过好友邀请奖励可扩展至 1,000 件）。由本地微调的 DressApp Eyes v1 模型提供开箱即用的支持，无需配置任何 API 密钥。
- **Manager 经理版（每月 $4.99 或每年 $49.99）**: 无限衣橱容量、早间着装排程 Push 推送、日历日程同步、循环市集转售、高级数据统计及 Trend Scout 潮流雷达筛选。
- **Professional 专业版（每月 $9.99 或每年 $99.99）**: 专为独立造型师与时尚创作者量身定制，包含赞助广告活动创建、入驻专家造型师名录、优先客服支持以及每月 100 点 AI 造型额度。
- **预付费额度包（永不过期）**: 按需充值永不过期的点数包（10 点 $3、50 点 $12、100 点 $20），满足高频穿搭建议或高清图像重建需求。

## 前提条件
- 已注册的 DressApp 账户。
- 用于订阅升级或充值的 PayPal 账户、信用卡/借记卡或 Bit 应用程序。

## 操作步骤
1. **探索免费基础版**: 立即开始整理多达 150 件衣物。搭配方案直接由 DressApp Eyes v1 本地模型生成，无需 API 密钥。
2. **通过邀请免费扩容**: 在“个人资料设置”中分享您的专属邀请链接。每邀请一位好友注册即可永久获得 +10 个衣橱槽位（最高可达 1,000 件）。
3. **升级至 Manager 经理版（每月 $4.99）**: 进入“个人资料设置 > 系统偏好设置 > 衣橱与订阅限制”，点击“价格页面”解锁无限容量、早间排程提醒和日历同步。
4. **升级至 Professional 专业版（每月 $9.99）**: 选择专业版即可创建定向时尚推广活动、入驻专家造型师目录并获得优先技术支持。
5. **购买预付费额度（永不过期）**: 如需额外额度，可选择购买 10、50 或 100 点额度包。系统优先消耗每月的订阅点数，永久保留充值点数。

## 预期效果
订阅成功后特权即刻生效。衣橱容量上限立刻更新为无限制，个人资料页面实时显示当前等级徽章。

## 常见问题排查
- **“已达到衣橱上限”提示**: 您已用尽可用槽位（基础 150 件或邀请扩容至 1,000 件）。可归档闲置衣物、邀请好友扩容，或升级至 Manager/Professional 获得无限空间。
- **支付后额度未立即到账**: 请刷新个人资料页面；交易 Webhook 将在数秒内自动入账。
- **取消订阅**: 您可以随时在 PayPal 账户或个人资料设置中管理或取消订阅，且不会丢失已上传的衣物数据。

## 限制说明
- 免费版中邀请好友的扩容上限为 1,000 件衣物。
- 每月订阅包含的额度不结转至下一周期；购买的预付费额度包永久有效。
