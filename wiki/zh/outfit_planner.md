# 穿搭规划器与 2D 画布

在穿衣出门前，先在虚拟形象上自由搭配、叠穿并预览整体穿搭效果。

## 概述
穿搭规划器提供了一个交互式 2D 虚拟形象画布，您可以在上面同时试穿多件衣物。您可以在虚拟形象上预览上装、下装、鞋履和配饰，随时切换外套的显示与隐藏，并在出门前查看搭配和谐度评分。

## 前提条件
- 衣橱中已添加数字化衣物。
- *（可选）* 如果您希望在真实身材轮廓上试穿衣物，可在个人资料中上传全身照。

## 分步说明
1. **打开画布**：点击应用中的**穿搭画布**标签页。
2. **为虚拟形象穿衣**：拖放或点击衣物，将其放置在人体模型或您的全身照上：
   - **上装、外套与连衣裙**会自动贴合虚拟形象的肩宽与领口，同时完整保留袖型与衣身的原始剪裁与版型。
   - **裤装与半身裙**会根据腰型款式（高腰、中腰、休闲腰或低腰）将裤腰定位在自然腰线与臀部之间，贴合腰部与骨盆，同时保持裤腿的原始剪裁（阔腿、直筒、微喇、工装或修身）完好无损。
   - **鞋履与靴子**会自动拆分双鞋照片，使每只脚上精准穿上一只鞋。
3. **外套叠穿切换（“穿外套 / 脱外套”）**：
   - 添加夹克、开衫或大衣。
   - 使用切换按钮查看**穿外套**（外套穿在衬衫外）或**脱外套**（完整显示内搭衬衫与裤装）的效果。
4. **点击查看详情**：直接点击虚拟形象身上的任意衣物，即可打开详情卡片或替换为其他款式。
5. **检查搭配和谐度评分**：查看色彩、面料、天气适宜度及场合正式度的和谐度评分条。
6. **保存到日历**：点击**保存穿搭**，将这套造型安排在今天或未来的任意日期。

## 预期效果
逼真且层次分明的穿搭预览，彻底告别早晨出门前的穿衣纠结。

## 常见问题排查
- **大衣显示在衬衫后面**：请确保您的夹克已归类为“外套”，以便系统自动将其叠穿在内搭上衣外层。
- **虚拟形象比例不准确**：打开个人资料检查身高和体重设置，或点击“重置虚拟形象”恢复默认人体模型比例。

## 限制说明
- 外套会自动叠穿在上衣外层；特殊的自定义叠穿顺序（例如将衬衫穿在连帽卫衣外面）暂不支持手动拖拽调整。
