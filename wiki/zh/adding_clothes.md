# 录入与添加衣物

通过多模态AI扫描、智能背景擦除和自动图像补全，数秒内将您的实体衣橱数字化。

## 概览
通过实时相机拍照、相册多图上传、数字产品护照（DPP）二维码或电子小票（发票OCR）录入衣物。内置的本地AI自动抠图去背景、提取20多项时尚属性，无需任何API密钥即可生成专业白底棚拍效果图。

## 前提条件
- 衣物拍摄清晰、光线充足（全身穿搭镜面自拍、平铺照均可）。
- 授予相机使用权限以便扫描实物与二维码。
- 电商购买的电子收据或发票截图（PDF / PNG / JPEG）。
- *（可选）* 个人 Google Gemini API 密钥（若需使用 Nano Banana 生成式照片修复与补全功能）。

## 分步操作指南

1. **交互式拍照与上传**：
   - 点击 **添加单品** &rarr; 选择 **拍照** 或从设备相册上传多张照片。
   - 内置查重检测会实时判断该衣物此前是否已录入过。
2. **AI多单品智能分割**：
   - 视觉模型在单次扫描中即可自动分离不同单品（外套、上衣、裙装、裤装、鞋履、配饰）。
3. **AI智能抠图与棚拍画质**：
   - 内置图像管道自动消除杂乱背景，为所有账户输出高分辨率透明底PNG图。
4. **时尚属性自动提取**：
   - 本地AI自动识别20多项时尚元数据（主辅颜色、面料成分、细分类别、着装场合、品牌及成色）。
5. **高级生成式照片修复（Nano Banana）**：
   - 针对配置了个人 Google Gemini API 密钥的用户，Nano Banana 会检测被包包、手部遮挡或画幅边缘截断的部位，自动外绘重构缺失面料，还原完整平铺棚拍图。
6. **电子小票与DPP数字标签**：
   - 切换至 **数字导入** 即可解析订单邮件或发票，锁定购入价格与标准尺码。
   - 扫描水洗标上的 **二维码（DPP）** 即可同步欧盟数字产品护照的供应链溯源与洗涤维护指南。
7. **保存至衣橱**：
   - 点击 **保存**，单品将立即呈现在您的数字衣橱网格中。

## 预期效果
每件衣物均以居中、清晰的高清摄影图形式展示在衣橱中，附带完整的索引标签与时尚属性。

## 常见问题排查
- **照片中衣物边缘被裁剪**：请将衣物平整居中放置于对比明显的背景上。若已配置 API 密钥，Nano Banana 会自动补全裁剪掉的衣领或下摆。
- **光线与对比度**：拍摄深色衣物时，建议放置于浅色高对比度背景上以获得最佳抠图边缘。
- **发票OCR识别偏差**：可在发票图片上使用交互式选框手动框选对应商品信息行。

## 局限与说明
- 超过5件的高清大图批量上传将通过异步后台队列处理，确保网页操作流畅不卡顿。
- Nano Banana 逼真图像补全功能需用户自行提供 Google Gemini API 密钥。
