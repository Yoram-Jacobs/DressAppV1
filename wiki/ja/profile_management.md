# プロフィール、サイズ、システム構成 (`/me`)

個人プロフィールダッシュボードで、身体の寸法、肌のトーン、体型写真の切り抜き、スタイリングの好み、AI モデルの認証情報、システム連携を一元管理します。

## 概要
**プロフィール＆設定** ページ（`https://dressapp.co/me`）は、DressApp エコシステム全体の集中コントロールハブとして機能します。身体測定パラメータ、デジタル試着アバターステージ、スタイル上の制約、ローカライズ設定、AI モデルキー、プッシュ通知スケジュールなどがここに集約されています。

---

## 前提条件
- 有効な DressApp アカウント。
- （オプション）全身写真をアップロードするためのデバイスのカメラへのアクセス権限。
- （オプション）地域のスタイリストキャンペーンのターゲティング、文化的配慮、天気予報のための位置情報の利用許可。

---

## ステップバイステップガイド: ページ全体の詳細解説

### 1. ページヘッダーと「見つける」ナビゲーションバー
`/me` ダッシュボードの最上部に配置されています：
- **ヘッダー**: アカウントのステータスとタイトルを表示します。
- **探索カード (Explore Cards)**: アプリの主要セクションへのクイックショートカット：
  - **Trend Scout** (`/trends`): AI が厳選した毎日のファッションニュースフィードを表示します。
  - **Outfits** (`/outfits`): 保存したコーディネートカレンダーにアクセスします。
  - **Experts** (`/experts`): 地域のファッションスタイリストや仕立て屋を検索します。
  - **Unpacked / Stats** (`/me/stats`): ワードローブの評価額、着用 1 回あたりのコスト（cost-per-wear）、カラーの内訳を表示します。

### 2. 言語と音声の選択カード
アクセスしやすいよう目立つ位置に配置されています：
- **言語セレクター**: 12 の対応言語（*英語、スペイン語、フランス語、ドイツ語、イタリア語、ポルトガル語、ロシア語、中国語、日本語、アラビア語、ヒンディー語、ヘブライ語*）から選択できます。言語を選択すると、UI のロケールが自動的に更新され、デフォルトの地域別 Text-to-Speech (TTS) 音声モデルが適用されます。

### 3. 身元と個人情報カード (`ProfileDetailsCard`)

個人情報、サイズ、アバターレンダリングを管理する 9 つの展開可能なアコーディオンパネルで構成されています：

#### パネル A: 身元情報 (Identity)
- **名と姓 (First Name & Last Name)**: 個人を識別するための氏名入力欄。
- **メールアドレス (Email Address)**: 登録済みメールアドレスの読み取り専用表示。
- **生年月日 (Date of Birth)**: 年代に応じたトレンドスコアのパーソナライズに使用されます。
- *Google 自動入力バッジ*: Google OAuth を介してプロフィールが初期登録された場合に自動表示されます。

#### パネル B: 連絡先と配送先住所 (Contact & Delivery Address)
- **電話番号**: 毎日のスケジューラー提案や地域エキスパートのキャンペーンに関する SMS / プッシュ通知を受信するために必要です。
- **住所 1 (Address Line 1)**: OpenStreetMap (Nominatim) によるストリートレベルのリアルタイム自動補完機能を備えています。候補を選択すると、住所 1、市区町村、都道府県/地域、郵便番号、国が自動入力されます。
- **住所 2、市区町村、地域、郵便番号**: マーケットプレイスの配送用の手動住所入力フィールド。
- **国**: 国名または ISO-2 コードで検索可能なオフラインコンボボックス。

#### パネル C: 人口統計情報 (Demographics)
- **性別 (Sex)**: *女性* または *男性* を選択して、基本身体測定値と衣料品分類体系を設定します。
- **配偶者の有無 (Personal Status)**: *独身*、*既婚*、*離婚*、*死別* から選択します。
- **職業 (Occupation)**: 自由記述欄（例：*学生*、*マーケティングマネージャー*、*バリスタ*）。Trend Scout のパーソナライズランキングに反映され、関連性の高いスタイルニュースを優先表示します。

#### 要約ガイド: 不足している Google プロフィールデータの同期 (People API Re-Consent)
DressApp が **People API** プロフィール詳細（電話番号、住所、性別、生年月日）へのアクセスを要求する前に Google でサインインした場合、これらのフィールドが空のままになっていることがあります。ワンクリックでこれらを同期できます：

1. **連絡先 (Contact) または人口統計 (Demographics) アコーディオンを開く** — セクションタイトルの横に **"Sync from Google"** ボタン（更新アイコン）が表示されます。
2. **"Sync from Google" をクリックする** — 最初のサインイン時に必要な People API スコープが付与されていなかった場合、DressApp がそれを検出し、通知トーストを表示します：*「Google プロフィールの詳細にアクセスするには許可が必要です。アクセスを許可するために Google にリダイレクトされます。」*
3. **Google の画面で同意を許可する** — Google の OAuth 同意画面にリダイレクトされます。**プロフィール情報**（名前、メールアドレス、写真）および **連絡先情報**（電話番号、住所、性別、誕生日）のチェックボックスをオンにします。
4. **自動復帰と自動入力** — 同意後、Google は自動的に DressApp にリダイレクトします。`syncGoogleProfile()` 関数が自動実行され、バックエンドの `/auth/google/sync-profile` エンドポイントが呼び出されます：
   - Google People API から電話番号、住所、性別、生年月日を取得
   - **連絡先**（電話番号、住所）および **人口統計**（性別、生年月日）パネルの空のフィールドに入力
   - プロフィールの更新を即座に保存
5. **完了** — 手動で入力することなく、プロフィール情報が完成します。

> **注意**: 「Sync from Google」ボタンはページヘッダー（メインの「Sync Google Profile」ボタンの横）にも配置されており、同様に動作します。利用可能なすべての Google プロフィールデータを一度に同期できます。

#### パネル D: 設定と測定単位 (Preferences & Measurement Units)
- **体重単位**: キログラム（`kg`）とポンド（`lb`）を切り替えます。
- **長さの単位**: センチメートル（`cm`）とインチ（`in`）を切り替えます。

#### パネル E: 写真とデジタルアバターステージ (Photos & Digital Avatar Stage)
- **左列 — 写真の選択と管理**:
  - *顔写真*: アバターサムネイルをアップロードします。
  - *全身写真*: 全身写真をアップロードします。システムはローカルの U2-Net (`rembg`) マッティング処理を自動的に実行し、背景を除去します。
  - *写真削除ボタン*: 写真の切り抜きをワンクリックで削除し、UI の遅延なしに試着ステージを 2D SVG ベクトルマネキンに即座に戻します。
- **右列 — デジタルアバター＆試着ステージ**:
  - **肌のトーンピッカー**: マネキンの肌のトーンを選択するインタラクティブなカラーパレット。
  - **アバター試着キャンバス (Avatar Try-On Canvas)**: 校正されたランドマークオフセット（襟元から首回り `top-[14.5%]`、ウエストバンドからウエストライン `top-[36.5%]`）を使用して、写真の切り抜きまたは動的ベジェベクトルマネキン（`DynamicAvatar.jsx`）の上に衣服をレンダリングします。

#### パネル F: スタイルプロファイル (Style Profile)
- **好みの系統 (Aesthetics)**: カンマ区切りのスタイルキーワード（例：*Minimalist, Streetwear, Vintage*）。
- **カラーパレット (Color Palette)**: 好みの色調（例：*Pastels, Earth Tones, Monochrome*）。
- **除外したいアイテム (Avoid)**: AI の提案から厳格に除外したい色や服のタイプ（例：*Yellow, Crop Tops*）。
- **文化的・服装の保守性**: 露出度のレベル（*カジュアル/リラックス*, *標準的*, *コンサバティブ*）を選択し、AI Stylist の提案する肌の露出度を調整します。

#### パネル G: 身体測定とサイズ予測 (ANSUR II Sizing Predictor)
- **クイックスタート / 初期設定モード**: **身長**、**体重**、**ウエスト囲**、**足の長さ** の 4 つの基本項目を入力します。組み込みの scikit-learn ANSUR II 多目的回帰モデルが、6 つの構造的測定値を自動的に予測します：
  - *肩幅*、*チェスト / バスト*、*ヒップ*、*袖丈*、*股下 (Inseam)*、*総丈 (Outseam)*。
- **自動サイズ換算**: 構造的測定値が予測されると、決定論的サイズアルゴリズムにより、靴のサイズに至るまで **すべての標準小売サイズ** が即座に入力されます：
  - *カジュアルシャツサイズ*（胸囲に基づく XS–XXL）
  - *パンツのウエストサイズ*（ウエストの cm をインチに換算）
  - *US シューズサイズ*（足の長さから算出されるメンズ/ウィメンズ公式）
  - *レディースドレスサイズ*（ウエストに基づく US 0–14+）
  - *レディースブラサイズ*（バストとアンダーバストから計算されるアンダー＋カップ）
- **詳細編集モード**: 自動入力後、15 のすべてのサイズパラメータ（シャツ、パンツ、靴、ブラ、ドレスサイズを含む）およびヘア属性（*長さ、タイプ、カラー、スタイル*）を微調整できます。
- **リアルタイム単位切り替え**: *kg/cm* と *lb/in* を自由に切り替え可能 — すべての値が再予測なしで即座に換算されます。

#### パネル H: プロフェッショナル＆エキスパートディレクトリ登録
- **プロスタイリスト登録トグル**: 認定ファッションプロフェッショナル（スタイリスト、仕立て屋、デザイナー）として登録します。
- **ビジネス情報**: 屋号・事業所名、住所、電話番号、メールアドレス、ウェブサイト、説明文を入力すると、`/experts` ディレクトリおよび地域のキャンペーンティッカーに掲載されます。

#### パネル I: PayPal 出金設定
- **PayPal 受信用メールアドレス**: マーケットプレイスでの売上金やアクティブなエキスパートキャンペーンの報酬を受け取るための PayPal メールアドレスを入力します。

### 4. システム設定アコーディオンカード (System Preferences)

システムレベルの設定、サブスクリプション、AI 連携を管理します：

- **AI 構成**:
  - *標準モード（プライマリ プロダクション エンジン）*: `llm_gateway.py` を経由した **Google Gemini 3.5 Flash-Lite** を搭載。個人の API キーの設定なしで、超高速なスタイリングを提供します。
  - *オンプレミス クォータセーフティネット (Quota Safety Net)*: クラウドの利用上限（`429` / `RESOURCE_EXHAUSTED`）に達した場合、リクエストはポート 7860 でセルフホストされているファインチューニング済み **Gemma-4-E4B** コンテナへ自動的にフォールバックされ、スタイリングの会話が途切れることはありません。
  - *カスタム API キーモード (BYOK)*: ご自身の Google Gemini API キーを連携させることで、高度な開発者向けクォータや、Trend Scout デイリーレーダー、Nano Banana 写真再構成などのクラウド画像生成ツールを利用できます。
- **サブスクリプションとクローゼット制限**:
  - 現在のアカウントプランを表示します（**Free**: 基本 50 アイテム制限、**Manager**（月額 $10）または **Professional**（月額 $15）: アイテム数無制限）。
  - **テスターグループプログラム**: 承認されたテスターメールアドレス（`maystarboard@gmail.com`、`lokoprod@gmail.com`、`dressapdeveloper@gmail.com`）は、サブスクリプション料金なしで **Professional プラン** の特権を自動的に無償で利用できます。
  - **Pricing（料金）ページ**（`/pricing` またはプランカードをクリック）にアクセスして、プラン比較表の確認、プランの変更、有効期限のない前払いクレジットパックの購入を行えます。
  - PayPal サブスクリプションまたはイスラエル現地向けの Atzmai ゲートウェイ（Bit / クレジットカード）による決済に対応。
  - **紹介リンク** のコピー: 友人が 1 人登録するごとに、クローゼット容量が +10 枠付与されます（最大 150 アイテムまで）。
- **スケジューラーとプッシュ通知**:
  - 毎朝のコーディネート提案通知のオン/オフ。
  - 配信頻度（*毎日*、*1日おき*、*週2回*、*平日のみ*）、時間（例：*07:00*）、ドレスコードスタイル（*カジュアル*、*フォーマル*、*アスレチック*、*カスタム*）の設定。
  - ブラウザの VAPID プッシュ通知を有効化。
- **キャンペーン通知設定**:
  - *地域のファッションプッシュ/メール*、*セールアラート*、*サステナブルファッション*、*ラグジュアリープロモーション*、*パーソナルスタイリスト* の詳細な切り替え。
  - **最大キャンペーン距離** スライダーの調整（5km 〜 50km）。
- **Google Calendar 連携**: 個人のカレンダーの予定を AI Stylist と同期するための OAuth 認証ボタン。
- **位置情報サービスカード**: 距離に応じたエキスパート一覧の取得や超地域特化型の天気予報を取得するための GPS 位置情報の許可。
- **友達を招待ボタン**: 共有可能な紹介リンクをコピーします。
- **ショッピングアシスタント**: Chrome ウェブストアの拡張機能の詳細を確認するか、EC サイトでの即時サイズ比較が可能な **ユニバーサルブックマークレット**（`javascript:...`）を生成します。

## 期待される結果
- 身体の測定値、肌のトーン、写真の切り抜きが、2D アバター試着キャンバスに即座に同期されます。

- あなたの露出度の基準やスケジュールに合わせた、カスタマイズされた AI Stylist のコーディネート提案が行われます。

## トラブルシューティング
- **写真の背景が除去されない場合**: アップロードした写真が全身であり、背景とのコントラストがはっきりした適切な照明の下で撮影されているか確認してください。
- **プッシュ通知が届かない場合**: ブラウザの通知権限が有効になっており、*Contact* に電話番号が保存されていることを確認してください。
- **住所の自動補完が反応しない場合**: OpenStreetMap Nominatim へのクエリを実行するために、インターネット接続がアクティブであることを確認してください。

## 制限事項
- Free Tier アカウントの保管スペースは初期 50 アイテムに制限されています。紹介ボーナス（1 人招待ごとに +10 枠、最大 150 アイテムまで）を利用するか、Manager または Professional プランにアップグレードすることで制限を解除できます。
- 高コストなクラウド生成エンドポイント（Trend Scout レーダーおよび Nano Banana 写真再構成）の利用には、ユーザー自身が提供する Google Gemini API キーが必要です。
- カスタム API キーモードをご利用の場合でも、外部プロバイダーのクォータが枯渇した際は、内蔵の Gemma-4-E4B エンジンへとスムーズにフォールバックされます。
